pub fn parse_recovering(source_file: &SimpleFile<String, String>) -> Parsed
Expand description

Parse source_file, carrying on past a syntax error to the next top-level declaration.

The token stream is cut into one chunk per top-level declaration before the layout pass sees it (chunk.rs has where it cuts and why there), and each chunk gets its own Layout and its own grammar entry point: Header for the first, Decls for every other. A chunk reports the first error raised in it and nothing after, which is the rule a whole module followed before the cut. The other chunks are parsed regardless, for their declarations or their errors.
