pub fn collect(modules: &[Interface]) -> Vec<ModuleTests>
Expand description

The tests each of modules exposes.

modules is one checked Interface per module of a package’s tests/ root, which is what a build that compiled the tests hands back. One ModuleTests comes back per module, in the same order, even when its tests is empty — a module that exposes no Test is still a module the build held, and dropping it here would leave a caller unable to tell “no tests” from “not compiled”.

Every tests is empty, for every module, when zelkova-test is not among the packages this build reached: nothing can have declared a value of a type nothing in the build can name, so nothing is found. That is not this pass’s error to raise — a package is free to hold no tests at all (What a test is).
