pub fn write(js_root: &Path, files: &[File]) -> Vec<Error>
Expand description

Write every one of files below js_root, creating the directories each needs, then remove whatever else was already below js_root that is not one of files — a module a previous build wrote that this one no longer holds, at any depth.

Writing stops at the first file that fails — the answer holds that one Error and nothing past it is written, and nothing is pruned — rather than working through every file the way loading or checking do; there is no diagnostic value in a second I/O failure once the first has already made the build’s output untrustworthy, and continuing would make “which files actually landed” a question with no single answer. Pruning runs only once every file wrote successfully, and stops at its own first failure the same way. The answer is empty when every write and every removal succeeded.
