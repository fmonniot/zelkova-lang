pub fn test(package_dir: &Path) -> Result<i32, BuildError>
Expand description

Compile the package rooted at package_dir with its tests (compile_package_with_tests), run every test it holds under node ([zelkova_test_runner::run], from the tree test_tree names), and answer the exit code the process should end with.

The answer is Ok(0) when every test passed and when the package holds none. It is node’s own exit code otherwise, which is non-zero exactly when a test did not pass or node itself failed. Anything that stops the tests being run — a build that did not compile, node missing — is an Err, and a build that did not compile never reaches node.
