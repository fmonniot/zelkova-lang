Struct Canonicalized 

Source 
pub struct Canonicalized {
    pub module: Module,
    pub errors: Vec<Error>,
}
Expand description

What canonicalize_recovering built of a module, beside every error it reported.

Fields§

§module: Module

The module, holding every declaration that canonicalized. A value declaration that did not is in Module::broken; a type, infix, class or instance declaration that did not is in neither.

§errors: Vec<Error>

Every error canonicalization reported. Empty exactly when canonicalize would answer Ok with module.

An error is left out of it only when another stands behind it: a not-found error raised in an incomplete scope restates the failure that made the scope incomplete (without_restated), and nothing about a declaration a chunk that failed to parse names is said beyond its annotation’s own errors, since the syntax error stands for it. A declaration that every error was left out of is either still absent from the module, because the error broke it, or present holding a hole for a name that did not resolve (Value::holds_hole). So empty here does not mean Module::broken is empty, that Module::incomplete is false, nor that no value holds a hole.
