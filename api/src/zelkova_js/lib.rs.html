1//! The JavaScript backend: one checked module in, the text of one ES module out.
2//!
3//! [`emit`] reads the [`ir::Module`] a [`CheckedModule`] carries, beside the
4//! [`canonical::Module`] it was built from for the one thing the IR does not hold — which
5//! names the module exports. It produces text and writes nothing: `compile_package` writes
6//! it, to the path [`module_file`] gives, once the whole build has checked and emitted.
7//!
8//! # The shape of an emitted module
9//!
10//! In this order, each section separated from the next by a blank line and left out when
11//! it is empty:
12//!
13//! 1. **Imports** — the runtime helpers the module calls, from the runtime module
14//!    ([`RUNTIME`]), then its companion's exports for a facade, then one named import per
15//!    value another module declares, from that module's package.
16//! 2. **Hoisted constructors** — one `const` per constructor of no arguments this module
17//!    declares, then one per such constructor of another module's that it mentions, which
18//!    every mention of it refers to ([`DEC-18` decision
19//!    4](../docs/decisions/dec-18.md#4--a-constructor-of-no-arguments-is-hoisted-to-one-module-level-constant)).
20//! 3. **Functions** — in a facade, first the union predicates its boundary checks call
21//!    ([*The boundary check*](#the-boundary-check)), in name order; then one `function`
22//!    per declaration that takes parameters, with exactly as many JavaScript parameters
23//!    as it was written with ([`DEC-18` decision
24//!    3](../docs/decisions/dec-18.md#3--a-function-emits-as-a-plain-n-ary-function-and-currying-is-a-runtime-helper)).
25//! 4. **Parameterless bindings** — one `const` each, in
26//!    [`ir::Module::initialisation_order`], so each is initialised after every other one
27//!    it depends on — the ones it mentions, and the ones a function it mentions reaches —
28//!    and no `const` is read before it is initialised.
29//! 5. **Exports** — one `export { … }` naming each exported value by its Zelkova name.
30//!
31//! # Representations
32//!
33//! An `Int` literal is a `BigInt` (`1n`), since [`Int` is 64
34//! bits](../docs/spec/evaluation-semantics.md#numbers); a `Float` is a number, a
35//! `Char` a one-character string and a `String` a string. `True` and `False` — the
36//! constructors of [`scalars::BOOL`], recognised by the union's qualified name — are
37//! `true` and `false`.
38//! `()` is `undefined` ([The unit value crosses as
39//! `undefined`](../docs/spec/interop.md#the-unit-value-crosses-as-undefined)) and a
40//! pattern that names it, at any depth, tests nothing and binds nothing — `undefined`
41//! among `RESERVED` is what keeps a Zelkova binding of that name from changing what a `()`
42//! in its scope reads as. Every other union value is `{$: "Ctor", a: …, b: …}`, arguments
43//! in declaration order ([A union crosses as a tagged
44//! value](../docs/spec/interop.md#a-union-crosses-as-a-tagged-value)); a
45//! constructor's arguments past the 26th continue `aa`, `ab`, … — see `field`. A tuple
46//! is an array.
47//!
48//! A constructor is not exported. An importer that builds one builds its own object of
49//! the same shape, and hoists its own constant for one of no arguments. [Equality is
50//! structural](../docs/spec/evaluation-semantics.md#what-structural-equality-computes),
51//! so nothing observes which module allocated it.
52//!
53//! # Calls
54//!
55//! An application whose IR node is [`Saturation::Saturated`] is a direct call,
56//! `f(a, b)`, or for a constructor the object itself. Every other application calls a
57//! *function value*, one argument per JavaScript call: `g(a)(b)`. What makes that
58//! correct is that every function value the emitted code hands around accepts being
59//! called one argument at a time. A declaration of two or more parameters — this
60//! module's or another's — and a constructor of two or more arguments, is `$curry(f, n)`
61//! wherever it is used as a value rather than called, so a partial application such as
62//! `pick 1` is `$curry(pick, 2)(1n)`; a one-parameter function already takes its
63//! argument one at a time.
64//!
65//! A value another module declares is called the same way as one of this module's
66//! ([`ir::ReferenceKind::Foreign`] carries its arity). A module exports each declaration
67//! as it emitted it — a declaration with parameters as the plain n-ary `function`, a
68//! parameterless binding as its `const` — and its [`Interface`](zelkova_compiler::Interface)
69//! records how many parameters each takes, so an importer's `Lib.pick a b` is a direct
70//! call of its import, `app$Lib$pick(a, b)`, as `pick a b` is inside `Lib`. A
71//! parameterless binding has arity 0 and is called one argument at a time wherever it
72//! is called, which is why a binding whose value is a function of two or more
73//! parameters, such as `Basics`' `add = Js.Basics.addInt`, holds that function
74//! `$curry`'d.
75//!
76//! One argument per call is also what keeps the [order of
77//! evaluation](../docs/spec/evaluation-semantics.md#order-of-evaluation): `g a b`
78//! applies `g a` before it evaluates `b`, and `g(a)(b)` does too where `g(a, b)` would
79//! not. Nothing here reorders a subexpression, and [nothing
80//! short-circuits](../docs/spec/evaluation-semantics.md#nothing-short-circuits):
81//! `&&` and `||` reach this module as ordinary applications of the functions their
82//! `infix` declarations name, so they are emitted as calls, never as JavaScript's own
83//! operators.
84//!
85//! # A facade
86//!
87//! [`emit`] answers a module for a `module foreign` facade too, so that an importer
88//! needs no special case. Every [`unsafe`](../docs/spec/interop.md#an-unsafe-facade)
89//! declaration becomes forwarding code that imports the companion's export under an
90//! alias and calls it with exactly the parameters the signature's arrow count gives —
91//! a plain function at arity one or more, a `const` at arity zero — the same
92//! [plain-parameter-list promise](../docs/spec/interop.md#the-javascript-companion)
93//! an ordinary declaration's call already keeps. [`Error::MissingCompanion`] is
94//! answered instead when the caller says no companion sits beside this module for the
95//! target being built ([*A facade names a boundary, not a
96//! backend*](../docs/spec/interop.md#a-facade-names-a-boundary-not-a-backend)) —
97//! [`emit`] has no path of its own to check that with, so the caller decides.
98//!
99//! A signature not marked `unsafe` declares an effect
100//! ([An effectful facade](../docs/spec/interop.md#an-effectful-facade)), and its
101//! forwarding code builds a `Task` instead of calling the companion: the `Task`'s run
102//! function calls the runtime's `$effect` with a function that calls the companion, the
103//! predicate of the payload type `a` of the signature's `Task (Result Failure a)` (`null`
104//! for a `()` payload, which is discarded), the export's name and the continuation it was
105//! handed. The companion is therefore called when the `Task` is run, never when it is built,
106//! and `$effect` is what catches a throw or a rejection as `Err (Threw ..)` and turns a
107//! value that fails the predicate into `Err (Malformed ..)`
108//! ([DEC-22 decision 4](../docs/decisions/dec-22.md#4--the-wrapper-is-one-runtime-helper-and-a-synchronous-companion-continues-synchronously)).
109//! The emitted text builds the `Task` as `{$: "Task", a: ($k) => $effect(..)}` and knows
110//! nothing of `Done`. A facade constant naming a `Task` gets the same `Task`, as one
111//! module-level `const`, and its companion export is called with no arguments each time the
112//! `Task` is run ([DEC-22 decision
113//! 7](../docs/decisions/dec-22.md#7--a-facade-constant-naming-a-task-gets-the-same-wrapper-with-no-arguments)).
114//!
115//! The companion is imported from [`companion_file`], beside the facade's own emitted
116//! file and renamed so that the two do not share one path.
117//!
118//! # The boundary check
119//!
120//! A value a companion hands back is run through the predicate of the type its signature
121//! declares ([Which types may cross the
122//! boundary](../docs/spec/interop.md#which-types-may-cross-the-boundary)): the
123//! forwarding code binds the companion's result to `$returned` and returns it unchanged
124//! when the predicate holds, and calls the runtime's `$abort` otherwise, naming the
125//! export — module and value — whose companion returned it ([When a program
126//! aborts](../docs/spec/evaluation-semantics.md#when-a-program-aborts)). An
127//! effectful facade's `$effect` runs the same predicate over the payload and routes a
128//! failure to `Err (Malformed ..)` where this check aborts.
129//!
130//! **Only the result is checked.** An argument on its way out to the companion is a
131//! Zelkova value the type checker already proved to be of its declared type, so nothing
132//! is run over it.
133//!
134//! **A result of `()` is discarded, not checked**: the companion is called, and the
135//! forwarding code returns `undefined` whatever it answered ([The unit value crosses as
136//! `undefined`](../docs/spec/interop.md#the-unit-value-crosses-as-undefined)). A
137//! facade constant of type `()` is `undefined`, its export still imported so that a
138//! companion missing it fails to link.
139//!
140//! Every other admitted type is decided by an expression over the value, built by
141//! `Predicates::test`: a scalar by its `typeof` — an `Int` also by `BigInt.asIntN(64, v)
142//! === v`, which holds exactly for a `bigint` the 64-bit range holds, and a `Char` by
143//! being a string of exactly one code point — a tuple as an array of its length whose
144//! elements each pass, and a `()` nested anywhere as `v === undefined`. A union is
145//! decided by a function of its own, `$is$<package>$<module>$<union>` (see `predicate`),
146//! emitted into the facade that needs it: it reads `$` against the declaration's
147//! constructors and checks each argument against the type that constructor declares for
148//! it, and it takes one predicate per type variable of the union, so `Maybe Int` is
149//! `$is$…$Maybe(v, ($v0) => …)`. A recursive union's function calls itself, which
150//! terminates because a Zelkova value holds no cycle; the walk costs the size of the
151//! value at every crossing.
152//!
153//! The declaration a union predicate is read off is the one its declaring module
154//! canonicalized — every constructor of it, whether or not the module exposes them —
155//! which is why [`emit`] is handed [`Unions`], every union of the build, rather than
156//! reading the facade's imports: an importer's view of an opaque type has no
157//! constructors. A result type with no predicate at all is [`Error::NoPredicate`].
158//!
159//! # A `case`
160//!
161//! [`ir::decision_tree`] turns a `case`'s branches — and a parameter written as a
162//! pattern, which the IR holds as a single-branch match on it
163//! ([`ir::CaseForm::Parameter`]) and which reaches `Emitter::case_expression` the
164//! same way — into the [`Decision`] tree a backend walks instead of re-deriving which
165//! test distinguishes which branch. `Emitter::case_expression` binds the scrutinee to
166//! `$scrutinee` once, since the tree tests it more than once and re-evaluating it per
167//! test would evaluate it once per test — observable through non-termination ([Order of
168//! evaluation](../docs/spec/evaluation-semantics.md#order-of-evaluation)) — and
169//! walks the tree into an `if`/`else` chain inside an immediately invoked function,
170//! since a `case` is an expression and JavaScript's `if` is a statement. A
171//! [`Decision::Test`] becomes an `if` on the value `occurrence_expr` reads off
172//! `$scrutinee`: `.$ === "Ctor"` for a constructor, an equality check for a literal. A
173//! [`Decision::Leaf`] declares its bindings as `const`s ahead of a `return`, all of it
174//! inside its own block — a binding may repeat a name the scrutinee expression reads
175//! ([Variable patterns](../docs/spec/patterns.md#variable-patterns)), and without
176//! that block the two would share a scope, putting the earlier read in the later
177//! binding's temporal dead zone. A [`Decision::Fail`] — the fall-through a `case`
178//! missing a branch reaches, because [coverage is not checked
179//! yet](../docs/spec/evaluation-semantics.md#two-outcomes) — calls the runtime's
180//! `$abort`, naming the declaration the `case` was written in and, for a parameter
181//! written as a pattern, saying so rather than naming a `case` the source never wrote.
182//!
183//! # What is refused
184//!
185//! [`emit`] answers an [`Error`] rather than a module missing a part: for a declaration
186//! with no IR ([`ir::Module::unchecked`]), for a facade declaration with no type signature,
187//! for a facade signature not marked `unsafe` whose result is not `Task (Result Failure a)`,
188//! for a facade with no companion for the target being built, for a facade result no
189//! predicate can decide, and for a construct it does not emit ([`Construct`]), a name that
190//! did not resolve among them.

211/// Why a module could not be emitted.
212#[derive(Debug, Clone, PartialEq)]
213pub enum Error {
214    /// A `module foreign` facade with no companion for the target being built
215    /// ([*A facade names a boundary, not a
216    /// backend*](../docs/spec/interop.md#a-facade-names-a-boundary-not-a-backend)).
217    ///
218    /// [`emit`] has no path of its own to check a companion's presence on disk with —
219    /// its caller does, and says so through [`emit`]'s `has_companion` parameter.
220    MissingCompanion { module: Name, target: &'static str },
221    /// A facade signature not marked `unsafe` whose result type is not `Task (Result
222    /// Failure a)`, so there is no payload for the wrapper to check
223    /// ([An effectful facade](../docs/spec/interop.md#an-effectful-facade)).
224    /// Canonicalization refuses such a signature first
225    /// (`canonical::Error::FacadeResultNotEffect`); this is what is left if one reaches
226    /// the backend anyway.
227    NotAnEffect { name: Name, span: NodeSpan },
228    /// A facade declaration the canonical module holds no type signature for, so there
229    /// is no result type to build a wrapper or a boundary check from. Canonicalization
230    /// refuses an unannotated facade declaration first; this is what is left if one
231    /// reaches the backend anyway.
232    NoSignature { name: Name, span: NodeSpan },
233    /// A declaration the typer could not check has no IR to emit, and a module emitted
234    /// without it would be missing a value its source declares.
235    Unchecked { name: Name, span: NodeSpan },
236    /// A facade signature whose result type has no predicate, so the value its
237    /// companion hands back cannot be checked ([Which types may cross the
238    /// boundary](../docs/spec/interop.md#which-types-may-cross-the-boundary)).
239    ///
240    /// The signature's own type expression is held to the admitted forms before this
241    /// phase (`canonical::Error::FacadeTypeNotAdmitted`), but a union it names is
242    /// checked through its constructors' declared arguments, which that check does not
243    /// read — so a union holding a function type is refused here, where its predicate
244    /// is built. Catching it in canonicalization instead is `BUG-45`. `constructor` is
245    /// the innermost constructor the offending type was declared in, when it was one.
246    NoPredicate {
247        name: Name,
248        span: NodeSpan,
249        found: Unpredicated,
250        constructor: Option<QualName>,
251    },
252    /// A construct this backend does not emit: one the front end does not accept yet,
253    /// or a name that did not resolve.
254    Unsupported {
255        construct: Construct,
256        /// The declaration it was written in.
257        declaration: Name,
258        span: NodeSpan,
259    },
260}

338impl PhaseError for Error {
339    fn message(&self) -> String {
340        match self {
341            Error::MissingCompanion { module, target } => format!(
342                "the facade `{}` has no companion for the `{}` target",
343                module.as_str(),
344                target
345            ),
346            Error::NotAnEffect { name, .. } => format!(
347                "`{}` is not marked `unsafe`, and its result is not `Task (Result Failure a)`, so no wrapper can be built for it",
348                name.as_str()
349            ),
350            Error::NoSignature { name, .. } => format!(
351                "the facade declaration `{}` has no type signature, so its boundary cannot be built",
352                name.as_str()
353            ),
354            Error::Unchecked { name, .. } => format!(
355                "`{}` cannot be compiled to JavaScript, because the type checker could not check it",
356                name.as_str()
357            ),
358            Error::NoPredicate {
359                name,
360                found,
361                constructor,
362                ..
363            } => {
364                let within = match constructor {
365                    Some(constructor) => format!(
366                        ", declared as an argument of the constructor `{}`",
367                        constructor.to_name().as_str()
368                    ),
369                    None => String::new(),
370                };
371                format!(
372                    "the value `{}`'s companion returns cannot be checked where it crosses into Zelkova: its type holds {}{}",
373                    name.as_str(),
374                    found.describe(),
375                    within
376                )
377            }
378            Error::Unsupported {
379                construct,
380                declaration,
381                ..
382            } => format!(
383                "`{}` cannot be compiled to JavaScript yet: it uses {}",
384                declaration.as_str(),
385                construct.describe()
386            ),
387        }
388    }
389
390    fn labels(&self) -> Vec<SpanLabel> {
391        let (span, message) = match self {
392            // No span exists for a `module foreign` line today — nothing in the parsed
393            // or canonical AST carries the module header's position, only each
394            // declaration's — so this names the facade and the target in `message()`
395            // alone.
396            Error::MissingCompanion { .. } => return Vec::new(),
397            Error::NotAnEffect { span, .. } => (span, "not marked `unsafe`"),
398            Error::NoSignature { span, .. } => (span, "this declaration"),
399            Error::Unchecked { span, .. } => (span, "this declaration"),
400            Error::NoPredicate { span, .. } => (span, "this signature"),
401            Error::Unsupported { span, .. } => (span, "not supported by the JavaScript backend"),
402        };
403
404        match span.span() {
405            Some(span) => vec![SpanLabel {
406                span,
407                message: message.to_owned(),
408                primary: true,
409                file: None,
410            }],
411            None => Vec::new(),
412        }
413    }

487/// The JavaScript name of a name the Zelkova source wrote: a declaration of this module,
488/// a parameter, or a name a pattern bound.
489///
490/// **The scheme.** A name in [`RESERVED`] gets a `$` prefix — `class` is `$class` — and
491/// every other name is left as it is: `classy` is `classy`. A Zelkova identifier is
492/// letters and digits as Unicode classifies them, and `_` — what JavaScript accepts in an
493/// identifier too — and never contains a `$`. That is what makes the scheme unable to merge two names: a name left
494/// alone has no `$`, a renamed one starts with the only `$` it has, and the prefix is
495/// removed by reading past it.
496///
497/// Every other name an emitted module declares is the emitter's own, and each is built
498/// so that it cannot be one this function returns, nor one another item here returns:
499///
500/// - the runtime's helpers, `$curry`, `$abort` and `$effect`, the `$scrutinee` a `case`
501///   binds, the `$k` an effectful facade's `Task` is handed, and
502///   the names a boundary check binds — `$returned`, the value a companion handed back,
503///   and inside a union predicate `$v0`, `$v1`, … for the value under test and `$p0`,
504///   `$p1`, … for the predicates of the union's type variables: a `$` and a word that is
505///   not in [`RESERVED`], and no other `$`;
506/// - a union predicate, [`predicate`]: `$is`, then the same segments as a hoisted
507///   constructor's, so its second segment is a package — lowercase, where the second
508///   segment of a hoisted constructor, even of a package named `is`, is a module's and
509///   uppercase;
510/// - a value imported from another module, [`imported`]: it contains a `$`, does not
511///   start with one, and its first segment — the package — is lowercase, where a module
512///   segment is uppercase;
513/// - a hoisted constructor, [`hoisted`]: a `$` followed by at least three more segments,
514///   each separated from the next by a `$` — package, module segments, constructor;
515/// - the facade's alias for its companion's export, [`companion_alias`]: `$companion$`
516///   and the value's name, which holds no `$` — a `$`, a word not in [`RESERVED`], and
517///   exactly one more `$`, so one segment fewer than any hoisted constructor;
518/// - a wildcard parameter, [`wildcard`]: `$_` and a number, and `_0`, `_1`, … are not in
519///   [`RESERVED`];
520/// - a parameter written as a pattern, [`ir::pattern_parameter`]: `$` and a number,
521///   which this function leaves as it is, since nothing in [`RESERVED`] holds a `$`.
522///
523/// Two imports, or two hoisted constructors, are told apart by their segments: none of
524/// them holds a `$`, so the segments come back out by splitting at it, and together
525/// they are the declaration's full identity — package, module and name — which is
526/// unique in a build.
527fn mangle(name: &str) -> String {
528    if RESERVED.contains(&name) {
529        format!("${}", name)
530    } else {
531        name.to_string()
532    }
533}
534
535/// The name of the `position`th parameter of a declaration, when the source wrote `_`
536/// there: `$_0`, `$_1`, ….
537///
538/// Nothing reads it; it exists because two parameters of one JavaScript function may not
539/// share a name, and `f _ _` has two. See [`mangle`] for why it cannot meet another name.
540fn wildcard(position: usize) -> String {
541    format!("$_{}", position)
542}
543
544/// A package's name as the first segment of a local name: each `-` replaced by `_` —
545/// `zelkova-core` is `zelkova_core`.
546///
547/// This is injective because a legal package name holds no `_`, and always a valid start
548/// of a JavaScript identifier because a package name starts with a lowercase letter.
549/// It is the package's own name and never its [namespace](zelkova_compiler::PackageName::namespace),
550/// which is how one dependent spells the package rather than what the package is.
551fn package_segment(package: &str) -> String {
552    package.replace('-', "_")
553}
554
555/// The module-level constant a constructor of no arguments is hoisted to: `$`, then the
556/// package declaring its union ([`package_segment`]), the segments of the module
557/// declaring it and its own name, joined by `$` — `Test`'s `Red` in package `app` is
558/// `$app$Test$Red`.
559///
560/// It is the same whether the module declaring the union hoists it or a module
561/// mentioning it does.
562fn hoisted(union: &QualName, constructor: &Name) -> String {
563    format!(
564        "${}${}${}",
565        package_segment(union.package().as_str()),
566        union.module_name().as_str().replace('.', "$"),
567        constructor.as_str()
568    )
569}
570
571/// The function deciding whether a value belongs to `union`: `$is`, then the package
572/// declaring it ([`package_segment`]), its module's segments and its own name, joined by
573/// `$` — `Maybe.Maybe` of `zelkova-core` is `$is$zelkova_core$Maybe$Maybe`.
574///
575/// Emitted by the facade whose boundary check calls it, never exported: two facades
576/// checking one union each hold their own copy, as two importers of a constructor each
577/// hoist their own constant.
578fn predicate(union: &QualName) -> String {
579    format!(
580        "$is${}${}${}",
581        package_segment(union.package().as_str()),
582        union.module_name().as_str().replace('.', "$"),
583        union.unqualified_name().as_str()
584    )
585}

587/// The local name a value another module declares is imported under: the package
588/// declaring it ([`package_segment`]), the module's segments and the value's name,
589/// joined by `$` — `Maybe.withDefault` is `zelkova_core$Maybe$withDefault`.
590///
591/// A value is never imported under its own name, because this module may declare the
592/// same name itself; and never under its module's name alone, because two packages may
593/// each declare a module of that name, and this module may import both.
594fn imported(package: &str, module: &str, name: &str) -> String {
595    format!(
596        "{}${}${}",
597        package_segment(package),
598        module.replace('.', "$"),
599        name
600    )
601}

603/// The local name a facade imports its companion's export `name` under:
604/// `$companion$<name>`.
605fn companion_alias(name: &str) -> String {
606    format!("$companion${}", name)
607}

609/// The name of the field a constructor's argument at `index` is stored in: `a`, `b`, …
610/// `z`, then `aa`, `ab`, … — the spreadsheet column sequence, which carries on the
611/// published `a`, `b`, `c` past the alphabet without two indices sharing a name.
612fn field(index: usize) -> String {
613    let mut letters = Vec::new();
614    let mut remaining = index + 1;
615
616    while remaining > 0 {
617        remaining -= 1;
618        letters.push((b'a' + (remaining % 26) as u8) as char);
619        remaining /= 26;
620    }
621
622    letters.iter().rev().collect()
623}

626//
627// The output of a build is one tree, `build/out/js/` beside the root package's manifest
628// ([`DEC-18` decision 5](../docs/decisions/dec-18.md#5--output-is-written-per-package-beside-the-root-manifest)):
629//
630// ```text
631// build/out/js/
632//   zelkova.mjs                      the runtime, RUNTIME_FILE
633//   main.mjs                         the entry point `zelkova run` adds, zelkova::program_runner::MAIN_FILE
634//   zelkova-core/                    one directory per package of the build
635//     Maybe.mjs                      one file per module, module_file
636//     Js/Basics.mjs                  a facade's module, like any other
637//     Js/Basics.companion.mjs        that facade's companion, companion_file
638// ```
639//
640// The functions below are the only places a path into that tree is built, and the
641// specifiers are built from the same shape, so what is written and what is imported
642// cannot disagree. `compile_package` writes the tree.
643
644/// The runtime's file name, at the root of `build/out/js/`, above every package's directory.
645pub const RUNTIME_FILE: &str = "zelkova.mjs";
646
647/// The runtime module's text, the one file of the output that is not generated.
648///
649/// It is embedded in the compiler binary when the compiler is built, from
650/// `runtime/js/zelkova.mjs` in the compiler's own tree, and written out from here. A
651/// compiler that looked for that file at run time would have to find its own source
652/// tree — relative to the binary, the working directory or an environment variable —
653/// and every one of those is wrong for a binary run from anywhere else. Embedding it
654/// leaves nothing to look up and no way to fail but writing, and a compiler always
655/// writes the runtime it was built with.
656pub const RUNTIME: &str = include_str!("../../../runtime/js/zelkova.mjs");

658/// How many directories below its package's output directory the emitted file for
659/// `module` sits: one per segment of its name but the last.
660fn depth(module: &Name) -> usize {
661    module.as_str().split('.').count() - 1
662}
663
664/// Where the module named `module` is written, relative to its package's directory:
665/// one directory per segment of its name but the last — `Js.Basics` is
666/// `Js/Basics.mjs`.
667///
668/// This is the module's name **within its own package**, never the namespace a
669/// dependent reaches it by, so each package's modules have one path whichever package
670/// imports them.
671pub fn module_file(module: &Name) -> PathBuf {
672    let mut path: PathBuf = module.as_str().split('.').collect();
673    path.set_extension("mjs");
674    path
675}
676
677/// Where the companion of the facade named `module` is written, relative to its
678/// package's directory: beside the facade's own module, named after it with
679/// `.companion.mjs` — `Js.Basics`'s is `Js/Basics.companion.mjs`.
680///
681/// It cannot keep the name it has beside the `.zel` source, `Basics.mjs`, because that
682/// is the facade's own [`module_file`]. It is the companion that is renamed rather than
683/// the facade, because the facade's path is the one every importer builds from a module
684/// name. No module's file can be called this: a segment of a module name holds no `.`,
685/// so no [`module_file`] has two in its file name.
686///
687/// The companion is copied byte for byte, so one that imports a sibling `.mjs` by a
688/// relative specifier finds the emitted module of that name there, not the sibling it
689/// was written beside. The one import a build rewrites is a test companion's of the
690/// companion it checks ([`test_companion_import`]).
691pub fn companion_file(module: &Name) -> PathBuf {
692    let mut path = module_file(module);
693    path.set_extension("companion.mjs");
694    path
695}

697/// The specifier the module `from` imports the module named `to`, declared by
698/// `package`, by.
699///
700/// Within one package it is a path inside that package's directory. Across a package
701/// boundary it climbs out of `from`'s package to `build/out/js/` and into `package`'s
702/// sibling directory — which is why every package of the build has its own directory
703/// rather than the whole build sharing one tree.
704fn module_specifier(from: &ModuleName, package: &str, to: &Name) -> String {
705    let to_path = to.as_str().replace('.', "/");
706
707    if from.package().as_str() == package {
708        let up = match depth(from.name()) {
709            0 => "./".to_string(),
710            depth => "../".repeat(depth),
711        };
712        format!("{}{}.mjs", up, to_path)
713    } else {
714        format!(
715            "{}{}/{}.mjs",
716            "../".repeat(depth(from.name()) + 1),
717            package,
718            to_path
719        )
720    }
721}

723/// The specifier the module named `from` imports the runtime by: [`RUNTIME_FILE`] at
724/// the root of `build/out/js/`, one level above `from`'s package directory.
725fn runtime_specifier(from: &Name) -> String {
726    format!("{}{}", "../".repeat(depth(from) + 1), RUNTIME_FILE)
727}

729/// The specifier a facade named `module` imports its own companion by: its
730/// [`companion_file`], which sits in the same directory — `Js.Basics` imports
731/// `./Basics.companion.mjs`.
732fn companion_specifier(module: &Name) -> String {
733    let file = companion_file(module);
734    let name = file
735        .file_name()
736        .map(|name| name.to_string_lossy().into_owned())
737        .unwrap_or_default();
738    format!("./{}", name)
739}

741/// How the companion of the test facade `checks`, a module of a package's `tests/` root,
742/// imports the companion of the facade `target`, a module of the same package's `src/`
743/// root: the specifier it spells in its source, then the one that replaces it in the
744/// build.
745///
746/// A test companion imports the companion it checks by the relative path between the two
747/// files as they sit in the package's source
748/// ([*Testing a companion*](../docs/spec/interop.md#testing-a-companion)): climb
749/// out of `tests/` to the package's root, then down into `src/` — from
750/// `tests/Js/BasicsChecks.mjs`, `Js.Basics`'s is `../../src/Js/Basics.mjs`. The build
751/// holds both roots' modules in one package directory and renames each companion
752/// ([`companion_file`]), so that path reaches nothing there. What does is the path from
753/// `checks`' [`companion_file`] to `target`'s, climbing to the package's directory and
754/// down again — `../Js/Basics.companion.mjs` — which is the companion the build wrote
755/// for `target`, the one the facade `target` calls.
756///
757/// Only the shortest spelling is produced: a specifier that reaches the same file by a
758/// longer path, `./../../src/Js/Basics.mjs`, is not this one.
759pub fn test_companion_import(checks: &Name, target: &Name) -> (String, String) {
760    let target_path = target.as_str().replace('.', "/");
761    let source = format!("{}src/{}.mjs", "../".repeat(depth(checks) + 1), target_path);
762    let build = match depth(checks) {
763        0 => format!("./{}.companion.mjs", target_path),
764        depth => format!("{}{}.companion.mjs", "../".repeat(depth), target_path),
765    };
766    (source, build)
767}

769/// `text` with every string literal spelling one of `imports`' first specifiers replaced
770/// by the same literal spelling its second, with the quote it was written with.
771///
772/// Only a literal delimited by `'` or `"` and holding exactly that specifier is replaced —
773/// a template literal, or the specifier as part of a longer string, is left as it is. The
774/// text is not parsed, so a literal inside a comment is replaced along with the ones in
775/// `import` declarations: a comment holding the exact quoted path to a companion under
776/// test is the only thing that changes that should not.
777pub fn rewrite_imports(text: &str, imports: &[(String, String)]) -> String {
778    let mut text = text.to_string();
779    for (from, to) in imports {
780        for quote in ['\'', '"'] {
781            text = text.replace(
782                &format!("{quote}{from}{quote}"),
783                &format!("{quote}{to}{quote}"),
784            );
785        }
786    }
787    text
788}

792/// A JavaScript string literal holding `c` and nothing else.
793fn char_literal(c: char) -> String {
794    format!("\"{}\"", escaped(c))
795}
796
797/// A JavaScript string literal holding `text`, each character escaped as
798/// [`char_literal`] escapes it.
799fn string_literal(text: &str) -> String {
800    format!("\"{}\"", text.chars().map(escaped).collect::<String>())
801}
802
803/// `c` as it is written inside a JavaScript string literal.
804fn escaped(c: char) -> String {
805    match c {
806        '"' => "\\\"".to_string(),
807        '\\' => "\\\\".to_string(),
808        '\n' => "\\n".to_string(),
809        '\r' => "\\r".to_string(),
810        '\t' => "\\t".to_string(),
811        // Control characters, and the two line terminators JavaScript source treats
812        // specially, as escapes rather than raw.
813        c if c.is_control() || c == '\u{2028}' || c == '\u{2029}' => {
814            format!("\\u{{{:x}}}", c as u32)
815        }
816        c => c.to_string(),
817    }
818}

820/// A JavaScript number literal for `f`.
821///
822/// `{:?}` is Rust's shortest representation that reads back as the same `f64`, and
823/// every finite one it writes — `1.0`, `0.1`, `1e300` — is also a JavaScript number
824/// literal of that value. No literal a source can write is infinite or `NaN`; they are
825/// covered so that nothing here can write something that is not JavaScript.
826fn float_literal(f: f64) -> String {
827    if f.is_nan() {
828        "NaN".to_string()
829    } else if f == f64::INFINITY {
830        "Infinity".to_string()
831    } else if f == f64::NEG_INFINITY {
832        "-Infinity".to_string()
833    } else {
834        format!("{:?}", f)
835    }
836}

838// ── Emitting a module ─────────────────────────────────────────────────────────
839
840/// The JavaScript text of `module`, or every reason it cannot be emitted.
841///
842/// `has_companion` is irrelevant to any module but a `module foreign` facade, for which
843/// it says whether a JavaScript companion sits beside it for the target being built.
844/// [`emit`] has no path of its own to check that with — the caller does, since only it
845/// knows where `module`'s source came from — so a facade with no companion is
846/// [`Error::MissingCompanion`] rather than something this function discovers.
847///
848/// `unions` is where a facade's boundary checks read each union they reach off its
849/// declaration; see [`Unions`]. A module that is not a facade reads nothing from it.
850///
851/// See this module's documentation for the shape of the text.
852pub fn emit(
853    module: &CheckedModule,
854    has_companion: bool,
855    unions: &Unions,
856) -> Result<String, Vec<Error>> {
857    let ir = &module.ir;
858
859    if ir.foreign && !has_companion {
860        return Err(vec![Error::MissingCompanion {
861            module: ir.name.name().clone(),
862            target: "javascript",
863        }]);
864    }
865
866    let mut emitter = Emitter {
867        arities: ir
868            .declarations
869            .iter()
870            .map(|declaration| (declaration.name.clone(), declaration.arity))
871            .collect(),
872        runtime: BTreeSet::new(),
873        imports: BTreeMap::new(),
874        module: ir.name.clone(),
875        imported_constructors: BTreeMap::new(),
876        errors: ir
877            .unchecked
878            .iter()
879            .map(|unchecked| Error::Unchecked {
880                name: unchecked.name.clone(),
881                span: unchecked.span,
882            })
883            .collect(),
884        declaration: None,
885    };
886
887    let mut functions = Vec::new();
888    let mut constants: HashMap<&Name, String> = HashMap::new();
889    let mut companion_imports: Vec<String> = Vec::new();
890    let mut predicates = Predicates {
891        unions,
892        functions: BTreeMap::new(),
893    };
894
895    for declaration in &ir.declarations {
896        emitter.declaration = Some(declaration.name.clone());
897
898        if ir.foreign {
899            emitter.facade_declaration(
900                &module.canonical,
901                declaration,
902                &mut predicates,
903                &mut functions,
904                &mut constants,
905                &mut companion_imports,
906            );
907            continue;
908        }
909
910        // Every declaration of a module that is not a facade has a body; one without
911        // would be a facade signature, handled above.
912        let Some(body) = &declaration.body else {
913            continue;
914        };
915
916        let expression = emitter.expression(&body.expression);
917        let name = mangle(declaration.name.as_str());
918
919        if body.parameters.is_empty() {
920            constants.insert(
921                &declaration.name,
922                format!("const {} = {};", name, expression),
923            );
924        } else {
925            let parameters: Vec<String> = body
926                .parameters
927                .iter()
928                .enumerate()
929                .map(|(position, parameter)| match parameter.name.as_str() {
930                    "_" => wildcard(position),
931                    other => mangle(other),
932                })
933                .collect();
934
935            functions.push(format!(
936                "function {}({}) {{\n  return {};\n}}",
937                name,
938                parameters.join(", "),
939                expression
940            ));
941        }
942    }
943
944    if !emitter.errors.is_empty() {
945        return Err(emitter.errors);
946    }
947
948    // The union predicates the boundary checks call go ahead of every other function,
949    // in name order — a function declaration is hoisted, so the order is for the reader.
950    let functions: Vec<String> = predicates
951        .functions
952        .into_values()
953        .chain(functions)
954        .collect();
955
956    // The parameterless bindings, in the order they have to be initialised. Every one
957    // of them is in that order; a binding that somehow was not would still be emitted,
958    // after the rest and in name order, rather than lost.
959    let mut ordered = Vec::new();
960    for name in &ir.initialisation_order {
961        if let Some(constant) = constants.remove(name) {
962            ordered.push(constant);
963        }
964    }
965    let mut leftover: Vec<(&Name, String)> = constants.into_iter().collect();
966    leftover.sort_by(|left, right| left.0.as_str().cmp(right.0.as_str()));
967    ordered.extend(leftover.into_iter().map(|(_, constant)| constant));
968
969    let mut hoisted = hoisted_constructors(ir);
970    hoisted.extend(
971        emitter
972            .imported_constructors
973            .iter()
974            .map(|(local, name)| format!("const {} = {{$: \"{}\"}};", local, name.as_str())),
975    );
976
977    let mut sections: Vec<String> = Vec::new();
978
979    let mut imports = Vec::new();
980    if !emitter.runtime.is_empty() {
981        let helpers: Vec<&str> = emitter.runtime.iter().copied().collect();
982        imports.push(format!(
983            "import {{ {} }} from \"{}\";",
984            helpers.join(", "),
985            runtime_specifier(ir.name.name())
986        ));
987    }
988    if !companion_imports.is_empty() {
989        imports.push(format!(
990            "import {{ {} }} from \"{}\";",
991            companion_imports.join(", "),
992            companion_specifier(ir.name.name())
993        ));
994    }
995    for ((package, from), names) in &emitter.imports {
996        let specifiers: Vec<String> = names
997            .iter()
998            .map(|name| format!("{} as {}", name, imported(package, from, name)))
999            .collect();
1000        imports.push(format!(
1001            "import {{ {} }} from \"{}\";",
1002            specifiers.join(", "),
1003            module_specifier(&ir.name, package, &Name::new(from.as_str()))
1004        ));
1005    }
1006
1007    for section in [imports, hoisted, ordered_functions(functions), ordered] {
1008        if !section.is_empty() {
1009            sections.push(section.join("\n"));
1010        }
1011    }
1012
1013    let exports = exports(module);
1014    if !exports.is_empty() {
1015        sections.push(format!("export {{ {} }};", exports.join(", ")));
1016    }
1017
1018    let mut text = sections.join("\n\n");
1019    text.push('\n');
1020    Ok(text)
1021}

1023/// Functions are separated from each other by a blank line, which joining the section
1024/// with one more newline gives.
1025fn ordered_functions(functions: Vec<String>) -> Vec<String> {
1026    functions
1027        .into_iter()
1028        .enumerate()
1029        .map(|(index, function)| {
1030            if index == 0 {
1031                function
1032            } else {
1033                format!("\n{}", function)
1034            }
1035        })
1036        .collect()
1037}

1039/// One `const` per constructor of no arguments the module declares, unions in the IR's
1040/// name order and each union's constructors in declaration order.
1041///
1042/// `Bool`'s two are not among them: they are `true` and `false`.
1043fn hoisted_constructors(ir: &ir::Module) -> Vec<String> {
1044    ir.unions
1045        .iter()
1046        .filter(|union| !scalars::BOOL.declares(&union.name))
1047        .flat_map(|union| {
1048            union
1049                .variants
1050                .iter()
1051                .filter(|variant| variant.arity == 0)
1052                .map(move |variant| {
1053                    format!(
1054                        "const {} = {{$: \"{}\"}};",
1055                        hoisted(&union.name, &variant.name),
1056                        variant.name.as_str()
1057                    )
1058                })
1059        })
1060        .collect()
1061}

1063/// The export specifiers for the values `module` exposes, in name order: a value its
1064/// `exposing` header names, or the function an exposed operator stands for.
1065///
1066/// Each is exported under its Zelkova name, so a renamed one reads `$class as class` —
1067/// an export's name may be a reserved word where a binding's may not.
1068fn exports(module: &CheckedModule) -> Vec<String> {
1069    let exposed = |name: &Name| match &module.canonical.exports {
1070        Exports::Everything => true,
1071        Exports::Specifics(specifics) => {
1072            specifics.get(name) == Some(&ExportType::Value)
1073                || specifics.iter().any(|(symbol, kind)| {
1074                    *kind == ExportType::Infix
1075                        && module
1076                            .canonical
1077                            .infixes
1078                            .get(symbol)
1079                            .is_some_and(|infix| &infix.function_name == name)
1080                })
1081        }
1082    };
1083
1084    module
1085        .ir
1086        .declarations
1087        .iter()
1088        .filter(|declaration| exposed(&declaration.name))
1089        .map(|declaration| {
1090            let local = mangle(declaration.name.as_str());
1091            if local == declaration.name.as_str() {
1092                local
1093            } else {
1094                format!("{} as {}", local, declaration.name.as_str())
1095            }
1096        })
1097        .collect()
1098}

1102/// Every union a build declares, by its qualified name, as its declaring module
1103/// canonicalized it: what a facade's boundary check reads a union's constructors, and
1104/// the type each declares for each of its arguments, off.
1105///
1106/// It is built from the checked modules themselves, never from an [`Interface`](zelkova_compiler::Interface):
1107/// an interface exposing a type without its constructors hands over none of them, and
1108/// the predicate of such a type still reads `$` against every constructor its
1109/// declaration has.

1127/// Why no predicate could be built: what was found, and the innermost constructor whose
1128/// declared argument held it, if it was inside one. Boxed, since it is the error half of
1129/// every `Result` the predicate builders return and is much larger than the text half.
1130type NoPredicate = Box<(Unpredicated, Option<QualName>)>;
1131
1132/// The union predicates one facade's boundary checks call, built as the checks need
1133/// them.
1134struct Predicates<'a> {
1135    unions: &'a Unions,
1136    /// Each union predicate's text, by its name ([`predicate`]). A union's entry is
1137    /// inserted, empty, before its body is built, so a recursive union meets its own
1138    /// name here and calls it rather than building it again.
1139    functions: BTreeMap<String, String>,
1140}
1141
1142impl Predicates<'_> {
1143    /// A JavaScript expression that is `true` exactly when `value` — an expression
1144    /// without side effects, evaluated as often as the test needs it — belongs to
1145    /// `tpe`. A conjunction of `===` tests and calls, so it needs no parentheses beside
1146    /// another `&&` or ahead of a `?`.
1147    ///
1148    /// `parameters` binds each type variable in scope — inside a union predicate, the
1149    /// union's own — to the name of the predicate its argument was given as. `depth`
1150    /// is how many parameters of nested arrow functions are already in scope, so each
1151    /// one gets its own name.
1152    fn test(
1153        &mut self,
1154        tpe: &canonical::Type,
1155        value: &str,
1156        depth: usize,
1157        parameters: &HashMap<&Name, String>,
1158    ) -> Result<String, NoPredicate> {
1159        match tpe {
1160            canonical::Type::Unit => Ok(format!("{} === undefined", value)),
1161            canonical::Type::Tuple(tuple) => {
1162                let mut tests = vec![
1163                    format!("Array.isArray({})", value),
1164                    format!("{}.length === {}", value, tuple.iter().count()),
1165                ];
1166                for (index, element) in tuple.iter().enumerate() {
1167                    tests.push(self.test(
1168                        element,
1169                        &format!("{}[{}]", value, index),
1170                        depth,
1171                        parameters,
1172                    )?);
1173                }
1174                Ok(tests.join(" && "))
1175            }
1176            canonical::Type::Variable(name) => match parameters.get(name) {
1177                Some(predicate) => Ok(format!("{}({})", predicate, value)),
1178                None => Err(Box::new((Unpredicated::Variable(name.clone()), None))),
1179            },
1180            canonical::Type::Arrow(..) => Err(Box::new((Unpredicated::Function, None))),
1181            canonical::Type::Record(_) => Err(Box::new((Unpredicated::Record, None))),
1182            canonical::Type::Type(name, arguments) => match scalars::scalar_of(name) {
1183                Some(scalars::INT) => Ok(format!(
1184                    "typeof {v} === \"bigint\" && BigInt.asIntN(64, {v}) === {v}",
1185                    v = value
1186                )),
1187                Some(scalars::FLOAT) => Ok(format!("typeof {} === \"number\"", value)),
1188                Some(scalars::BOOL) => Ok(format!("typeof {} === \"boolean\"", value)),
1189                // One code point: a string of one UTF-16 unit, or of the two a code
1190                // point past `0xFFFF` takes. An empty string's `codePointAt(0)` is
1191                // `undefined`, which asks for a length of one and fails it.
1192                Some(scalars::CHAR) => Ok(format!(
1193                    "typeof {v} === \"string\" && {v}.length === ({v}.codePointAt(0) > 0xFFFF ? 2 : 1)",
1194                    v = value
1195                )),
1196                Some(scalars::STRING) => Ok(format!("typeof {} === \"string\"", value)),
1197                _ => {
1198                    let function = self.union(name)?;
1199                    let mut call = vec![value.to_string()];
1200                    for argument in arguments {
1201                        let parameter = format!("$v{}", depth);
1202                        let test = self.test(argument, &parameter, depth + 1, parameters)?;
1203                        call.push(format!("({}) => {}", parameter, test));
1204                    }
1205                    Ok(format!("{}({})", function, call.join(", ")))
1206                }
1207            },
1208        }
1209    }
1210
1211    /// The name of the predicate deciding `union`, building its function first when
1212    /// this facade has not needed it yet.
1213    ///
1214    /// The function takes the value as `$v0` and one predicate per type variable of the
1215    /// union, `$p0`, `$p1`, … in declaration order. It answers `false` for anything but
1216    /// a non-null object, and otherwise switches on `$`: each constructor tests its
1217    /// arguments, read off the fields [`field`] names, against the types it declares
1218    /// for them, and a `$` naming no constructor of the declaration is `false`.
1219    fn union(&mut self, union: &QualName) -> Result<String, NoPredicate> {
1220        let name = predicate(union);
1221        if self.functions.contains_key(&name) {
1222            return Ok(name);
1223        }
1224
1225        let unions = self.unions;
1226        let Some(declaration) = unions.0.get(union) else {
1227            return Err(Box::new((Unpredicated::Undeclared(union.clone()), None)));
1228        };
1229        self.functions.insert(name.clone(), String::new());
1230
1231        // A union no predicate can be built for leaves no entry behind, so another facade
1232        // declaration naming *that* union meets the same error rather than a call to a
1233        // function that was never finished. That covers this union only: a mutually
1234        // recursive union built successfully while this one was still in progress (it
1235        // found this union's placeholder and used it) keeps its own `functions` entry,
1236        // even though the removal below just deleted the predicate that entry calls — a
1237        // facade naming only the other union gets no diagnostic for that.
1238        match self.union_function(union, &name, declaration) {
1239            Ok(function) => {
1240                self.functions.insert(name.clone(), function);
1241                Ok(name)
1242            }
1243            Err(error) => {
1244                self.functions.remove(&name);
1245                Err(error)
1246            }
1247        }
1248    }
1249
1250    /// The text of the function [`Predicates::union`] names `name`, deciding `union`
1251    /// against `declaration`.
1252    fn union_function(
1253        &mut self,
1254        union: &QualName,
1255        name: &str,
1256        declaration: &canonical::UnionType,
1257    ) -> Result<String, NoPredicate> {
1258        let predicates: Vec<String> = (0..declaration.variables.len())
1259            .map(|index| format!("$p{}", index))
1260            .collect();
1261        let parameters: HashMap<&Name, String> = declaration
1262            .variables
1263            .iter()
1264            .zip(predicates.iter().cloned())
1265            .collect();
1266
1267        let mut cases = Vec::new();
1268        for constructor in &declaration.variants {
1269            let mut tests = Vec::new();
1270            for (index, argument) in constructor.type_parameters.iter().enumerate() {
1271                let value = format!("$v0.{}", field(index));
1272                let test =
1273                    self.test(argument, &value, 1, &parameters)
1274                        .map_err(|mut no_predicate| {
1275                            if no_predicate.1.is_none() {
1276                                no_predicate.1 = Some(union.sibling(&constructor.name));
1277                            }
1278                            no_predicate
1279                        })?;
1280                tests.push(test);
1281            }
1282            let test = if tests.is_empty() {
1283                "true".to_string()
1284            } else {
1285                tests.join(" && ")
1286            };
1287            cases.push(format!(
1288                "    case {}:\n      return {};",
1289                string_literal(constructor.name.as_str()),
1290                test
1291            ));
1292        }
1293        cases.push("    default:\n      return false;".to_string());
1294
1295        let signature: Vec<&str> = std::iter::once("$v0")
1296            .chain(predicates.iter().map(String::as_str))
1297            .collect();
1298        Ok(format!(
1299            "function {}({}) {{\n  if (typeof $v0 !== \"object\" || $v0 === null) {{\n    return false;\n  }}\n  switch ($v0.$) {{\n{}\n  }}\n}}",
1300            name,
1301            signature.join(", "),
1302            cases.join("\n")
1303        ))
1304    }
1305}

1307/// The canonical type left once `arity` arrows are taken off the front of `tpe` — a
1308/// facade signature's result, `tpe` itself for a facade constant.
1309fn canonical_result(tpe: &canonical::Type, arity: usize) -> &canonical::Type {
1310    let mut result = tpe;
1311    for _ in 0..arity {
1312        match result {
1313            canonical::Type::Arrow(_, rest) => result = rest,
1314            _ => break,
1315        }
1316    }
1317    result
1318}
1319
1320/// [`canonical_result`] over the typer's type of the same signature, which is the one
1321/// that can be written out the way the source spells it.
1322fn typer_result(tpe: &Type, arity: usize) -> &Type {
1323    let mut result = tpe;
1324    for _ in 0..arity {
1325        match result {
1326            Type::Fun { return_tpe, .. } => result = return_tpe,
1327            _ => break,
1328        }
1329    }
1330    result
1331}

1335struct Emitter {
1336    /// How many parameters each of this module's declarations takes.
1337    arities: HashMap<Name, usize>,
1338    /// The runtime helpers the emitted text calls.
1339    runtime: BTreeSet<&'static str>,
1340    /// The values of other modules the emitted text mentions, by the package and the
1341    /// module declaring each.
1342    imports: BTreeMap<(String, String), BTreeSet<String>>,
1343    /// The module being emitted, package included, which tells a constructor it declares
1344    /// from one another module does — of this package or of another.
1345    module: ModuleName,
1346    /// The constructors of no arguments another module declares that the emitted text
1347    /// mentions, by the name each is hoisted to. This module hoists its own constant for
1348    /// each, since the declaring module exports none.
1349    imported_constructors: BTreeMap<String, Name>,
1350    errors: Vec<Error>,
1351    /// The declaration being emitted, which an [`Error::Unsupported`] names.
1352    declaration: Option<Name>,
1353}
1354
1355impl Emitter {
1356    fn unsupported(&mut self, construct: Construct, span: NodeSpan) -> String {
1357        self.errors.push(Error::Unsupported {
1358            construct,
1359            declaration: self.declaration.clone().unwrap_or_else(|| Name::new("")),
1360            span,
1361        });
1362        // Never part of an emitted module: an error means `emit` answers `Err`.
1363        String::new()
1364    }
1365
1366    fn curry(&mut self, function: &str, arity: usize) -> String {
1367        self.runtime.insert("$curry");
1368        format!("$curry({}, {})", function, arity)
1369    }
1370
1371    /// One `module foreign` facade declaration's forwarding code, appended to
1372    /// `functions` or `constants` — a plain function at arity one or more, a `const`
1373    /// at arity zero — plus the companion import it needs, appended to
1374    /// `companion_imports`, and any union predicate its boundary check calls, added to
1375    /// `predicates`. See this module's doc comment, "The boundary check", for what the
1376    /// forwarding code does with the companion's result.
1377    ///
1378    /// A signature marked `unsafe` calls the companion directly. One that is not declares
1379    /// an effect ([An effectful
1380    /// facade](../docs/spec/interop.md#an-effectful-facade)), and its forwarding
1381    /// code is the `Task` this module's *A facade* section describes. A result type no predicate decides
1382    /// pushes [`Error::NoPredicate`] and appends nothing.
1383    fn facade_declaration<'a>(
1384        &mut self,
1385        canonical: &canonical::Module,
1386        declaration: &'a ir::Declaration,
1387        predicates: &mut Predicates,
1388        functions: &mut Vec<String>,
1389        constants: &mut HashMap<&'a Name, String>,
1390        companion_imports: &mut Vec<String>,
1391    ) {
1392        let (signature, marked_unsafe) = match canonical.values.get(&declaration.name) {
1393            Some(Value::TypedValue {
1394                marked_unsafe, tpe, ..
1395            }) => (tpe, *marked_unsafe),
1396            _ => {
1397                self.errors.push(Error::NoSignature {
1398                    name: declaration.name.clone(),
1399                    span: declaration.span,
1400                });
1401                return;
1402            }
1403        };
1404
1405        // What the companion hands back: the signature with the arrows of its own
1406        // parameter list — `arity` of them — taken off the front. For an effect, the
1407        // payload of the `Task (Result Failure a)` that remains.
1408        let result = canonical_result(signature, declaration.arity);
1409        let result = if marked_unsafe {
1410            result
1411        } else {
1412            match canonical::effectful_result_payload(result) {
1413                Some(payload) => payload,
1414                None => {
1415                    self.errors.push(Error::NotAnEffect {
1416                        name: declaration.name.clone(),
1417                        span: declaration.span,
1418                    });
1419                    return;
1420                }
1421            }
1422        };
1423
1424        // The companion's export is imported under an alias — never the plain name,
1425        // which this method is about to declare a local binding under, and a module
1426        // cannot import and declare the same name twice.
1427        let local = mangle(declaration.name.as_str());
1428        let alias = companion_alias(declaration.name.as_str());
1429        let parameters: Vec<String> = (0..declaration.arity).map(field).collect();
1430        let call = format!("{}({})", alias, parameters.join(", "));
1431
1432        // `None` is a `()` result: discarded, so nothing is checked.
1433        let test = if matches!(result, canonical::Type::Unit) {
1434            None
1435        } else {
1436            match predicates.test(result, "$returned", 0, &HashMap::new()) {
1437                Ok(test) => Some(test),
1438                Err(no_predicate) => {
1439                    let (found, constructor) = *no_predicate;
1440                    self.errors.push(Error::NoPredicate {
1441                        name: declaration.name.clone(),
1442                        span: declaration.span,
1443                        found,
1444                        constructor,
1445                    });
1446                    return;
1447                }
1448            }
1449        };
1450
1451        companion_imports.push(format!("{} as {}", declaration.name.as_str(), alias));
1452
1453        if !marked_unsafe {
1454            let export = format!(
1455                "{}.{}",
1456                self.module.name().as_str(),
1457                declaration.name.as_str()
1458            );
1459            self.runtime.insert("$effect");
1460            let check = match &test {
1461                Some(test) => format!("($returned) => {}", test),
1462                None => "null".to_string(),
1463            };
1464            let task = format!(
1465                "{{$: \"Task\", a: ($k) => $effect(() => {}, {}, {}, $k)}}",
1466                call,
1467                check,
1468                string_literal(&export)
1469            );
1470            if declaration.arity == 0 {
1471                constants.insert(&declaration.name, format!("const {} = {};", local, task));
1472            } else {
1473                functions.push(format!(
1474                    "function {}({}) {{\n  return {};\n}}",
1475                    local,
1476                    parameters.join(", "),
1477                    task
1478                ));
1479            }
1480            return;
1481        }
1482
1483        let Some(test) = test else {
1484            if declaration.arity == 0 {
1485                constants.insert(&declaration.name, format!("const {} = undefined;", local));
1486            } else {
1487                functions.push(format!(
1488                    "function {}({}) {{\n  {};\n  return undefined;\n}}",
1489                    local,
1490                    parameters.join(", "),
1491                    call
1492                ));
1493            }
1494            return;
1495        };
1496
1497        self.runtime.insert("$abort");
1498        let description = string_literal(&format!(
1499            "`{}.{}`'s companion returned a value its declared type, `{}`, does not admit",
1500            self.module.name().as_str(),
1501            declaration.name.as_str(),
1502            typer_result(&declaration.tpe, declaration.arity)
1503        ));
1504        let checked = format!("{} ? $returned : $abort({})", test, description);
1505
1506        if declaration.arity == 0 {
1507            constants.insert(
1508                &declaration.name,
1509                format!("const {} = (($returned) => {})({});", local, checked, alias),
1510            );
1511        } else {
1512            functions.push(format!(
1513                "function {}({}) {{\n  const $returned = {};\n  return {};\n}}",
1514                local,
1515                parameters.join(", "),
1516                call,
1517                checked
1518            ));
1519        }
1520    }

1522    fn expression(&mut self, term: &TypedTerm) -> String {
1523        match &term.kind {
1524            TypedTermKind::Int(i) => format!("{}n", i),
1525            TypedTermKind::Float(f) => float_literal(*f),
1526            TypedTermKind::Char(c) => char_literal(*c),
1527            TypedTermKind::String(s) => string_literal(s),
1528            TypedTermKind::Identifier(reference) => self.value(&reference.name, &reference.kind),
1529            TypedTermKind::Apply { .. } => self.application(term),
1530            TypedTermKind::If {
1531                cond,
1532                true_branch,
1533                false_branch,
1534            } => {
1535                let cond = self.operand(cond);
1536                let true_branch = self.expression(true_branch);
1537                let false_branch = self.expression(false_branch);
1538                format!("{} ? {} : {}", cond, true_branch, false_branch)
1539            }
1540            TypedTermKind::Tuple(tuple) => {
1541                let elements: Vec<String> = tuple
1542                    .iter()
1543                    .map(|element| self.expression(element))
1544                    .collect();
1545                format!("[{}]", elements.join(", "))
1546            }
1547            TypedTermKind::Case {
1548                scrutinee,
1549                branches,
1550                form,
1551            } => self.case_expression(scrutinee, branches, *form),
1552            TypedTermKind::Unit => "undefined".to_string(),
1553            TypedTermKind::Let { .. } => self.unsupported(Construct::Let, term.span),
1554            TypedTermKind::Fun { .. } => self.unsupported(Construct::Lambda, term.span),
1555            TypedTermKind::Hole => self.unsupported(Construct::Hole, term.span),
1556        }
1557    }

1559    /// An expression in a position where a conditional has to be parenthesised: the
1560    /// condition of another conditional, and the function of a call.
1561    fn operand(&mut self, term: &TypedTerm) -> String {
1562        let text = self.expression(term);
1563        match term.kind {
1564            TypedTermKind::If { .. } => format!("({})", text),
1565            _ => text,
1566        }
1567    }

1569    /// A name used as a value rather than called.
1570    fn value(&mut self, name: &str, kind: &ReferenceKind) -> String {
1571        match kind {
1572            ReferenceKind::Local => mangle(name),
1573            ReferenceKind::TopLevel(qname) => {
1574                let unqualified = qname.unqualified_name();
1575                let local = mangle(unqualified.as_str());
1576                match self.arities.get(&unqualified).copied() {
1577                    Some(arity) if arity >= 2 => self.curry(&local, arity),
1578                    _ => local,
1579                }
1580            }
1581            ReferenceKind::Foreign(qname, package, arity) => {
1582                let local = self.import(qname, package);
1583                if *arity >= 2 {
1584                    self.curry(&local, *arity)
1585                } else {
1586                    local
1587                }
1588            }
1589            ReferenceKind::Constructor(ctor) => {
1590                if scalars::BOOL.declares(&ctor.union) {
1591                    match ctor.name.as_str() {
1592                        "True" => return "true".to_string(),
1593                        "False" => return "false".to_string(),
1594                        _ => {}
1595                    }
1596                }
1597
1598                match ctor.arity {
1599                    0 => {
1600                        let local = hoisted(&ctor.union, &ctor.name);
1601                        // Compares the full identity field-wise instead of allocating a
1602                        // throwaway `ModuleName` just to compare it against `self.module`.
1603                        let declared_here = *ctor.union.package() == *self.module.package()
1604                            && ctor.union.module_name() == *self.module.name();
1605                        if !declared_here {
1606                            self.imported_constructors
1607                                .insert(local.clone(), ctor.name.clone());
1608                        }
1609                        local
1610                    }
1611                    arity => {
1612                        let parameters: Vec<String> = (0..arity).map(field).collect();
1613                        let function = format!(
1614                            "({}) => ({})",
1615                            parameters.join(", "),
1616                            tagged(&ctor.name, parameters.clone())
1617                        );
1618                        if arity >= 2 {
1619                            self.curry(&function, arity)
1620                        } else {
1621                            function
1622                        }
1623                    }
1624                }
1625            }
1626        }
1627    }

1629    /// The local name the value `qname` of another module is imported under, recording
1630    /// the import so the module's import section names it.
1631    fn import(&mut self, qname: &QualName, package: &PackageName) -> String {
1632        let module = qname.module_name().as_str().to_string();
1633        let name = qname.unqualified_name().as_str().to_string();
1634        let local = imported(package.as_str(), &module, &name);
1635        self.imports
1636            .entry((package.as_str().to_string(), module))
1637            .or_default()
1638            .insert(name);
1639        local
1640    }

1642    /// An application spine: a direct call up to the node the IR marks saturated, if
1643    /// there is one, then one call per remaining argument.
1644    fn application(&mut self, term: &TypedTerm) -> String {
1645        let mut arguments = Vec::new();
1646        let mut head = term;
1647        while let TypedTermKind::Apply {
1648            fun,
1649            arg,
1650            saturation,
1651        } = &head.kind
1652        {
1653            arguments.push((arg.as_ref(), *saturation));
1654            head = fun;
1655        }
1656        arguments.reverse();
1657
1658        let saturated = arguments
1659            .iter()
1660            .position(|(_, saturation)| *saturation == Saturation::Saturated);
1661
1662        // Evaluated in the order written: the function, then each argument.
1663        let (mut callee, rest) = match (&head.kind, saturated) {
1664            (TypedTermKind::Identifier(reference), Some(last)) => match &reference.kind {
1665                ReferenceKind::TopLevel(qname) => {
1666                    let supplied = self.arguments(&arguments[..=last]);
1667                    (
1668                        format!(
1669                            "{}({})",
1670                            mangle(qname.unqualified_name().as_str()),
1671                            supplied.join(", ")
1672                        ),
1673                        &arguments[last + 1..],
1674                    )
1675                }
1676                ReferenceKind::Foreign(qname, package, _) => {
1677                    let local = self.import(qname, package);
1678                    let supplied = self.arguments(&arguments[..=last]);
1679                    (
1680                        format!("{}({})", local, supplied.join(", ")),
1681                        &arguments[last + 1..],
1682                    )
1683                }
1684                ReferenceKind::Constructor(ctor) => {
1685                    let supplied = self.arguments(&arguments[..=last]);
1686                    let fields: Vec<String> = supplied;
1687                    (tagged(&ctor.name, fields), &arguments[last + 1..])
1688                }
1689                _ => (self.operand(head), &arguments[..]),
1690            },
1691            _ => (self.operand(head), &arguments[..]),
1692        };
1693
1694        for (argument, _) in rest {
1695            let argument = self.expression(argument);
1696            callee = format!("{}({})", callee, argument);
1697        }
1698
1699        callee
1700    }

1704            .iter()
1705            .map(|(argument, _)| self.expression(argument))

1709    /// A `case … of`, or a parameter written as a pattern — the IR's single-branch
1710    /// match on it ([`ir::CaseForm::Parameter`]), which lowers and emits the same way.
1711    /// See this module's doc comment, "A `case`", for the shape.
1712    ///
1713    /// `scrutinee` is evaluated exactly once — bound to `$scrutinee` before the tree is
1714    /// walked — never once per test, which is what a decision tree built by
1715    /// [`decision_tree`] wants: [Order of
1716    /// evaluation](../docs/spec/evaluation-semantics.md#order-of-evaluation).
1717    ///
1718    /// `form` says whether the source wrote a `case … of` or a parameter pattern
1719    /// ([`ir::CaseForm`]) and reaches [`abort_description`] unchanged, so a
1720    /// [`Decision::Fail`] this tree needs describes itself in the vocabulary the source
1721    /// actually used.
1722    ///
1723    /// Mutation-checked by re-emitting `self.expression(scrutinee)` at every
1724    /// [`Decision::Test`] instead of binding it once: a `case` whose scrutinee is a call
1725    /// then contains that call's text more than once.
1726    fn case_expression(
1727        &mut self,
1728        scrutinee: &TypedTerm,
1729        branches: &[(ir::TermPattern, Box<TypedTerm>)],
1730        form: CaseForm,
1731    ) -> String {
1732        // A constructor that did not resolve has no case to test for, so the tree is not
1733        // built at all.
1734        if let Some(hole) = branches
1735            .iter()
1736            .find_map(|(pattern, _)| pattern_hole(pattern))
1737        {
1738            return self.unsupported(Construct::Hole, hole);
1739        }
1740
1741        let declaration = self.declaration.clone().unwrap_or_else(|| Name::new(""));
1742        let tree = decision_tree(&scrutinee.tpe, branches, &declaration);
1743        let scrutinee_expr = self.expression(scrutinee);
1744        let body = self.decision(&tree, "$scrutinee", 1, form);
1745
1746        format!(
1747            "(() => {{\n  const $scrutinee = {};\n{}\n}})()",
1748            scrutinee_expr, body
1749        )
1750    }
1751
1752    /// One [`Decision`] node as the statements of an `if`/`else` chain, each line
1753    /// indented `depth` levels of two spaces — the body of [`case_expression`]'s
1754    /// immediately invoked function. `root` is the name the scrutinee is bound to,
1755    /// which [`occurrence_expr`] reads a test's or a binding's value off; `form` is
1756    /// passed through unchanged to [`abort_description`].
1757    ///
1758    /// A [`Decision::Test`] nests: its `matched` and `default` are each a full
1759    /// [`Decision`] emitted one level deeper, so a chain of tests on the scrutinee comes
1760    /// out as `if`s nested in one another's `else`, never merged or reordered — the
1761    /// order [Conditional
1762    /// evaluation](../docs/spec/evaluation-semantics.md#conditional-evaluation)
1763    /// tries branches in. A [`Decision::Leaf`] declares its bindings as `const`s, each
1764    /// read off `root` by [`occurrence_expr`], ahead of a `return` of its body — all of
1765    /// it inside its own block, so a binding never shares a scope with the
1766    /// `$scrutinee` line above it. Sharing that scope is observable: a binding may name
1767    /// anything the pattern it comes from could ([Variable
1768    /// patterns](../docs/spec/patterns.md#variable-patterns) lets one repeat a
1769    /// name already in scope), and a `const` anywhere in a block puts every reference to
1770    /// that name earlier in the *same* block in its temporal dead zone — so without the
1771    /// leaf's own block, a scrutinee expression that happens to read a name a leaf also
1772    /// binds would throw `ReferenceError` before ever reaching the leaf. A
1773    /// [`Decision::Fail`] returns the runtime's `$abort`, importing it the way `$curry`
1774    /// is imported; it carries no binding, so it needs no block of its own.
1775    fn decision(&mut self, tree: &Decision, root: &str, depth: usize, form: CaseForm) -> String {
1776        let pad = "  ".repeat(depth);
1777
1778        match tree {
1779            Decision::Test {
1780                scrutinee,
1781                outcome,
1782                matched,
1783                default,
1784            } => {
1785                let condition = test_condition(root, scrutinee, outcome);
1786                let matched = self.decision(matched, root, depth + 1, form);
1787                let default = self.decision(default, root, depth + 1, form);
1788                format!(
1789                    "{pad}if ({condition}) {{\n{matched}\n{pad}}} else {{\n{default}\n{pad}}}",
1790                    pad = pad,
1791                    condition = condition,
1792                    matched = matched,
1793                    default = default,
1794                )
1795            }
1796            Decision::Leaf { bindings, body } => {
1797                let inner_pad = "  ".repeat(depth + 1);
1798                let mut lines: Vec<String> = bindings
1799                    .iter()
1800                    .map(|binding| {
1801                        format!(
1802                            "{}const {} = {};",
1803                            inner_pad,
1804                            mangle(&binding.name),
1805                            occurrence_expr(root, &binding.occurrence)
1806                        )
1807                    })
1808                    .collect();
1809                lines.push(format!("{}return {};", inner_pad, self.expression(body)));
1810                format!("{pad}{{\n{}\n{pad}}}", lines.join("\n"), pad = pad)
1811            }
1812            Decision::Fail { declaration } => {
1813                self.runtime.insert("$abort");
1814                format!(
1815                    "{}return $abort({});",
1816                    pad,
1817                    abort_description(declaration, form)
1818                )
1819            }
1820        }
1821    }
1822}

1824/// The condition a [`Decision::Test`] compiles to: an equality check against the value
1825/// [`occurrence_expr`] reads off `root`. A constructor is tested by its `$` field — a
1826/// `Bool`'s constructors never reach here, since `typer::translate_pattern` turns
1827/// `True`/`False` into an [`Outcome::Literal`] — and a literal by the value itself,
1828/// which is also how a `case` on a `Bool` tests it (see this module's doc comment,
1829/// "Representations").
1830fn test_condition(root: &str, occurrence: &Occurrence, outcome: &Outcome) -> String {
1831    let value = occurrence_expr(root, occurrence);
1832
1833    match outcome {
1834        Outcome::Literal(LiteralValue::Bool(b)) => format!("{} === {}", value, b),
1835        Outcome::Literal(LiteralValue::Int(i)) => format!("{} === {}n", value, i),
1836        Outcome::Literal(LiteralValue::Char(c)) => format!("{} === {}", value, char_literal(*c)),
1837        Outcome::Constructor(ctor) => format!("{}.$ === \"{}\"", value, ctor.name.as_str()),
1838    }
1839}

1841/// The JavaScript expression reading the value at `occurrence` off `root`, the name the
1842/// scrutinee is bound to: a constructor argument is a field ([`field`], the same one
1843/// [`tagged`] builds an object under), a tuple element an index — the representations
1844/// [A union crosses as a tagged
1845/// value](../docs/spec/interop.md#a-union-crosses-as-a-tagged-value) gives them.
1846fn occurrence_expr(root: &str, occurrence: &Occurrence) -> String {
1847    match occurrence {
1848        Occurrence::Root => root.to_string(),
1849        Occurrence::At(base, step) => {
1850            let base = occurrence_expr(root, base);
1851            match step {
1852                Step::ConstructorArgument(index) => format!("{}.{}", base, field(*index)),
1853                Step::TupleElement(index) => format!("{}[{}]", base, index),
1854            }
1855        }
1856    }
1857}

1859/// The description a [`Decision::Fail`]'s `$abort` call carries: which declaration's
1860/// `case` — or, for [`CaseForm::Parameter`], parameter pattern — matched no branch. That
1861/// leaf exists only because [coverage is not checked
1862/// yet](../docs/spec/evaluation-semantics.md#two-outcomes) (`LANG-19`) — reaching
1863/// it aborts rather than falling through to `undefined`. `form` keeps the message in the
1864/// vocabulary the source actually used: a parameter written as a pattern has no `case`
1865/// for the message to name.
1866fn abort_description(declaration: &Name, form: CaseForm) -> String {
1867    match form {
1868        CaseForm::Expression => {
1869            format!("\"`{}`'s case matched no branch\"", declaration.as_str())
1870        }
1871        CaseForm::Parameter => format!(
1872            "\"`{}`'s parameter pattern matched no branch\"",
1873            declaration.as_str()
1874        ),
1875    }
1876}

1878/// Where `pattern` holds an [`ir::TermPatternKind::Hole`], at any depth, when it holds
1879/// one: the outermost, leftmost one's span.
1880fn pattern_hole(pattern: &ir::TermPattern) -> Option<NodeSpan> {
1881    match &pattern.kind {
1882        ir::TermPatternKind::Hole { .. } => Some(pattern.span),
1883        ir::TermPatternKind::Constructor { args, .. } => {
1884            args.iter().find_map(|arg| pattern_hole(&arg.pattern))
1885        }
1886        ir::TermPatternKind::Tuple { elements } => elements
1887            .iter()
1888            .find_map(|element| pattern_hole(&element.pattern)),
1889        ir::TermPatternKind::Anything
1890        | ir::TermPatternKind::Bind(_)
1891        | ir::TermPatternKind::Literal { .. }
1892        | ir::TermPatternKind::Unit => None,
1893    }
1894}

1896/// The tagged object a constructor builds, each argument in the field [`field`] names
1897/// for its position.
1898fn tagged(name: &Name, arguments: Vec<String>) -> String {
1899    let mut fields = vec![format!("$: \"{}\"", name.as_str())];
1900    fields.extend(
1901        arguments
1902            .into_iter()
1903            .enumerate()
1904            .map(|(index, argument)| format!("{}: {}", field(index), argument)),
1905    );
1906    format!("{{{}}}", fields.join(", "))
1907}
