1//! The JavaScript backend: one checked module in, the text of one ES module out.
2//!
3//! [`emit`] reads the [`ir::Module`] a [`CheckedModule`] carries, beside the
4//! [`canonical::Module`] it was built from for the one thing the IR does not hold — which
5//! names the module exports. It produces text and writes nothing: `compile_package` writes
6//! it, to the path [`module_file`] gives, once the whole build has checked and emitted.
7//!
8//! # The shape of an emitted module
9//!
10//! In this order, each section separated from the next by a blank line and left out when
11//! it is empty:
12//!
13//! 1. **Imports** — the runtime helpers the module calls, from the runtime module
14//!    ([`RUNTIME`]), then its companion's exports for a facade, then one named import per
15//!    value another module declares, from that module's package.
16//! 2. **Hoisted constructors** — one `const` per constructor of no arguments this module
17//!    declares, then one per such constructor of another module's that it mentions, which
18//!    every mention of it refers to ([`DEC-18` decision
19//!    4](../docs/decisions/dec-18.md#4--a-constructor-of-no-arguments-is-hoisted-to-one-module-level-constant)).
20//! 3. **Functions** — in a facade, first the union predicates its boundary checks call
21//!    ([*The boundary check*](#the-boundary-check)), in name order; then one `function`
22//!    per declaration that takes parameters, with exactly as many JavaScript parameters
23//!    as it was written with ([`DEC-18` decision
24//!    3](../docs/decisions/dec-18.md#3--a-function-emits-as-a-plain-n-ary-function-and-currying-is-a-runtime-helper)),
25//!    then the same for each member of an instance and each specialisation
26//!    ([*Classes, instances and specialisations*](#classes-instances-and-specialisations)).
27//!    A declaration whose annotation has a constraint has none.
28//! 4. **Parameterless bindings** — one `const` each, in
29//!    [`ir::initialisation_items`]: the declarations in
30//!    [`ir::Module::initialisation_order`], the members of an instance that take no
31//!    parameter and the specialisations that take none among them, so that each is
32//!    initialised after every other one it depends on — the ones it mentions, and the ones a
33//!    function it mentions reaches — and no `const` is read before it is initialised.
34//! 5. **Exports** — one `export { … }`, in two runs each in name order. The first is
35//!    each value the module has to export, by its Zelkova name: what the `exposing` header
36//!    names, and what a copy of the module's code placed in another module mentions
37//!    ([*Exports*](#exports)). The second is the function of each instance member the
38//!    module declares.
39//!
40//! # Exports
41//!
42//! `exposing` is a rule about what another module's *source* may write, and canonicalization
43//! holds every module to it, whatever the emitted `export` lists. What that list holds is a
44//! JavaScript matter: it is what the header exposes, each instance member, and whatever a
45//! constrained declaration, an instance binding or a derivation's binding of the module
46//! mentions at top level ([`ir::mentioned_by_copies`]). A copy of such a body is placed in
47//! the module that uses it, which imports what it names from here, and a name the header does
48//! not expose has to be exported all the same for that import to link. A derivation's bindings
49//! are placed in the members of the instances that derive them, so they are among the bindings
50//! the rule reads. A constrained declaration has no function under its own name and is never
51//! exported, whatever the header says.
52//!
53//! # Classes, instances and specialisations
54//!
55//! A class has no code: its members are not values of any module, and every use of one is
56//! resolved to a function by [`ir::specialise`], which the caller runs over every module of the
57//! build before any is emitted. No dictionary is built or passed
58//! ([`DEC-2` decision 7](../docs/decisions/dec-2.md#7--dictionaries-are-erased-by-specialisation-not-passed)).
59//!
60//! - **An instance's member** is an ordinary function of the module that declares the
61//!   instance, emitted once, as a `const` when it takes no parameter, and exported. Its name
62//!   is built from the class, the head and the member and cannot be a name a source file
63//!   writes: `$instance$`, then the class's package, module segments and name, then the
64//!   head — a declared type written the same way, or `tuple2`, `tuple3` or `unit` — then the
65//!   member, joined by `$` (`instance_member_name`). A use of a member at a type whose
66//!   instance has no context is a direct reference to it, imported under that name from the
67//!   instance's module where that is another.
68//! - **A specialisation** is a function of the module that uses it, `$spec$`, its place in
69//!   [`ir::Module::specialisations`] and the declaration's name — `$spec$0$min`
70//!   (`specialisation_name`). It is emitted into the using module and not into the one that
71//!   declares the function, because the instance it calls may be declared by a module that
72//!   imports that one, and `Basics` could not import `App`. An instance with a context has
73//!   members that are specialised like any other function.
74//!
75//! The call rule does not change. A specialisation has the arity its declaration was written
76//! with, a saturated call of it is a direct call, and one used as a value is `$curry`'d; an
77//! instance's member is called the same way, at the arity its binding was written with.
78//!
79//! **Two modules that use one key each carry a copy.** For a function that is code written
80//! twice and nothing a program can observe. For a constrained binding with no parameters it is
81//! one evaluation for each module that uses it, where [the chapter says
82//! "once"](../docs/spec/evaluation-semantics.md#a-binding-with-no-parameters-is-evaluated-once);
83//! a Zelkova value has no identity, so what differs is the work done and never an answer. A
84//! reading of that promise that covers it is a `SPEC-` ticket to file and not a design to
85//! change here.
86//!
87//! # Representations
88//!
89//! An `Int` literal is a `BigInt` (`1n`), since [`Int` is 64
90//! bits](../docs/spec/evaluation-semantics.md#numbers); a `Float` is a number, a
91//! `Char` a one-character string and a `String` a string. `True` and `False` — the
92//! constructors of [`scalars::BOOL`], recognised by the union's qualified name — are
93//! `true` and `false`.
94//! `()` is `undefined` ([The unit value crosses as
95//! `undefined`](../docs/spec/interop.md#the-unit-value-crosses-as-undefined)) and a
96//! pattern that names it, at any depth, tests nothing and binds nothing — `undefined`
97//! among `RESERVED` is what keeps a Zelkova binding of that name from changing what a `()`
98//! in its scope reads as. Every other union value is `{$: "Ctor", a: …, b: …}`, arguments
99//! in declaration order ([A union crosses as a tagged
100//! value](../docs/spec/interop.md#a-union-crosses-as-a-tagged-value)); a
101//! constructor's arguments past the 26th continue `aa`, `ab`, … — see `field`. A tuple
102//! is an array.
103//!
104//! **A record is a plain object keyed by its labels and by nothing else**: `{ x = 1, y = 2 }`
105//! is `{x: 1n, y: 2n}`, with no `$` to tell it from a union value — a label is never `$`,
106//! and a record is never read by `$`. The key is the label as the source spells it. A label
107//! is not a binding, so `mangle` never touches it: `{ new = 1 }` is `{new: 1n}` and
108//! `r.new` reads it, `constructor` and `toString` are the record's own fields where
109//! every object inherits a property of that name, and a label that is not a bare ASCII
110//! identifier is a string-literal key, `r["é"]` (see `property` and `key`). The
111//! fields stand in the order they were written, which is the order they are evaluated in
112//! ([Order of evaluation](../docs/spec/evaluation-semantics.md#order-of-evaluation)): an
113//! object literal evaluates its entries as they stand.
114//!
115//! - A **field access** is a property read, `r.name`, and chains as one: `r.centre.x`.
116//! - An **accessor** is a function of one parameter, `(r) => r.name`, called one argument at
117//!   a time like any function value, so [*Calls*](#calls) needs no rule of its own for it;
118//!   as the function of a call it is parenthesised.
119//! - An **update** is an object literal that begins by spreading the record updated and
120//!   continues with the fields written, `{...r, x: 1n}`. The record is evaluated once, ahead
121//!   of every field, and the spread copies its own enumerable properties into a new
122//!   object, so the one it was copied from is never written to. A record the emitter built
123//!   has only enumerable own properties, and one a companion returned has been checked to
124//!   have them for each label ([*The boundary check*](#the-boundary-check)). A label the
125//!   update names replaces the copied one.
126//! - A **record pattern** tests nothing of its own: a record has one shape, so
127//!   [`ir::decision_tree`] holds a test for an entry's sub-pattern only, and reaches it by
128//!   a [`Step::Field`], which `occurrence_expr` writes as the same property read an access
129//!   is.
130//!
131//! [Equality is structural](../docs/spec/evaluation-semantics.md#what-structural-equality-computes),
132//! and `==` is `Eq`'s member, which a derived instance computes by walking a union's
133//! arguments and a tuple's elements. A record has no instance yet, so `ir::specialise`
134//! refuses an `Eq` obligation at one and no `==` over a record is emitted
135//! ([`LANG-85`](../docs/tickets/lang-85.md)).
136//!
137//! A constructor is not exported. An importer that builds one builds its own object of
138//! the same shape, and hoists its own constant for one of no arguments. [Equality is
139//! structural](../docs/spec/evaluation-semantics.md#what-structural-equality-computes),
140//! so nothing observes which module allocated it.
141//!
142//! # Calls
143//!
144//! An application whose IR node is [`Saturation::Saturated`] is a direct call,
145//! `f(a, b)`, or for a constructor the object itself. Every other application calls a
146//! *function value*, one argument per JavaScript call: `g(a)(b)`. What makes that
147//! correct is that every function value the emitted code hands around accepts being
148//! called one argument at a time. A declaration of two or more parameters — this
149//! module's or another's — and a constructor of two or more arguments, is `$curry(f, n)`
150//! wherever it is used as a value rather than called, so a partial application such as
151//! `pick 1` is `$curry(pick, 2)(1n)`; a one-parameter function already takes its
152//! argument one at a time.
153//!
154//! A value another module declares is called the same way as one of this module's
155//! ([`ir::ReferenceKind::Foreign`] carries its arity). A module exports each declaration
156//! as it emitted it — a declaration with parameters as the plain n-ary `function`, a
157//! parameterless binding as its `const` — and its [`Interface`](zelkova_compiler::Interface)
158//! records how many parameters each takes, so an importer's `Lib.pick a b` is a direct
159//! call of its import, `app$Lib$pick(a, b)`, as `pick a b` is inside `Lib`. A
160//! parameterless binding has arity 0 and is called one argument at a time wherever it
161//! is called, which is why a binding whose value is a function of two or more
162//! parameters, such as `Basics`' `add = Js.Basics.addInt`, holds that function
163//! `$curry`'d.
164//!
165//! One argument per call is also what keeps the [order of
166//! evaluation](../docs/spec/evaluation-semantics.md#order-of-evaluation): `g a b`
167//! applies `g a` before it evaluates `b`, and `g(a)(b)` does too where `g(a, b)` would
168//! not. Nothing here reorders a subexpression, and [nothing
169//! short-circuits](../docs/spec/evaluation-semantics.md#nothing-short-circuits):
170//! `&&` and `||` reach this module as ordinary applications of the functions their
171//! `infix` declarations name, so they are emitted as calls, never as JavaScript's own
172//! operators.
173//!
174//! # A facade
175//!
176//! [`emit`] answers a module for a `module foreign` facade too, so that an importer
177//! needs no special case. Every [`unsafe`](../docs/spec/interop.md#an-unsafe-facade)
178//! declaration becomes forwarding code that imports the companion's export under an
179//! alias and calls it with exactly the parameters the signature's arrow count gives —
180//! a plain function at arity one or more, a `const` at arity zero — the same
181//! [plain-parameter-list promise](../docs/spec/interop.md#the-javascript-companion)
182//! an ordinary declaration's call already keeps. [`Error::MissingCompanion`] is
183//! answered instead when the caller says no companion sits beside this module for the
184//! target being built ([*A facade names a boundary, not a
185//! backend*](../docs/spec/interop.md#a-facade-names-a-boundary-not-a-backend)) —
186//! [`emit`] has no path of its own to check that with, so the caller decides.
187//!
188//! A signature not marked `unsafe` declares an effect
189//! ([An effectful facade](../docs/spec/interop.md#an-effectful-facade)), and its
190//! forwarding code builds a `Task` instead of calling the companion: the `Task`'s run
191//! function calls the runtime's `$effect` with a function that calls the companion, the
192//! predicate of the payload type `a` of the signature's `Task (Result Failure a)` (`null`
193//! for a `()` payload, which is discarded), the export's name and the continuation it was
194//! handed. The companion is therefore called when the `Task` is run, never when it is built,
195//! and `$effect` is what catches a throw or a rejection as `Err (Threw ..)` and turns a
196//! value that fails the predicate into `Err (Malformed ..)`
197//! ([DEC-22 decision 4](../docs/decisions/dec-22.md#4--the-wrapper-is-one-runtime-helper-and-a-synchronous-companion-continues-synchronously)).
198//! The emitted text builds the `Task` as `{$: "Task", a: ($k) => $effect(..)}` and knows
199//! nothing of `Done`. A facade constant naming a `Task` gets the same `Task`, as one
200//! module-level `const`, and its companion export is called with no arguments each time the
201//! `Task` is run ([DEC-22 decision
202//! 7](../docs/decisions/dec-22.md#7--a-facade-constant-naming-a-task-gets-the-same-wrapper-with-no-arguments)).
203//!
204//! The companion is imported from [`companion_file`], beside the facade's own emitted
205//! file and renamed so that the two do not share one path.
206//!
207//! # The boundary check
208//!
209//! A value a companion hands back is run through the predicate of the type its signature
210//! declares ([Which types may cross the
211//! boundary](../docs/spec/interop.md#which-types-may-cross-the-boundary)): the
212//! forwarding code binds the companion's result to `$returned` and returns it unchanged
213//! when the predicate holds, and calls the runtime's `$abort` otherwise, naming the
214//! export — module and value — whose companion returned it ([When a program
215//! aborts](../docs/spec/evaluation-semantics.md#when-a-program-aborts)). An
216//! effectful facade's `$effect` runs the same predicate over the payload and routes a
217//! failure to `Err (Malformed ..)` where this check aborts.
218//!
219//! **Only the result is checked.** An argument on its way out to the companion is a
220//! Zelkova value the type checker already proved to be of its declared type, so nothing
221//! is run over it.
222//!
223//! **A result of `()` is discarded, not checked**: the companion is called, and the
224//! forwarding code returns `undefined` whatever it answered ([The unit value crosses as
225//! `undefined`](../docs/spec/interop.md#the-unit-value-crosses-as-undefined)). A
226//! facade constant of type `()` is `undefined`, its export still imported so that a
227//! companion missing it fails to link.
228//!
229//! Every other admitted type is decided by an expression over the value, built by
230//! `Predicates::test`: a scalar by its `typeof` — an `Int` also by `BigInt.asIntN(64, v)
231//! === v`, which holds exactly for a `bigint` the 64-bit range holds, and a `Char` by
232//! being a string of exactly one code point — a tuple as an array of its length whose
233//! elements each pass, and a `()` nested anywhere as `v === undefined`. A union is
234//! decided by a function of its own, `$is$<package>$<module>$<union>` (see `predicate`),
235//! emitted into the facade that needs it: it reads `$` against the declaration's
236//! constructors and checks each argument against the type that constructor declares for
237//! it, and it takes one predicate per type variable of the union, so `Maybe Int` is
238//! `$is$…$Maybe(v, ($v0) => …)`. A recursive union's function calls itself, which
239//! terminates because a Zelkova value holds no cycle; the walk costs the size of the
240//! value at every crossing.
241//!
242//! A record is decided by what it has and by what it has not: an object that is not an
243//! array and not `null`, whose own keys are the record's labels and no others, each
244//! field passing the predicate of its own type. "No others" is `Reflect.ownKeys(v).length`
245//! — which counts symbol keys and non-enumerable properties as well as the enumerable
246//! strings `Object.keys` lists — equal to the number of labels, and each label is then
247//! found by `Object.hasOwn`, which looks at the value's own properties and so never finds
248//! the `toString` every object inherits. `Object.keys(v).length` is asked to equal the
249//! number of labels too, so every label is an enumerable own property: the update's
250//! spread copies only those. A field of type `()` is present, holding
251//! `undefined`: `Object.hasOwn` is what tells it from one that is missing, which
252//! `v.f === undefined` could not ([`DEC-21`](../docs/decisions/dec-21.md)). Nothing else
253//! is asked of the object: one with a prototype of its own or one that is frozen is
254//! admitted when its own keys are right. A field's value is read where it is tested and
255//! again where the program reads it, so a getter or a `Proxy` that answers differently
256//! the second time is admitted all the same: the predicate decides the value it saw, not
257//! that a property keeps it. Fields are tested in label order, the order
258//! `canonical::Type::Record` holds them in.
259//!
260//! The declaration a union predicate is read off is the one its declaring module
261//! canonicalized — every constructor of it, whether or not the module exposes them —
262//! which is why [`emit`] is handed [`Unions`], every union of the build, rather than
263//! reading the facade's imports: an importer's view of an opaque type has no
264//! constructors. A result type with no predicate at all is [`Error::NoPredicate`].
265//!
266//! # A `case`
267//!
268//! [`ir::decision_tree`] turns a `case`'s branches — and a parameter written as a
269//! pattern, which the IR holds as a single-branch match on it
270//! ([`ir::CaseForm::Parameter`]) and which reaches `Emitter::case_expression` the
271//! same way — into the [`Decision`] tree a backend walks instead of re-deriving which
272//! test distinguishes which branch. `Emitter::case_expression` binds the scrutinee to
273//! `$scrutinee` once, since the tree tests it more than once and re-evaluating it per
274//! test would evaluate it once per test — observable through non-termination ([Order of
275//! evaluation](../docs/spec/evaluation-semantics.md#order-of-evaluation)) — and
276//! walks the tree into an `if`/`else` chain inside an immediately invoked function,
277//! since a `case` is an expression and JavaScript's `if` is a statement. A
278//! [`Decision::Test`] becomes an `if` on the value `occurrence_expr` reads off
279//! `$scrutinee`: `.$ === "Ctor"` for a constructor, an equality check for a literal;
280//! the value it reads is `.a` for a constructor's argument, `[0]` for a tuple's element and
281//! `.label` for a record's field, and a record pattern is no test of its own. A
282//! [`Decision::Leaf`] declares its bindings as `const`s ahead of a `return`, all of it
283//! inside its own block — a binding may repeat a name the scrutinee expression reads
284//! ([Variable patterns](../docs/spec/patterns.md#variable-patterns)), and without
285//! that block the two would share a scope, putting the earlier read in the later
286//! binding's temporal dead zone. A [`Decision::Fail`] — the fall-through a `case`
287//! missing a branch reaches, because [coverage is not checked
288//! yet](../docs/spec/evaluation-semantics.md#two-outcomes) — calls the runtime's
289//! `$abort`, naming the declaration the `case` was written in and, for a parameter
290//! written as a pattern, saying so rather than naming a `case` the source never wrote.
291//!
292//! # What is refused
293//!
294//! [`emit`] answers an [`Error`] rather than a module missing a part: for a declaration
295//! with no IR ([`ir::Module::unchecked`]), for a facade declaration with no type signature,
296//! for a facade signature not marked `unsafe` whose result is not `Task (Result Failure a)`,
297//! for a facade with no companion for the target being built, for a facade result no
298//! predicate can decide, for an instance the type checker rejected ([`Error::RejectedInstance`]),
299//! for a reference that still asks for an instance because [`ir::specialise`] did not
300//! resolve it ([`Error::Unspecialised`]), and for a construct it does not emit
301//! ([`Construct`]), a name that did not resolve among them. A class is not refused: it has no
302//! code. Neither is a constrained declaration, which is emitted where it is specialised.

323/// Why a module could not be emitted.
324#[derive(Debug, Clone, PartialEq)]
325pub enum Error {
326    /// A `module foreign` facade with no companion for the target being built
327    /// ([*A facade names a boundary, not a
328    /// backend*](../docs/spec/interop.md#a-facade-names-a-boundary-not-a-backend)).
329    ///
330    /// [`emit`] has no path of its own to check a companion's presence on disk with —
331    /// its caller does, and says so through [`emit`]'s `has_companion` parameter.
332    MissingCompanion { module: Name, target: &'static str },
333    /// A facade signature not marked `unsafe` whose result type is not `Task (Result
334    /// Failure a)`, so there is no payload for the wrapper to check
335    /// ([An effectful facade](../docs/spec/interop.md#an-effectful-facade)).
336    /// Canonicalization refuses such a signature first
337    /// (`canonical::Error::FacadeResultNotEffect`); this is what is left if one reaches
338    /// the backend anyway.
339    NotAnEffect { name: Name, span: NodeSpan },
340    /// A facade declaration the canonical module holds no type signature for, so there
341    /// is no result type to build a wrapper or a boundary check from. Canonicalization
342    /// refuses an unannotated facade declaration first; this is what is left if one
343    /// reaches the backend anyway.
344    NoSignature { name: Name, span: NodeSpan },
345    /// A declaration the typer could not check has no IR to emit, and a module emitted
346    /// without it would be missing a value its source declares.
347    Unchecked { name: Name, span: NodeSpan },
348    /// A facade signature whose result type has no predicate, so the value its
349    /// companion hands back cannot be checked ([Which types may cross the
350    /// boundary](../docs/spec/interop.md#which-types-may-cross-the-boundary)).
351    ///
352    /// The signature's own type expression is held to the admitted forms before this
353    /// phase (`canonical::Error::FacadeTypeNotAdmitted`), but a union it names is
354    /// checked through its constructors' declared arguments, which that check does not
355    /// read — so a union holding a function type is refused here, where its predicate
356    /// is built. Catching it in canonicalization instead is `BUG-45`. `constructor` is
357    /// the innermost constructor the offending type was declared in, when it was one.
358    NoPredicate {
359        name: Name,
360        span: NodeSpan,
361        found: Unpredicated,
362        constructor: Option<QualName>,
363    },
364    /// An `instance` declaration whose own check failed — a superclass it cannot prove at
365    /// its head. An error stands behind it, and a module emitted without it would be missing
366    /// what its source declares.
367    RejectedInstance { class: Name, span: NodeSpan },
368    /// A reference that still asks for an instance: it names a class member or a constrained
369    /// function, and `zelkova_compiler::ir::specialise` has not resolved it. Nothing is
370    /// emitted for a name that has no function under its own name, so the module has to
371    /// come out of that pass before it is emitted; `zelkova::compile_package` always runs it.
372    Unspecialised {
373        /// The declaration the reference was written in.
374        declaration: Name,
375        /// The name it asks an instance for.
376        name: Name,
377        span: NodeSpan,
378    },
379    /// A construct this backend does not emit: one the front end does not accept yet,
380    /// or a name that did not resolve.
381    Unsupported {
382        construct: Construct,
383        /// The declaration it was written in.
384        declaration: Name,
385        span: NodeSpan,
386    },
387}

391pub enum Construct {
392    /// A `let` expression. The front end does not accept one yet, so the IR never holds
393    /// one; it is named so that meeting one is an error rather than a panic.
394    Let,
395    /// A function nested inside a declaration's body. The language has no lambda and
396    /// [`ir::build`] takes every parameter off the body, so the IR never holds one either.

398    /// A name that did not resolve: an [`ir::TypedTermKind::Hole`], or a pattern of a

400    /// error that the name does not resolve stands behind it, so a module holding one
401    /// never reaches emission through the driver; this keeps one that is handed to
402    /// [`emit`] anyway from being emitted ([`DEC-23` decision

404    Hole,
405}

417/// The part of a facade's result type that no predicate decides — see
418/// [`Error::NoPredicate`].
419#[derive(Debug, Clone, PartialEq)]
420pub enum Unpredicated {
421    /// A function type: `typeof v === "function"` decides that a value is *some*

423    Function,

612/// The JavaScript name of a name the Zelkova source wrote: a declaration of this module,
613/// a parameter, or a name a pattern bound.
614///
615/// **The scheme.** A name in [`RESERVED`] gets a `$` prefix — `class` is `$class` — and
616/// every other name is left as it is: `classy` is `classy`. A Zelkova identifier is
617/// letters and digits as Unicode classifies them, and `_` — what JavaScript accepts in an
618/// identifier too — and never contains a `$`. That is what makes the scheme unable to merge two names: a name left
619/// alone has no `$`, a renamed one starts with the only `$` it has, and the prefix is
620/// removed by reading past it.
621///
622/// Every other name an emitted module declares is the emitter's own, and each is built
623/// so that it cannot be one this function returns, nor one another item here returns:
624///
625/// - the runtime's helpers, `$curry`, `$abort` and `$effect`, the `$scrutinee` a `case`
626///   binds, the `$k` an effectful facade's `Task` is handed, and
627///   the names a boundary check binds — `$returned`, the value a companion handed back,
628///   and inside a union predicate `$v0`, `$v1`, … for the value under test and `$p0`,
629///   `$p1`, … for the predicates of the union's type variables: a `$` and a word that is
630///   not in [`RESERVED`], and no other `$`;
631/// - a union predicate, [`predicate`]: `$is`, then the same segments as a hoisted
632///   constructor's, so its second segment is a package — lowercase, where the second
633///   segment of a hoisted constructor, even of a package named `is`, is a module's and
634///   uppercase;
635/// - a value imported from another module, [`imported`]: it contains a `$`, does not
636///   start with one, and its first segment — the package — is lowercase, where a module
637///   segment is uppercase;
638/// - a hoisted constructor, [`hoisted`]: a `$` followed by at least three more segments,
639///   each separated from the next by a `$` — package, module segments, constructor;
640/// - the facade's alias for its companion's export, [`companion_alias`]: `$companion$`
641///   and the value's name, which holds no `$` — a `$`, a word not in [`RESERVED`], and
642///   exactly one more `$`, so one segment fewer than any hoisted constructor;
643/// - an instance's member, [`instance_member_name`]: `$instance$` and the segments of the
644///   class, the head and the member. Its second segment is a package's, lowercase, where a
645///   hoisted constructor's is a module's, uppercase, and no other name here starts `$instance`;
646/// - a specialisation, [`specialisation_name`]: `$spec$`, a number and the declaration's name.
647///   Its second segment is a number, which no module's name is, so it is not a hoisted
648///   constructor, and it has more than one `$` after the first, so it is not a companion alias;
649/// - a wildcard parameter, [`wildcard`]: `$_` and a number, and `_0`, `_1`, … are not in
650///   [`RESERVED`];
651/// - a parameter written as a pattern, [`ir::pattern_parameter`]: `$` and a number,
652///   which this function leaves as it is, since nothing in [`RESERVED`] holds a `$`.
653///
654/// Two imports, or two hoisted constructors, are told apart by their segments: none of
655/// them holds a `$`, so the segments come back out by splitting at it, and together
656/// they are the declaration's full identity — package, module and name — which is
657/// unique in a build.
658fn mangle(name: &str) -> String {
659    if RESERVED.contains(&name) {
660        format!("${}", name)
661    } else {
662        name.to_string()
663    }
664}

666/// The name of the `position`th parameter of a declaration, when the source wrote `_`
667/// there: `$_0`, `$_1`, ….
668///
669/// Nothing reads it; it exists because two parameters of one JavaScript function may not
670/// share a name, and `f _ _` has two. See [`mangle`] for why it cannot meet another name.
671fn wildcard(position: usize) -> String {
672    format!("$_{}", position)
673}

675/// A package's name as the first segment of a local name: each `-` replaced by `_` —

678/// This is injective because a legal package name holds no `_`, and always a valid start
679/// of a JavaScript identifier because a package name starts with a lowercase letter.

753/// How the name of an instance's member begins.

756/// The name an instance's member is emitted under, and exported and imported by: `$instance$`,
757/// then the class — its package ([`package_segment`]), its module's segments and its own
758/// name — then the head, then the member's own name, all joined by `$`.
759///
760/// The head is the name at the front of the instance's head: a declared type is written like
761/// a class, package first, and a tuple of two, a tuple of three and `()` are `tuple2`,
762/// `tuple3` and `unit`. `Basics.Eq` at `app`'s `App.Colour` is
763/// `$instance$zelkova_core$Basics$Eq$app$App$Colour$eq`.
764///
765/// An instance is identified by its class and its head's name, and a class by its package,
766/// module and name, so two members that get one name are one member. It is built so that no
767/// other name an emitted module declares can be it, whatever a source file spells: it starts
768/// with `$instance$`, which is `$` and a word in no reserved list followed by a segment that
769/// no hoisted constructor, union predicate or companion alias has second — a package segment
770/// is lowercase, and a hoisted constructor's second is a module's, uppercase — and no
771/// Zelkova name holds a `$`. [`imported`] gives it a second `$` in a row, which no other
772/// import has.
773fn instance_member_name(class: &QualName, head: &HeadName, member: &Name) -> String {
774    let head = match head {
775        HeadName::Type(name) => format!(
776            "{}${}${}",
777            package_segment(name.package().as_str()),
778            name.module_name().as_str().replace('.', "$"),
779            name.unqualified_name().as_str()
780        ),
781        HeadName::TwoTuple => "tuple2".to_string(),
782        HeadName::ThreeTuple => "tuple3".to_string(),
783        HeadName::Unit => "unit".to_string(),
784    };
785
786    format!(
787        "{}{}${}${}${}${}",
788        INSTANCE_PREFIX,
789        package_segment(class.package().as_str()),
790        class.module_name().as_str().replace('.', "$"),
791        class.unqualified_name().as_str(),
792        head,
793        member.as_str()
794    )
795}

808/// The name of the field a constructor's argument at `index` is stored in: `a`, `b`, …
809/// `z`, then `aa`, `ab`, … — the spreadsheet column sequence, which carries on the
810/// published `a`, `b`, `c` past the alphabet without two indices sharing a name.
811fn field(index: usize) -> String {
812    let mut letters = Vec::new();
813    let mut remaining = index + 1;
814
815    while remaining > 0 {
816        remaining -= 1;
817        letters.push((b'a' + (remaining % 26) as u8) as char);
818        remaining /= 26;
819    }
820
821    letters.iter().rev().collect()
822}

824/// Whether `label` can be written as a bare property name, in `r.label` and `{label: …}`:
825/// ASCII letters, digits and `_`, starting with a letter or `_`, and not `__proto__`.
826///
827/// A reserved word passes — `r.new` and `{new: 1n}` are legal ECMAScript — and so does a
828/// name every object inherits, `constructor` or `toString`: written as a property of a
829/// record it is that record's own, and a record never renames a label the way [`mangle`]
830/// renames a binding. A label of any other character is written as a string literal rather
831/// than trusting what a Zelkova identifier may hold to be what ECMAScript's identifiers
832/// do. `__proto__` is the one name that is bare-legal and still wrong in an object literal,
833/// where `{__proto__: v}` sets the object's prototype instead of a property: it is
834/// written `["__proto__"]: v` — no Zelkova label can be spelled that way, since an
835/// identifier starts with a letter, and nothing here relies on that.
836fn is_bare_property(label: &str) -> bool {
837    let mut chars = label.chars();
838    chars
839        .next()
840        .is_some_and(|c| c.is_ascii_alphabetic() || c == '_')
841        && chars.all(|c| c.is_ascii_alphanumeric() || c == '_')
842        && label != "__proto__"
843}
844
845/// How a record's field named `label` is read off an expression: `.label`, or
846/// `["label"]` where [`is_bare_property`] says the label cannot be written bare.
847fn property(label: &str) -> String {
848    if is_bare_property(label) {
849        format!(".{}", label)
850    } else {
851        format!("[{}]", string_literal(label))
852    }
853}
854
855/// How a record's field named `label` is written in an object literal, ahead of the
856/// `:`: the label itself, a string literal where [`is_bare_property`] says it cannot be
857/// bare, and a computed key for `__proto__`, which only a computed key makes an own
858/// property.
859fn key(label: &str) -> String {
860    if is_bare_property(label) {
861        label.to_string()
862    } else if label == "__proto__" {
863        format!("[{}]", string_literal(label))
864    } else {
865        string_literal(label)
866    }
867}

888/// The runtime's file name, at the root of `build/out/js/`, above every package's directory.

896/// tree — relative to the binary, the working directory or an environment variable —
897/// and every one of those is wrong for a binary run from anywhere else. Embedding it

941/// The specifier the module `from` imports the module named `to`, declared by
942/// `package`, by.
943///
944/// Within one package it is a path inside that package's directory. Across a package
945/// boundary it climbs out of `from`'s package to `build/out/js/` and into `package`'s
946/// sibling directory — which is why every package of the build has its own directory
947/// rather than the whole build sharing one tree.
948fn module_specifier(from: &ModuleName, package: &str, to: &Name) -> String {
949    let to_path = to.as_str().replace('.', "/");
950
951    if from.package().as_str() == package {
952        let up = match depth(from.name()) {
953            0 => "./".to_string(),
954            depth => "../".repeat(depth),
955        };
956        format!("{}{}.mjs", up, to_path)
957    } else {
958        format!(
959            "{}{}/{}.mjs",
960            "../".repeat(depth(from.name()) + 1),
961            package,
962            to_path
963        )
964    }
965}

990/// A test companion imports the companion it checks by the relative path between the two
991/// files as they sit in the package's source
992/// ([*Testing a companion*](../docs/spec/interop.md#testing-a-companion)): climb
993/// out of `tests/` to the package's root, then down into `src/` — from
994/// `tests/Js/BasicsChecks.mjs`, `Js.Basics`'s is `../../src/Js/Basics.mjs`. The build
995/// holds both roots' modules in one package directory and renames each companion
996/// ([`companion_file`]), so that path reaches nothing there. What does is the path from
997/// `checks`' [`companion_file`] to `target`'s, climbing to the package's directory and
998/// down again — `../Js/Basics.companion.mjs` — which is the companion the build wrote
999/// for `target`, the one the facade `target` calls.
1000///
1001/// Only the shortest spelling is produced: a specifier that reaches the same file by a
1002/// longer path, `./../../src/Js/Basics.mjs`, is not this one.
1003pub fn test_companion_import(checks: &Name, target: &Name) -> (String, String) {
1004    let target_path = target.as_str().replace('.', "/");
1005    let source = format!("{}src/{}.mjs", "../".repeat(depth(checks) + 1), target_path);
1006    let build = match depth(checks) {
1007        0 => format!("./{}.companion.mjs", target_path),
1008        depth => format!("{}{}.companion.mjs", "../".repeat(depth), target_path),
1009    };
1010    (source, build)
1011}

1013/// `text` with every string literal spelling one of `imports`' first specifiers replaced
1014/// by the same literal spelling its second, with the quote it was written with.
1015///
1016/// Only a literal delimited by `'` or `"` and holding exactly that specifier is replaced —
1017/// a template literal, or the specifier as part of a longer string, is left as it is. The
1018/// text is not parsed, so a literal inside a comment is replaced along with the ones in
1019/// `import` declarations: a comment holding the exact quoted path to a companion under
1020/// test is the only thing that changes that should not.
1021pub fn rewrite_imports(text: &str, imports: &[(String, String)]) -> String {
1022    let mut text = text.to_string();
1023    for (from, to) in imports {
1024        for quote in ['\'', '"'] {
1025            text = text.replace(
1026                &format!("{quote}{from}{quote}"),
1027                &format!("{quote}{to}{quote}"),
1028            );
1029        }
1030    }
1031    text
1032}

1036/// A JavaScript string literal holding `c` and nothing else.
1037fn char_literal(c: char) -> String {
1038    format!("\"{}\"", escaped(c))
1039}
1040
1041/// A JavaScript string literal holding `text`, each character escaped as
1042/// [`char_literal`] escapes it.
1043fn string_literal(text: &str) -> String {
1044    format!("\"{}\"", text.chars().map(escaped).collect::<String>())
1045}
1046
1047/// `c` as it is written inside a JavaScript string literal.
1048fn escaped(c: char) -> String {
1049    match c {
1050        '"' => "\\\"".to_string(),
1051        '\\' => "\\\\".to_string(),
1052        '\n' => "\\n".to_string(),
1053        '\r' => "\\r".to_string(),
1054        '\t' => "\\t".to_string(),
1055        // Control characters, and the two line terminators JavaScript source treats
1056        // specially, as escapes rather than raw.
1057        c if c.is_control() || c == '\u{2028}' || c == '\u{2029}' => {
1058            format!("\\u{{{:x}}}", c as u32)
1059        }
1060        c => c.to_string(),
1061    }
1062}

1064/// A JavaScript number literal for `f`.
1065///
1066/// `{:?}` is Rust's shortest representation that reads back as the same `f64`, and
1067/// every finite one it writes — `1.0`, `0.1`, `1e300` — is also a JavaScript number
1068/// literal of that value. No literal a source can write is infinite or `NaN`; they are
1069/// covered so that nothing here can write something that is not JavaScript.
1070fn float_literal(f: f64) -> String {
1071    if f.is_nan() {
1072        "NaN".to_string()
1073    } else if f == f64::INFINITY {
1074        "Infinity".to_string()
1075    } else if f == f64::NEG_INFINITY {
1076        "-Infinity".to_string()
1077    } else {
1078        format!("{:?}", f)
1079    }
1080}

1084/// The JavaScript text of `module`, or every reason it cannot be emitted.
1085///
1086/// `has_companion` is irrelevant to any module but a `module foreign` facade, for which
1087/// it says whether a JavaScript companion sits beside it for the target being built.
1088/// [`emit`] has no path of its own to check that with — the caller does, since only it
1089/// knows where `module`'s source came from — so a facade with no companion is
1090/// [`Error::MissingCompanion`] rather than something this function discovers.
1091///
1092/// `unions` is where a facade's boundary checks read each union they reach off its
1093/// declaration; see [`Unions`]. A module that is not a facade reads nothing from it.
1094///
1095/// `module` has to have been through [`ir::specialise`] along with the rest of its build, or
1096/// hold no name that asks for an instance: a reference that still does is
1097/// [`Error::Unspecialised`]. The pass is what gives it the specialisations and the instance
1098/// bindings this function emits.
1099///
1100/// See this module's documentation for the shape of the text.
1101pub fn emit(
1102    module: &CheckedModule,
1103    has_companion: bool,
1104    unions: &Unions,
1105) -> Result<String, Vec<Error>> {
1106    let ir = &module.ir;
1107
1108    if ir.foreign && !has_companion {
1109        return Err(vec![Error::MissingCompanion {
1110            module: ir.name.name().clone(),
1111            target: "javascript",
1112        }]);
1113    }
1114
1115    let mut errors: Vec<Error> = ir
1116        .unchecked
1117        .iter()
1118        .map(|unchecked| Error::Unchecked {
1119            name: unchecked.name.clone(),
1120            span: unchecked.span,
1121        })
1122        .collect();
1123
1124    // An instance that did not check is missing a binding its source declares, or the
1125    // instance itself; either way a module emitted without it would not be what was written.
1126    for instance in &ir.instances {
1127        if instance.rejected {
1128            errors.push(Error::RejectedInstance {
1129                class: instance.class.unqualified_name(),
1130                span: instance.span,
1131            });
1132        }
1133        errors.extend(instance.unchecked.iter().map(|unchecked| Error::Unchecked {
1134            name: unchecked.name.clone(),
1135            span: unchecked.span,
1136        }));
1137    }
1138
1139    let mut emitter = Emitter {
1140        arities: ir
1141            .declarations
1142            .iter()
1143            .map(|declaration| (declaration.name.clone(), declaration.arity))
1144            .collect(),
1145        specialisations: ir
1146            .specialisations
1147            .iter()
1148            .enumerate()
1149            .map(|(index, specialisation)| {
1150                (
1151                    specialisation_name(index, &specialisation.declaration.name),
1152                    specialisation.declaration.arity,
1153                )
1154            })
1155            .collect(),
1156        runtime: BTreeSet::new(),
1157        imports: BTreeMap::new(),
1158        module: ir.name.clone(),
1159        imported_constructors: BTreeMap::new(),
1160        errors,
1161        declaration: None,
1162    };
1163
1164    let mut functions = Vec::new();
1165    let mut constants: HashMap<Item, String> = HashMap::new();
1166    let mut companion_imports: Vec<String> = Vec::new();
1167    let mut predicates = Predicates {
1168        unions,
1169        functions: BTreeMap::new(),
1170    };
1171
1172    for (index, declaration) in ir.declarations.iter().enumerate() {
1173        emitter.declaration = Some(declaration.name.clone());
1174
1175        if ir.foreign {
1176            emitter.facade_declaration(
1177                &module.canonical,
1178                index,
1179                declaration,
1180                &mut predicates,
1181                &mut functions,
1182                &mut constants,
1183                &mut companion_imports,
1184            );
1185            continue;
1186        }
1187
1188        // Every declaration of a module that is not a facade has a body; one without
1189        // would be a facade signature, handled above.
1190        let Some(body) = &declaration.body else {
1191            continue;
1192        };
1193
1194        // A constrained declaration has no function under its own name: each module that
1195        // uses it holds a specialisation, which is what is emitted.
1196        if !declaration.context.is_empty() {
1197            continue;
1198        }
1199
1200        emitter.binding(
1201            Item::Declaration(index),
1202            &mangle(declaration.name.as_str()),
1203            body,
1204            &mut functions,
1205            &mut constants,
1206        );
1207    }
1208
1209    // An instance's members are ordinary declarations of this module, emitted once under a
1210    // name of their own. One of an instance with a context is a constrained function, and
1211    // is emitted where it is specialised.
1212    for (instance_index, instance) in ir.instances.iter().enumerate() {
1213        if instance.rejected || !instance.context.is_empty() {
1214            continue;
1215        }
1216
1217        for (member_index, member) in instance.members.iter().enumerate() {
1218            let Some(body) = &member.body else {
1219                continue;
1220            };
1221            if !member.context.is_empty() {
1222                continue;
1223            }
1224
1225            emitter.declaration = Some(member.name.clone());
1226            emitter.binding(
1227                Item::InstanceMember {
1228                    instance: instance_index,
1229                    member: member_index,
1230                },
1231                &instance_member_name(&instance.class, &instance.head_name, &member.name),
1232                body,
1233                &mut functions,
1234                &mut constants,
1235            );
1236        }
1237    }
1238
1239    for (index, specialisation) in ir.specialisations.iter().enumerate() {
1240        let declaration = &specialisation.declaration;
1241        let Some(body) = &declaration.body else {
1242            continue;
1243        };
1244
1245        emitter.declaration = Some(declaration.name.clone());
1246        emitter.binding(
1247            Item::Specialisation(index),
1248            &specialisation_name(index, &declaration.name),
1249            body,
1250            &mut functions,
1251            &mut constants,
1252        );
1253    }
1254
1255    if !emitter.errors.is_empty() {
1256        return Err(emitter.errors);
1257    }
1258
1259    // The union predicates the boundary checks call go ahead of every other function,
1260    // in name order — a function declaration is hoisted, so the order is for the reader.
1261    let functions: Vec<String> = predicates
1262        .functions
1263        .into_values()
1264        .chain(functions)
1265        .collect();
1266
1267    // The parameterless bindings, in the order they have to be initialised. Every one
1268    // of them is in that order; a binding that somehow was not would still be emitted,
1269    // after the rest and in the order the module holds them, rather than lost.
1270    let mut ordered = Vec::new();
1271    for item in ir::initialisation_items(ir) {
1272        if let Some(constant) = constants.remove(&item) {
1273            ordered.push(constant);
1274        }
1275    }
1276    let mut leftover: Vec<(Item, String)> = constants.into_iter().collect();
1277    leftover.sort_by_key(|(item, _)| *item);
1278    ordered.extend(leftover.into_iter().map(|(_, constant)| constant));
1279
1280    let mut hoisted = hoisted_constructors(ir);
1281    hoisted.extend(
1282        emitter
1283            .imported_constructors
1284            .iter()
1285            .map(|(local, name)| format!("const {} = {{$: \"{}\"}};", local, name.as_str())),
1286    );
1287
1288    let mut sections: Vec<String> = Vec::new();
1289
1290    let mut imports = Vec::new();
1291    if !emitter.runtime.is_empty() {
1292        let helpers: Vec<&str> = emitter.runtime.iter().copied().collect();
1293        imports.push(format!(
1294            "import {{ {} }} from \"{}\";",
1295            helpers.join(", "),
1296            runtime_specifier(ir.name.name())
1297        ));
1298    }
1299    if !companion_imports.is_empty() {
1300        imports.push(format!(
1301            "import {{ {} }} from \"{}\";",
1302            companion_imports.join(", "),
1303            companion_specifier(ir.name.name())
1304        ));
1305    }
1306    for ((package, from), names) in &emitter.imports {
1307        let specifiers: Vec<String> = names
1308            .iter()
1309            .map(|name| match import_alias(package, from, name) {
1310                local if &local == name => local,
1311                local => format!("{} as {}", name, local),
1312            })
1313            .collect();
1314        imports.push(format!(
1315            "import {{ {} }} from \"{}\";",
1316            specifiers.join(", "),
1317            module_specifier(&ir.name, package, &Name::new(from.as_str()))
1318        ));
1319    }
1320
1321    for section in [imports, hoisted, ordered_functions(functions), ordered] {
1322        if !section.is_empty() {
1323            sections.push(section.join("\n"));
1324        }
1325    }
1326
1327    let exports = exports(module);
1328    if !exports.is_empty() {
1329        sections.push(format!("export {{ {} }};", exports.join(", ")));
1330    }
1331
1332    let mut text = sections.join("\n\n");
1333    text.push('\n');
1334    Ok(text)
1335}

1337/// Functions are separated from each other by a blank line, which joining the section
1338/// with one more newline gives.
1339fn ordered_functions(functions: Vec<String>) -> Vec<String> {
1340    functions
1341        .into_iter()
1342        .enumerate()
1343        .map(|(index, function)| {
1344            if index == 0 {
1345                function
1346            } else {
1347                format!("\n{}", function)
1348            }
1349        })
1350        .collect()
1351}

1353/// One `const` per constructor of no arguments the module declares, unions in the IR's
1354/// name order and each union's constructors in declaration order.
1355///
1356/// `Bool`'s two are not among them: they are `true` and `false`.
1357fn hoisted_constructors(ir: &ir::Module) -> Vec<String> {
1358    ir.unions
1359        .iter()
1360        .filter(|union| !scalars::BOOL.declares(&union.name))
1361        .flat_map(|union| {
1362            union
1363                .variants
1364                .iter()
1365                .filter(|variant| variant.arity == 0)
1366                .map(move |variant| {
1367                    format!(
1368                        "const {} = {{$: \"{}\"}};",
1369                        hoisted(&union.name, &variant.name),
1370                        variant.name.as_str()
1371                    )
1372                })
1373        })
1374        .collect()
1375}

1377/// The export specifiers of `module`, in two runs, each in name order: the values it has to
1378/// export, then the functions of its instances.
1379///
1380/// The values are what the `exposing` header names — a value, or the function an exposed
1381/// operator stands for — and what a copy of its code placed in another module names beside
1382/// them ([`ir::mentioned_by_copies`]). The header is a rule about what another module's
1383/// source may write, canonicalization holds every module to it whatever this lists, and a
1384/// copy is code the compiler wrote: it can name a value the header leaves out, and the
1385/// module it is in imports that value from here. A constrained declaration has no function
1386/// under its own name and is never exported, whatever the header says.
1387///
1388/// Each is exported under its Zelkova name, so a renamed one reads `$class as class` — an
1389/// export's name may be a reserved word where a binding's may not. An instance's function is
1390/// exported under the name it is emitted as ([`instance_member_name`]), which is built so
1391/// that no Zelkova name can be it.
1392fn exports(module: &CheckedModule) -> Vec<String> {
1393    let exposed = |name: &Name| match &module.canonical.exports {
1394        Exports::Everything => true,
1395        Exports::Specifics(specifics) => {
1396            specifics.get(name) == Some(&ExportType::Value)
1397                || specifics.iter().any(|(symbol, kind)| {
1398                    *kind == ExportType::Infix
1399                        && module
1400                            .canonical
1401                            .infixes
1402                            .get(symbol)
1403                            .is_some_and(|infix| &infix.function_name == name)
1404                })
1405        }
1406    };
1407    let mentioned: BTreeSet<Name> = ir::mentioned_by_copies(&module.ir).into_iter().collect();
1408
1409    let mut values: Vec<String> = module
1410        .ir
1411        .declarations
1412        .iter()
1413        .filter(|declaration| declaration.context.is_empty())
1414        .filter(|declaration| exposed(&declaration.name) || mentioned.contains(&declaration.name))
1415        .map(|declaration| {
1416            let local = mangle(declaration.name.as_str());
1417            if local == declaration.name.as_str() {
1418                local
1419            } else {
1420                format!("{} as {}", local, declaration.name.as_str())
1421            }
1422        })
1423        .collect();
1424
1425    let mut instances: Vec<String> = module
1426        .ir
1427        .instances
1428        .iter()
1429        .filter(|instance| !instance.rejected && instance.context.is_empty())
1430        .flat_map(|instance| {
1431            instance.members.iter().map(move |member| {
1432                instance_member_name(&instance.class, &instance.head_name, &member.name)
1433            })
1434        })
1435        .collect();
1436    instances.sort();
1437
1438    values.extend(instances);
1439    values
1440}

1444/// Every union a build declares, by its qualified name, as its declaring module
1445/// canonicalized it: what a facade's boundary check reads a union's constructors, and
1446/// the type each declares for each of its arguments, off.
1447///
1448/// It is built from the checked modules themselves, never from an [`Interface`](zelkova_compiler::Interface):
1449/// an interface exposing a type without its constructors hands over none of them, and
1450/// the predicate of such a type still reads `$` against every constructor its
1451/// declaration has.
1452#[derive(Debug, Default)]
1453pub struct Unions(HashMap<QualName, canonical::UnionType>);
1454
1455impl Unions {
1456    /// Every union declared by one of `modules`. `compile_package` passes every module
1457    /// of the build, so each union a facade can name is one of them.
1458    pub fn of<'a>(modules: impl IntoIterator<Item = &'a CheckedModule>) -> Unions {
1459        let mut unions = HashMap::new();
1460        for module in modules {
1461            for (name, union) in &module.canonical.types {
1462                unions.insert(module.canonical.name.qualify_name(name), union.clone());
1463            }
1464        }
1465        Unions(unions)
1466    }
1467}

1469/// Why no predicate could be built: what was found, and the innermost constructor whose
1470/// declared argument held it, if it was inside one. Boxed, since it is the error half of
1471/// every `Result` the predicate builders return and is much larger than the text half.
1472type NoPredicate = Box<(Unpredicated, Option<QualName>)>;
1473
1474/// The union predicates one facade's boundary checks call, built as the checks need
1475/// them.
1476struct Predicates<'a> {
1477    unions: &'a Unions,
1478    /// Each union predicate's text, by its name ([`predicate`]). A union's entry is
1479    /// inserted, empty, before its body is built, so a recursive union meets its own
1480    /// name here and calls it rather than building it again.
1481    functions: BTreeMap<String, String>,
1482}
1483
1484impl Predicates<'_> {
1485    /// A JavaScript expression that is `true` exactly when `value` — an expression
1486    /// without side effects, evaluated as often as the test needs it — belongs to
1487    /// `tpe`. A conjunction of `===` tests and calls, so it needs no parentheses beside
1488    /// another `&&` or ahead of a `?`.
1489    ///
1490    /// `parameters` binds each type variable in scope — inside a union predicate, the
1491    /// union's own — to the name of the predicate its argument was given as. `depth`
1492    /// is how many parameters of nested arrow functions are already in scope, so each
1493    /// one gets its own name.
1494    fn test(
1495        &mut self,
1496        tpe: &canonical::Type,
1497        value: &str,
1498        depth: usize,
1499        parameters: &HashMap<&Name, String>,
1500    ) -> Result<String, NoPredicate> {
1501        match tpe {
1502            canonical::Type::Unit => Ok(format!("{} === undefined", value)),
1503            canonical::Type::Tuple(tuple) => {
1504                let mut tests = vec![
1505                    format!("Array.isArray({})", value),
1506                    format!("{}.length === {}", value, tuple.iter().count()),
1507                ];
1508                for (index, element) in tuple.iter().enumerate() {
1509                    tests.push(self.test(
1510                        element,
1511                        &format!("{}[{}]", value, index),
1512                        depth,
1513                        parameters,
1514                    )?);
1515                }
1516                Ok(tests.join(" && "))
1517            }
1518            canonical::Type::Variable(name) => match parameters.get(name) {
1519                Some(predicate) => Ok(format!("{}({})", predicate, value)),
1520                None => Err(Box::new((Unpredicated::Variable(name.clone()), None))),
1521            },
1522            canonical::Type::Arrow(..) => Err(Box::new((Unpredicated::Function, None))),
1523            canonical::Type::Record(fields) => {
1524                // `Reflect.ownKeys` counts every own key — symbols and non-enumerable
1525                // properties as well as the enumerable strings `Object.keys` lists — and
1526                // `Object.hasOwn` finds a label only among the value's own, so a name every
1527                // object inherits, `toString`, is not mistaken for a field. With the count
1528                // equal to the number of labels and each label found, the own keys are the
1529                // labels and no others. `Object.keys` counting the same number then makes
1530                // every one of them enumerable, which the update's spread relies on: a
1531                // label that is a non-enumerable own property would be found by `hasOwn`,
1532                // read by an access, and lost by the next update. A field of type `()` is told from a missing one by `hasOwn`,
1533                // which `=== undefined` could not do.
1534                let mut tests = vec![
1535                    format!("typeof {} === \"object\"", value),
1536                    format!("{} !== null", value),
1537                    format!("!Array.isArray({})", value),
1538                    format!("Reflect.ownKeys({}).length === {}", value, fields.len()),
1539                    format!("Object.keys({}).length === {}", value, fields.len()),
1540                ];
1541                for (label, tpe) in fields {
1542                    tests.push(format!(
1543                        "Object.hasOwn({}, {})",
1544                        value,
1545                        string_literal(label.as_str())
1546                    ));
1547                    tests.push(self.test(
1548                        tpe,
1549                        &format!("{}{}", value, property(label.as_str())),
1550                        depth,
1551                        parameters,
1552                    )?);
1553                }
1554                Ok(tests.join(" && "))
1555            }
1556            canonical::Type::Type(name, arguments) => match scalars::scalar_of(name) {
1557                Some(scalars::INT) => Ok(format!(
1558                    "typeof {v} === \"bigint\" && BigInt.asIntN(64, {v}) === {v}",
1559                    v = value
1560                )),
1561                Some(scalars::FLOAT) => Ok(format!("typeof {} === \"number\"", value)),
1562                Some(scalars::BOOL) => Ok(format!("typeof {} === \"boolean\"", value)),
1563                // One code point: a string of one UTF-16 unit, or of the two a code
1564                // point past `0xFFFF` takes. An empty string's `codePointAt(0)` is
1565                // `undefined`, which asks for a length of one and fails it.
1566                Some(scalars::CHAR) => Ok(format!(
1567                    "typeof {v} === \"string\" && {v}.length === ({v}.codePointAt(0) > 0xFFFF ? 2 : 1)",
1568                    v = value
1569                )),
1570                Some(scalars::STRING) => Ok(format!("typeof {} === \"string\"", value)),
1571                _ => {
1572                    let function = self.union(name)?;
1573                    let mut call = vec![value.to_string()];
1574                    for argument in arguments {
1575                        let parameter = format!("$v{}", depth);
1576                        let test = self.test(argument, &parameter, depth + 1, parameters)?;
1577                        call.push(format!("({}) => {}", parameter, test));
1578                    }
1579                    Ok(format!("{}({})", function, call.join(", ")))
1580                }
1581            },
1582        }
1583    }
1584
1585    /// The name of the predicate deciding `union`, building its function first when
1586    /// this facade has not needed it yet.
1587    ///
1588    /// The function takes the value as `$v0` and one predicate per type variable of the
1589    /// union, `$p0`, `$p1`, … in declaration order. It answers `false` for anything but
1590    /// a non-null object, and otherwise switches on `$`: each constructor tests its
1591    /// arguments, read off the fields [`field`] names, against the types it declares
1592    /// for them, and a `$` naming no constructor of the declaration is `false`.
1593    fn union(&mut self, union: &QualName) -> Result<String, NoPredicate> {
1594        let name = predicate(union);
1595        if self.functions.contains_key(&name) {
1596            return Ok(name);
1597        }
1598
1599        let unions = self.unions;
1600        let Some(declaration) = unions.0.get(union) else {
1601            return Err(Box::new((Unpredicated::Undeclared(union.clone()), None)));
1602        };
1603        self.functions.insert(name.clone(), String::new());
1604
1605        // A union no predicate can be built for leaves no entry behind, so another facade
1606        // declaration naming *that* union meets the same error rather than a call to a
1607        // function that was never finished. That covers this union only: a mutually
1608        // recursive union built successfully while this one was still in progress (it
1609        // found this union's placeholder and used it) keeps its own `functions` entry,
1610        // even though the removal below just deleted the predicate that entry calls — a
1611        // facade naming only the other union gets no diagnostic for that.
1612        match self.union_function(union, &name, declaration) {
1613            Ok(function) => {
1614                self.functions.insert(name.clone(), function);
1615                Ok(name)
1616            }
1617            Err(error) => {
1618                self.functions.remove(&name);
1619                Err(error)
1620            }
1621        }
1622    }
1623
1624    /// The text of the function [`Predicates::union`] names `name`, deciding `union`
1625    /// against `declaration`.
1626    fn union_function(
1627        &mut self,
1628        union: &QualName,
1629        name: &str,
1630        declaration: &canonical::UnionType,
1631    ) -> Result<String, NoPredicate> {
1632        let predicates: Vec<String> = (0..declaration.variables.len())
1633            .map(|index| format!("$p{}", index))
1634            .collect();
1635        let parameters: HashMap<&Name, String> = declaration
1636            .variables
1637            .iter()
1638            .zip(predicates.iter().cloned())
1639            .collect();
1640
1641        let mut cases = Vec::new();
1642        for constructor in &declaration.variants {
1643            let mut tests = Vec::new();
1644            for (index, argument) in constructor.type_parameters.iter().enumerate() {
1645                let value = format!("$v0.{}", field(index));
1646                let test =
1647                    self.test(argument, &value, 1, &parameters)
1648                        .map_err(|mut no_predicate| {
1649                            if no_predicate.1.is_none() {
1650                                no_predicate.1 = Some(union.sibling(&constructor.name));
1651                            }
1652                            no_predicate
1653                        })?;
1654                tests.push(test);
1655            }
1656            let test = if tests.is_empty() {
1657                "true".to_string()
1658            } else {
1659                tests.join(" && ")
1660            };
1661            cases.push(format!(
1662                "    case {}:\n      return {};",
1663                string_literal(constructor.name.as_str()),
1664                test
1665            ));
1666        }
1667        cases.push("    default:\n      return false;".to_string());
1668
1669        let signature: Vec<&str> = std::iter::once("$v0")
1670            .chain(predicates.iter().map(String::as_str))
1671            .collect();
1672        Ok(format!(
1673            "function {}({}) {{\n  if (typeof $v0 !== \"object\" || $v0 === null) {{\n    return false;\n  }}\n  switch ($v0.$) {{\n{}\n  }}\n}}",
1674            name,
1675            signature.join(", "),
1676            cases.join("\n")
1677        ))
1678    }
1679}

1681/// The canonical type left once `arity` arrows are taken off the front of `tpe` — a
1682/// facade signature's result, `tpe` itself for a facade constant.
1683fn canonical_result(tpe: &canonical::Type, arity: usize) -> &canonical::Type {
1684    let mut result = tpe;
1685    for _ in 0..arity {
1686        match result {
1687            canonical::Type::Arrow(_, rest) => result = rest,
1688            _ => break,
1689        }
1690    }
1691    result
1692}

1694/// [`canonical_result`] over the typer's type of the same signature, which is the one
1695/// that can be written out the way the source spells it.
1696fn typer_result(tpe: &Type, arity: usize) -> &Type {
1697    let mut result = tpe;
1698    for _ in 0..arity {
1699        match result {
1700            Type::Fun { return_tpe, .. } => result = return_tpe,
1701            _ => break,
1702        }
1703    }

1801    /// One `module foreign` facade declaration's forwarding code, appended to
1802    /// `functions` or `constants` — a plain function at arity one or more, a `const`
1803    /// at arity zero — plus the companion import it needs, appended to
1804    /// `companion_imports`, and any union predicate its boundary check calls, added to
1805    /// `predicates`. See this module's doc comment, "The boundary check", for what the
1806    /// forwarding code does with the companion's result.
1807    ///
1808    /// A signature marked `unsafe` calls the companion directly. One that is not declares
1809    /// an effect ([An effectful
1810    /// facade](../docs/spec/interop.md#an-effectful-facade)), and its forwarding
1811    /// code is the `Task` this module's *A facade* section describes. A result type no predicate decides
1812    /// pushes [`Error::NoPredicate`] and appends nothing.
1813    #[allow(clippy::too_many_arguments)]
1814    fn facade_declaration(
1815        &mut self,
1816        canonical: &canonical::Module,
1817        index: usize,
1818        declaration: &ir::Declaration,
1819        predicates: &mut Predicates,
1820        functions: &mut Vec<String>,
1821        constants: &mut HashMap<Item, String>,
1822        companion_imports: &mut Vec<String>,
1823    ) {
1824        let item = Item::Declaration(index);
1825        let (signature, marked_unsafe) = match canonical.values.get(&declaration.name) {
1826            Some(Value::TypedValue {
1827                marked_unsafe, tpe, ..
1828            }) => (tpe, *marked_unsafe),
1829            _ => {
1830                self.errors.push(Error::NoSignature {
1831                    name: declaration.name.clone(),
1832                    span: declaration.span,
1833                });
1834                return;
1835            }
1836        };
1837
1838        // What the companion hands back: the signature with the arrows of its own
1839        // parameter list — `arity` of them — taken off the front. For an effect, the
1840        // payload of the `Task (Result Failure a)` that remains.
1841        let result = canonical_result(signature, declaration.arity);
1842        let result = if marked_unsafe {
1843            result
1844        } else {
1845            match canonical::effectful_result_payload(result) {
1846                Some(payload) => payload,
1847                None => {
1848                    self.errors.push(Error::NotAnEffect {
1849                        name: declaration.name.clone(),
1850                        span: declaration.span,
1851                    });
1852                    return;
1853                }
1854            }
1855        };
1856
1857        // The companion's export is imported under an alias — never the plain name,
1858        // which this method is about to declare a local binding under, and a module
1859        // cannot import and declare the same name twice.
1860        let local = mangle(declaration.name.as_str());
1861        let alias = companion_alias(declaration.name.as_str());
1862        let parameters: Vec<String> = (0..declaration.arity).map(field).collect();
1863        let call = format!("{}({})", alias, parameters.join(", "));
1864
1865        // `None` is a `()` result: discarded, so nothing is checked.
1866        let test = if matches!(result, canonical::Type::Unit) {
1867            None
1868        } else {
1869            match predicates.test(result, "$returned", 0, &HashMap::new()) {
1870                Ok(test) => Some(test),
1871                Err(no_predicate) => {
1872                    let (found, constructor) = *no_predicate;
1873                    self.errors.push(Error::NoPredicate {
1874                        name: declaration.name.clone(),
1875                        span: declaration.span,
1876                        found,
1877                        constructor,
1878                    });
1879                    return;
1880                }
1881            }
1882        };
1883
1884        companion_imports.push(format!("{} as {}", declaration.name.as_str(), alias));
1885
1886        if !marked_unsafe {
1887            let export = format!(
1888                "{}.{}",
1889                self.module.name().as_str(),
1890                declaration.name.as_str()
1891            );
1892            self.runtime.insert("$effect");
1893            let check = match &test {
1894                Some(test) => format!("($returned) => {}", test),
1895                None => "null".to_string(),
1896            };
1897            let task = format!(
1898                "{{$: \"Task\", a: ($k) => $effect(() => {}, {}, {}, $k)}}",
1899                call,
1900                check,
1901                string_literal(&export)
1902            );
1903            if declaration.arity == 0 {
1904                constants.insert(item, format!("const {} = {};", local, task));
1905            } else {
1906                functions.push(format!(
1907                    "function {}({}) {{\n  return {};\n}}",
1908                    local,
1909                    parameters.join(", "),
1910                    task
1911                ));
1912            }
1913            return;
1914        }
1915
1916        let Some(test) = test else {
1917            if declaration.arity == 0 {
1918                constants.insert(item, format!("const {} = undefined;", local));
1919            } else {
1920                functions.push(format!(
1921                    "function {}({}) {{\n  {};\n  return undefined;\n}}",
1922                    local,
1923                    parameters.join(", "),
1924                    call
1925                ));
1926            }
1927            return;
1928        };
1929
1930        self.runtime.insert("$abort");
1931        let description = string_literal(&format!(
1932            "`{}.{}`'s companion returned a value its declared type, `{}`, does not admit",
1933            self.module.name().as_str(),
1934            declaration.name.as_str(),
1935            typer_result(&declaration.tpe, declaration.arity)
1936        ));
1937        let checked = format!("{} ? $returned : $abort({})", test, description);
1938
1939        if declaration.arity == 0 {
1940            constants.insert(
1941                item,
1942                format!("const {} = (($returned) => {})({});", local, checked, alias),
1943            );
1944        } else {
1945            functions.push(format!(
1946                "function {}({}) {{\n  const $returned = {};\n  return {};\n}}",
1947                local,
1948                parameters.join(", "),
1949                call,
1950                checked
1951            ));
1952        }
1953    }

1955    fn expression(&mut self, term: &TypedTerm) -> String {
1956        match &term.kind {
1957            TypedTermKind::Int(i) => format!("{}n", i),
1958            TypedTermKind::Float(f) => float_literal(*f),
1959            TypedTermKind::Char(c) => char_literal(*c),
1960            TypedTermKind::String(s) => string_literal(s),
1961            TypedTermKind::Identifier { reference, context } => {
1962                self.refuse_obligations(reference, context, term.span);
1963                self.value(&reference.name, &reference.kind, term.span)
1964            }
1965            TypedTermKind::Apply { .. } => self.application(term),
1966            TypedTermKind::If {
1967                cond,
1968                true_branch,
1969                false_branch,
1970            } => {
1971                let cond = self.operand(cond);
1972                let true_branch = self.expression(true_branch);
1973                let false_branch = self.expression(false_branch);
1974                format!("{} ? {} : {}", cond, true_branch, false_branch)
1975            }
1976            TypedTermKind::Tuple(tuple) => {
1977                let elements: Vec<String> = tuple
1978                    .iter()
1979                    .map(|element| self.expression(element))
1980                    .collect();
1981                format!("[{}]", elements.join(", "))
1982            }
1983            TypedTermKind::Case {
1984                scrutinee,
1985                branches,
1986                form,
1987            } => self.case_expression(scrutinee, branches, *form),
1988            TypedTermKind::Unit => "undefined".to_string(),
1989            TypedTermKind::Let { .. } => self.unsupported(Construct::Let, term.span),
1990            TypedTermKind::Fun { .. } => self.unsupported(Construct::Lambda, term.span),
1991            TypedTermKind::Hole => self.unsupported(Construct::Hole, term.span),
1992            TypedTermKind::Record(fields) => {
1993                format!("{{{}}}", self.record_fields(fields).join(", "))
1994            }
1995            TypedTermKind::Update { record, fields } => {
1996                // The record updated is evaluated first, once, by the spread; the fields
1997                // follow in the order written, and a label the update names replaces the
1998                // one the spread copied.
1999                let record = self.expression(record);
2000                let mut entries = vec![format!("...{}", record)];
2001                entries.extend(self.record_fields(fields));
2002                format!("{{{}}}", entries.join(", "))
2003            }
2004            TypedTermKind::Access { record, label, .. } => {
2005                let record = self.operand(record);
2006                format!("{}{}", record, property(label.as_str()))
2007            }
2008            TypedTermKind::Accessor { label, .. } => {
2009                format!("(r) => r{}", property(label.as_str()))
2010            }
2011        }
2012    }

2078                    }
2079                }

2082                    0 => {

2084                        // Compares the full identity field-wise instead of allocating a
2085                        // throwaway `ModuleName` just to compare it against `self.module`.

2087                            && ctor.union.module_name() == *self.module.name();

2090                                .insert(local.clone(), ctor.name.clone());

2093                    }

2097                            "({}) => ({})",
2098                            parameters.join(", "),
2099                            tagged(&ctor.name, parameters.clone())
2100                        );
2101                        if arity >= 2 {
2102                            self.curry(&function, arity)
2103                        } else {
2104                            function
2105                        }
2106                    }
2107                }
2108            }
2109        }
2110    }

2163    /// An application spine: a direct call up to the node the IR marks saturated, if
2164    /// there is one, then one call per remaining argument.
2165    fn application(&mut self, term: &TypedTerm) -> String {
2166        let mut arguments = Vec::new();
2167        let mut head = term;
2168        while let TypedTermKind::Apply {
2169            fun,
2170            arg,
2171            saturation,
2172        } = &head.kind
2173        {
2174            arguments.push((arg.as_ref(), *saturation));
2175            head = fun;
2176        }
2177        arguments.reverse();
2178
2179        let saturated = arguments
2180            .iter()
2181            .position(|(_, saturation)| *saturation == Saturation::Saturated);
2182
2183        // Evaluated in the order written: the function, then each argument.
2184        let (mut callee, rest) = match (&head.kind, saturated) {
2185            (TypedTermKind::Identifier { reference, context }, Some(last)) => {
2186                self.refuse_obligations(reference, context, head.span);
2187                match &reference.kind {
2188                    ReferenceKind::Specialised(index) => match self.specialisation(*index) {
2189                        Some((local, _)) => {
2190                            let supplied = self.arguments(&arguments[..=last]);
2191                            (
2192                                format!("{}({})", local, supplied.join(", ")),
2193                                &arguments[last + 1..],
2194                            )
2195                        }
2196                        None => (
2197                            self.unspecialised(&reference.name, head.span),
2198                            &arguments[..],
2199                        ),
2200                    },
2201                    ReferenceKind::InstanceMember(member) => {
2202                        let local = self.instance_member(member);
2203                        let supplied = self.arguments(&arguments[..=last]);
2204                        (

2254    /// A `case … of`, or a parameter written as a pattern — the IR's single-branch
2255    /// match on it ([`ir::CaseForm::Parameter`]), which lowers and emits the same way.
2256    /// See this module's doc comment, "A `case`", for the shape.
2257    ///
2258    /// `scrutinee` is evaluated exactly once — bound to `$scrutinee` before the tree is
2259    /// walked — never once per test, which is what a decision tree built by
2260    /// [`decision_tree`] wants: [Order of
2261    /// evaluation](../docs/spec/evaluation-semantics.md#order-of-evaluation).
2262    ///
2263    /// `form` says whether the source wrote a `case … of` or a parameter pattern
2264    /// ([`ir::CaseForm`]) and reaches [`abort_description`] unchanged, so a
2265    /// [`Decision::Fail`] this tree needs describes itself in the vocabulary the source
2266    /// actually used.
2267    ///
2268    /// Mutation-checked by re-emitting `self.expression(scrutinee)` at every
2269    /// [`Decision::Test`] instead of binding it once: a `case` whose scrutinee is a call
2270    /// then contains that call's text more than once.
2271    fn case_expression(
2272        &mut self,
2273        scrutinee: &TypedTerm,
2274        branches: &[(ir::TermPattern, Box<TypedTerm>)],
2275        form: CaseForm,
2276    ) -> String {
2277        // A constructor that did not resolve has no case to test for, so the tree is not
2278        // built at all.
2279        if let Some(hole) = branches
2280            .iter()
2281            .find_map(|(pattern, _)| pattern_hole(pattern))
2282        {
2283            return self.unsupported(Construct::Hole, hole);
2284        }
2285
2286        let declaration = self.declaration.clone().unwrap_or_else(|| Name::new(""));
2287        let tree = decision_tree(&scrutinee.tpe, branches, &declaration);
2288        let scrutinee_expr = self.expression(scrutinee);
2289        let body = self.decision(&tree, "$scrutinee", 1, form);
2290
2291        format!(
2292            "(() => {{\n  const $scrutinee = {};\n{}\n}})()",
2293            scrutinee_expr, body
2294        )
2295    }

2297    /// One [`Decision`] node as the statements of an `if`/`else` chain, each line
2298    /// indented `depth` levels of two spaces — the body of [`case_expression`]'s
2299    /// immediately invoked function. `root` is the name the scrutinee is bound to,
2300    /// which [`occurrence_expr`] reads a test's or a binding's value off; `form` is
2301    /// passed through unchanged to [`abort_description`].
2302    ///
2303    /// A [`Decision::Test`] nests: its `matched` and `default` are each a full
2304    /// [`Decision`] emitted one level deeper, so a chain of tests on the scrutinee comes
2305    /// out as `if`s nested in one another's `else`, never merged or reordered — the
2306    /// order [Conditional
2307    /// evaluation](../docs/spec/evaluation-semantics.md#conditional-evaluation)
2308    /// tries branches in. A [`Decision::Leaf`] declares its bindings as `const`s, each
2309    /// read off `root` by [`occurrence_expr`], ahead of a `return` of its body — all of
2310    /// it inside its own block, so a binding never shares a scope with the
2311    /// `$scrutinee` line above it. Sharing that scope is observable: a binding may name
2312    /// anything the pattern it comes from could ([Variable
2313    /// patterns](../docs/spec/patterns.md#variable-patterns) lets one repeat a
2314    /// name already in scope), and a `const` anywhere in a block puts every reference to
2315    /// that name earlier in the *same* block in its temporal dead zone — so without the
2316    /// leaf's own block, a scrutinee expression that happens to read a name a leaf also
2317    /// binds would throw `ReferenceError` before ever reaching the leaf. A
2318    /// [`Decision::Fail`] returns the runtime's `$abort`, importing it the way `$curry`
2319    /// is imported; it carries no binding, so it needs no block of its own.
2320    ///
2321    /// Each `Test`'s `default` is emitted where it stands, and [`Decision`] copies the tree
2322    /// for the later branches into the `default` of every test an earlier branch holds, so
2323    /// the text grows with the product of the branches' refutable parts, and a leaf's
2324    /// body is written once per copy of its leaf. `GEN-26` tracks it.
2325    fn decision(&mut self, tree: &Decision, root: &str, depth: usize, form: CaseForm) -> String {
2326        let pad = "  ".repeat(depth);
2327
2328        match tree {
2329            Decision::Test {
2330                scrutinee,
2331                outcome,
2332                matched,
2333                default,
2334            } => {
2335                let condition = test_condition(root, scrutinee, outcome);
2336                let matched = self.decision(matched, root, depth + 1, form);
2337                let default = self.decision(default, root, depth + 1, form);
2338                format!(
2339                    "{pad}if ({condition}) {{\n{matched}\n{pad}}} else {{\n{default}\n{pad}}}",
2340                    pad = pad,
2341                    condition = condition,
2342                    matched = matched,
2343                    default = default,
2344                )
2345            }
2346            Decision::Leaf { bindings, body } => {
2347                let inner_pad = "  ".repeat(depth + 1);
2348                let mut lines: Vec<String> = bindings
2349                    .iter()
2350                    .map(|binding| {
2351                        format!(
2352                            "{}const {} = {};",
2353                            inner_pad,
2354                            mangle(&binding.name),
2355                            occurrence_expr(root, &binding.occurrence)
2356                        )
2357                    })
2358                    .collect();
2359                lines.push(format!("{}return {};", inner_pad, self.expression(body)));
2360                format!("{pad}{{\n{}\n{pad}}}", lines.join("\n"), pad = pad)
2361            }
2362            Decision::Fail { declaration } => {
2363                self.runtime.insert("$abort");
2364                format!(
2365                    "{}return $abort({});",
2366                    pad,
2367                    abort_description(declaration, form)
2368                )
2369            }
2370        }
2371    }
2372}

2374/// The condition a [`Decision::Test`] compiles to: an equality check against the value
2375/// [`occurrence_expr`] reads off `root`. A constructor is tested by its `$` field — a
2376/// `Bool`'s constructors never reach here, since `typer::translate_pattern` turns
2377/// `True`/`False` into an [`Outcome::Literal`] — and a literal by the value itself,
2378/// which is also how a `case` on a `Bool` tests it (see this module's doc comment,
2379/// "Representations"). A record is never tested: it has one shape, so a record pattern
2380/// reaches here only through the tests of its entries.
2381fn test_condition(root: &str, occurrence: &Occurrence, outcome: &Outcome) -> String {
2382    let value = occurrence_expr(root, occurrence);
2383
2384    match outcome {
2385        Outcome::Literal(LiteralValue::Bool(b)) => format!("{} === {}", value, b),
2386        Outcome::Literal(LiteralValue::Int(i)) => format!("{} === {}n", value, i),
2387        // `===` on two numbers is IEEE 754's equality, which is what a `Float` pattern
2388        // asks for (docs/spec/evaluation-semantics.md#what-structural-equality-computes):
2389        // `0 === -0` holds and `NaN === NaN` does not.
2390        Outcome::Literal(LiteralValue::Float(f)) => format!("{} === {}", value, float_literal(*f)),
2391        Outcome::Literal(LiteralValue::Char(c)) => format!("{} === {}", value, char_literal(*c)),
2392        Outcome::Literal(LiteralValue::String(s)) => format!("{} === {}", value, string_literal(s)),
2393        Outcome::Constructor(ctor) => format!("{}.$ === \"{}\"", value, ctor.name.as_str()),
2394    }
2395}

2397/// The JavaScript expression reading the value at `occurrence` off `root`, the name the
2398/// scrutinee is bound to: a constructor argument is a field ([`field`], the same one
2399/// [`tagged`] builds an object under), a tuple element an index and a record's field a
2400/// property read by its label ([`property`]) — the representations [A union crosses as a
2401/// tagged value](../docs/spec/interop.md#a-union-crosses-as-a-tagged-value) gives the
2402/// first two and *Representations* the third.
2403fn occurrence_expr(root: &str, occurrence: &Occurrence) -> String {
2404    match occurrence {
2405        Occurrence::Root => root.to_string(),
2406        Occurrence::At(base, step) => {
2407            let base = occurrence_expr(root, base);
2408            match step {
2409                Step::ConstructorArgument(index) => format!("{}.{}", base, field(*index)),
2410                Step::TupleElement(index) => format!("{}[{}]", base, index),
2411                Step::Field(label) => format!("{}{}", base, property(label.as_str())),
2412            }
2413        }
2414    }
2415}

2428        }
2429        CaseForm::Parameter => format!(

2431            declaration.as_str()
2432        ),
2433    }

2436/// Where `pattern` holds an [`ir::TermPatternKind::Hole`], at any depth, when it holds
2437/// one: the outermost, leftmost one's span.
2438fn pattern_hole(pattern: &ir::TermPattern) -> Option<NodeSpan> {
2439    match &pattern.kind {
2440        ir::TermPatternKind::Hole { .. } => Some(pattern.span),
2441        ir::TermPatternKind::Constructor { args, .. } => {
2442            args.iter().find_map(|arg| pattern_hole(&arg.pattern))
2443        }
2444        ir::TermPatternKind::Tuple { elements } => elements
2445            .iter()
2446            .find_map(|element| pattern_hole(&element.pattern)),
2447        ir::TermPatternKind::Record { fields } => fields
2448            .iter()
2449            .find_map(|field| pattern_hole(&field.value.pattern)),
2450        ir::TermPatternKind::Anything
2451        | ir::TermPatternKind::Bind(_)
2452        | ir::TermPatternKind::Literal { .. }
2453        | ir::TermPatternKind::Unit => None,
2454    }
2455}
