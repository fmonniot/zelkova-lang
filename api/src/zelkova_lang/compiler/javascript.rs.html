1//! The JavaScript backend: one checked module in, the text of one ES module out.
2//!
3//! [`emit`] reads the [`ir::Module`] a [`CheckedModule`] carries, beside the
4//! [`canonical::Module`] it was built from for the one thing the IR does not hold — which
5//! names the module exports. It produces text and writes nothing; where that text goes is
6//! [`GEN-13`](../../../docs/tickets/gen-13.md)'s.
7//!
8//! # The shape of an emitted module
9//!
10//! In this order, each section separated from the next by a blank line and left out when
11//! it is empty:
12//!
13//! 1. **Imports** — the runtime helpers the module calls, from the runtime module
14//!    (`runtime/js/zelkova.mjs`), then one named import per value another module declares.
15//! 2. **Hoisted constructors** — one `const` per constructor of no arguments this module
16//!    declares, then one per such constructor of another module's that it mentions, which
17//!    every mention of it refers to ([`DEC-18` decision
18//!    4](../../../docs/decisions/dec-18.md#4--a-constructor-of-no-arguments-is-hoisted-to-one-module-level-constant)).
19//! 3. **Functions** — one `function` per declaration that takes parameters, with exactly
20//!    as many JavaScript parameters as it was written with ([`DEC-18` decision
21//!    3](../../../docs/decisions/dec-18.md#3--a-function-emits-as-a-plain-n-ary-function-and-currying-is-a-runtime-helper)).
22//! 4. **Parameterless bindings** — one `const` each, in
23//!    [`ir::Module::initialisation_order`], so each is initialised after every other one
24//!    it mentions directly. One that reaches another only through a function it calls is
25//!    not ordered after it, and the emitted module throws at load
26//!    ([`BUG-38`](../../../docs/tickets/bug-38.md)).
27//! 5. **Exports** — one `export { … }` naming each exported value by its Zelkova name.
28//!
29//! # Representations
30//!
31//! An `Int` literal is a `BigInt` (`1n`), since [`Int` is 64
32//! bits](../../../docs/spec/evaluation-semantics.md#numbers); a `Float` is a number, a
33//! `Char` a one-character string. `True` and `False` — the constructors of
34//! [`scalars::BOOL`], recognised by the union's qualified name — are `true` and `false`.
35//! Every other union value is `{$: "Ctor", a: …, b: …}`, arguments in declaration order
36//! ([A union crosses as a tagged
37//! value](../../../docs/spec/interop.md#a-union-crosses-as-a-tagged-value)); a
38//! constructor's arguments past the 26th continue `aa`, `ab`, … — see [`field`]. A tuple
39//! is an array.
40//!
41//! A constructor is not exported. An importer that builds one builds its own object of
42//! the same shape, and hoists its own constant for one of no arguments. [Equality is
43//! structural](../../../docs/spec/evaluation-semantics.md#what-structural-equality-computes),
44//! so nothing observes which module allocated it.
45//!
46//! # Calls
47//!
48//! An application whose IR node is [`Saturation::Saturated`] is a direct call,
49//! `f(a, b)`, or for a constructor the object itself. Every other application calls a
50//! *function value*, one argument per JavaScript call: `g(a)(b)`. What makes that
51//! correct is that every function value the emitted code hands around accepts being
52//! called one argument at a time. A declaration of two or more parameters, and a
53//! constructor of two or more arguments, is `$curry(f, n)` wherever it is used as a value
54//! rather than called, so a partial application such as `pick 1` is `$curry(pick,
55//! 2)(1n)`; a one-parameter function already takes its argument one at a time.
56//!
57//! One argument per call is also what keeps the [order of
58//! evaluation](../../../docs/spec/evaluation-semantics.md#order-of-evaluation): `g a b`
59//! applies `g a` before it evaluates `b`, and `g(a)(b)` does too where `g(a, b)` would
60//! not. Nothing here reorders a subexpression, and [nothing
61//! short-circuits](../../../docs/spec/evaluation-semantics.md#nothing-short-circuits):
62//! `&&` and `||` reach this module as ordinary applications of the functions their
63//! `infix` declarations name, so they are emitted as calls, never as JavaScript's own
64//! operators.
65//!
66//! A value another module declares has an arity this module cannot see, so it is called
67//! one argument at a time like any other value ([`ir::ReferenceKind::Foreign`]).
68//!
69//! # A facade
70//!
71//! [`emit`] answers a module for a `module foreign` facade too, so that an importer
72//! needs no special case. Every [`unsafe`](../../../docs/spec/interop.md#an-unsafe-facade)
73//! declaration becomes forwarding code that imports the companion's export under an
74//! alias and calls it with exactly the parameters the signature's arrow count gives —
75//! a plain function at arity one or more, a `const` at arity zero — the same
76//! [plain-parameter-list promise](../../../docs/spec/interop.md#the-javascript-companion)
77//! an ordinary declaration's call already keeps. [`Error::MissingCompanion`] is
78//! answered instead when the caller says no companion sits beside this module for the
79//! target being built ([*A facade names a boundary, not a
80//! backend*](../../../docs/spec/interop.md#a-facade-names-a-boundary-not-a-backend)) —
81//! [`emit`] has no path of its own to check that with, so the caller decides.
82//!
83//! A signature not marked `unsafe` declares an effect
84//! ([An effectful facade](../../../docs/spec/interop.md#an-effectful-facade)), and
85//! wrapping one in the `Result` its call site is owed is
86//! [`GEN-16`](../../../docs/tickets/gen-16.md)'s, blocked on `Task` existing at all.
87//! [`emit`] answers [`Error::Effectful`] for one rather than emitting the `unsafe`
88//! shape for it.
89//!
90//! [`companion_specifier`] assumes the companion sits beside this module's own emitted
91//! file, sharing the last segment of its name, which is where it sits beside the
92//! `.zel` source today. Whether the two can share that output path once one is written
93//! there is [`GEN-13`](../../../docs/tickets/gen-13.md)'s to settle, along with copying
94//! the companion into place at all — nothing here does either.
95//!
96//! # A `case`
97//!
98//! [`ir::decision_tree`] turns a `case`'s branches — and a parameter written as a
99//! pattern, which the IR holds as a single-branch match on it
100//! ([`ir::CaseForm::Parameter`]) and which reaches [`Emitter::case_expression`] the
101//! same way — into the [`Decision`] tree a backend walks instead of re-deriving which
102//! test distinguishes which branch. [`Emitter::case_expression`] binds the scrutinee to
103//! `$scrutinee` once, since the tree tests it more than once and re-evaluating it per
104//! test would evaluate it once per test — observable through non-termination ([Order of
105//! evaluation](../../../docs/spec/evaluation-semantics.md#order-of-evaluation)) — and
106//! walks the tree into an `if`/`else` chain inside an immediately invoked function,
107//! since a `case` is an expression and JavaScript's `if` is a statement. A
108//! [`Decision::Test`] becomes an `if` on the value [`occurrence_expr`] reads off
109//! `$scrutinee`: `.$ === "Ctor"` for a constructor, an equality check for a literal. A
110//! [`Decision::Leaf`] declares its bindings as `const`s ahead of a `return`, all of it
111//! inside its own block — a binding may repeat a name the scrutinee expression reads
112//! ([Variable patterns](../../../docs/spec/patterns.md#variable-patterns)), and without
113//! that block the two would share a scope, putting the earlier read in the later
114//! binding's temporal dead zone. A [`Decision::Fail`] — the fall-through a `case`
115//! missing a branch reaches, because [coverage is not checked
116//! yet](../../../docs/spec/evaluation-semantics.md#two-outcomes) — calls the runtime's
117//! `$abort`, naming the declaration the `case` was written in and, for a parameter
118//! written as a pattern, saying so rather than naming a `case` the source never wrote.
119//!
120//! # What is refused
121//!
122//! [`emit`] answers an [`Error`] rather than a module missing a part: for a declaration
123//! with no IR ([`ir::Module::unchecked`]), for a facade signature not marked `unsafe`,
124//! and for a facade with no companion for the target being built.
125

139/// Why a module could not be emitted.
140#[derive(Debug, Clone, PartialEq)]
141pub enum Error {
142    /// A `module foreign` facade with no companion for the target being built
143    /// ([*A facade names a boundary, not a
144    /// backend*](../../../docs/spec/interop.md#a-facade-names-a-boundary-not-a-backend)).
145    ///
146    /// [`emit`] has no path of its own to check a companion's presence on disk with —
147    /// its caller does, and says so through [`emit`]'s `has_companion` parameter.
148    MissingCompanion { module: Name, target: &'static str },
149    /// A facade signature not marked `unsafe`. It declares an effect
150    /// ([An effectful facade](../../../docs/spec/interop.md#an-effectful-facade)), and
151    /// the wrapper its call site is owed is [`GEN-16`](../../../docs/tickets/gen-16.md)'s,
152    /// blocked on `Task` existing at all — so this is refused rather than emitted as
153    /// if it were `unsafe`.
154    Effectful { name: Name, span: NodeSpan },
155    /// A declaration the typer could not check has no IR to emit, and a module emitted
156    /// without it would be missing a value its source declares.
157    Unchecked { name: Name, span: NodeSpan },
158    /// A construct this backend does not emit yet.
159    Unsupported {
160        construct: Construct,
161        /// The declaration it was written in.
162        declaration: Name,
163        span: NodeSpan,
164    },
165}
166
167/// The expression forms [`Error::Unsupported`] names.
168#[derive(Debug, Clone, Copy, PartialEq, Eq)]
169pub enum Construct {
170    /// A `let` expression. The front end does not accept one yet, so the IR never holds
171    /// one; it is named so that meeting one is an error rather than a panic.
172    Let,
173    /// A function nested inside a declaration's body. The language has no lambda and
174    /// [`ir::build`] takes every parameter off the body, so the IR never holds one either.
175    Lambda,
176}
177
178impl Construct {
179    fn describe(self) -> &'static str {
180        match self {
181            Construct::Let => "a `let` expression",
182            Construct::Lambda => "an anonymous function",
183        }
184    }
185}
186
187impl PhaseError for Error {
188    fn message(&self) -> String {
189        match self {
190            Error::MissingCompanion { module, target } => format!(
191                "the facade `{}` has no companion for the `{}` target",
192                module.as_str(),
193                target
194            ),
195            Error::Effectful { name, .. } => format!(
196                "`{}` declares an effect, which the JavaScript backend does not wrap yet",
197                name.as_str()
198            ),
199            Error::Unchecked { name, .. } => format!(
200                "`{}` cannot be compiled to JavaScript, because the type checker could not check it",
201                name.as_str()
202            ),
203            Error::Unsupported {
204                construct,
205                declaration,
206                ..
207            } => format!(
208                "`{}` cannot be compiled to JavaScript yet: it uses {}",
209                declaration.as_str(),
210                construct.describe()
211            ),
212        }
213    }
214
215    fn labels(&self) -> Vec<SpanLabel> {
216        let (span, message) = match self {
217            // No span exists for a `module foreign` line today — nothing in the parsed
218            // or canonical AST carries the module header's position, only each
219            // declaration's — so this names the facade and the target in `message()`
220            // alone.
221            Error::MissingCompanion { .. } => return Vec::new(),
222            Error::Effectful { span, .. } => (span, "not marked `unsafe`"),
223            Error::Unchecked { span, .. } => (span, "this declaration"),
224            Error::Unsupported { span, .. } => (span, "not supported by the JavaScript backend"),
225        };
226
227        match span.span() {
228            Some(span) => vec![SpanLabel {
229                span,
230                message: message.to_owned(),
231                primary: true,
232                file: None,
233            }],
234            None => Vec::new(),
235        }
236    }
237}

300/// The JavaScript name of a name the Zelkova source wrote: a declaration of this module,
301/// a parameter, or a name a pattern bound.
302///
303/// **The scheme.** A name in [`RESERVED`] gets a `$` prefix — `class` is `$class` — and
304/// every other name is left as it is: `classy` is `classy`. A Zelkova identifier is
305/// letters and digits as Unicode classifies them, and `_` — what JavaScript accepts in an
306/// identifier too — and never contains a `$`. That is what makes the scheme unable to merge two names: a name left
307/// alone has no `$`, a renamed one starts with the only `$` it has, and the prefix is
308/// removed by reading past it.
309///
310/// Every other name an emitted module declares is the emitter's own, and each is built
311/// so that it cannot be one this function returns:
312///
313/// - the runtime's helpers, `$curry` and `$abort`: a `$` and a word that is not in
314///   [`RESERVED`];
315/// - a hoisted constructor, [`hoisted`]: a `$` followed by a name that contains
316///   another `$`;
317/// - a value imported from another module, [`imported`]: a `$` that is not the first
318///   character;
319/// - a wildcard parameter, [`wildcard`]: `$_` and a number, and `_0`, `_1`, … are not in
320///   [`RESERVED`];
321/// - a parameter written as a pattern, [`ir::pattern_parameter`]: `$` and a number,
322///   which this function leaves as it is, since nothing in [`RESERVED`] holds a `$`.
323fn mangle(name: &str) -> String {
324    if RESERVED.contains(&name) {
325        format!("${}", name)
326    } else {
327        name.to_string()
328    }
329}
330
331/// The name of the `position`th parameter of a declaration, when the source wrote `_`
332/// there: `$_0`, `$_1`, ….
333///
334/// Nothing reads it; it exists because two parameters of one JavaScript function may not
335/// share a name, and `f _ _` has two. See [`mangle`] for why it cannot meet another name.
336fn wildcard(position: usize) -> String {
337    format!("$_{}", position)
338}
339
340/// The module-level constant a constructor of no arguments is hoisted to: `$`, then the
341/// segments of the module declaring its union and its own name, joined by `$` — `Test`'s
342/// `Red` is `$Test$Red`.
343fn hoisted(union: &QualName, constructor: &Name) -> String {
344    format!(
345        "${}${}",
346        union.module_name().as_str().replace('.', "$"),
347        constructor.as_str()
348    )
349}
350
351/// The local name a value another module declares is imported under: the module's
352/// segments and the value's name, joined by `$` — `Maybe.withDefault` is
353/// `Maybe$withDefault`.
354///
355/// A value is never imported under its own name, because this module may declare the
356/// same name itself.
357fn imported(module: &str, name: &str) -> String {
358    format!("{}${}", module.replace('.', "$"), name)
359}
360
361/// The name of the field a constructor's argument at `index` is stored in: `a`, `b`, …
362/// `z`, then `aa`, `ab`, … — the spreadsheet column sequence, which carries on the
363/// published `a`, `b`, `c` past the alphabet without two indices sharing a name.
364fn field(index: usize) -> String {
365    let mut letters = Vec::new();
366    let mut remaining = index + 1;
367
368    while remaining > 0 {
369        remaining -= 1;
370        letters.push((b'a' + (remaining % 26) as u8) as char);
371        remaining /= 26;
372    }
373
374    letters.iter().rev().collect()
375}

379/// How many directories below its package's output directory the emitted file for
380/// `module` sits: one per segment of its name but the last.
381fn depth(module: &Name) -> usize {
382    module.as_str().split('.').count() - 1
383}
384
385/// The specifier the module named `from` imports the module named `to` by.
386///
387/// **Provisional, until [`GEN-13`](../../../docs/tickets/gen-13.md) settles the output
388/// layout**, and the only function that would change when it does. Each module is
389/// assumed to be at `<module path>.mjs` below one directory per package, as [`DEC-18`
390/// decision 5](../../../docs/decisions/dec-18.md#5--output-is-written-per-package-beside-the-root-manifest)
391/// has it, and both modules are assumed to be in the same package: a module name is all
392/// an [`ir::ReferenceKind::Foreign`] carries, and it does not say which package declared
393/// it.
394fn module_specifier(from: &Name, to: &Name) -> String {
395    let up = match depth(from) {
396        0 => "./".to_string(),
397        depth => "../".repeat(depth),
398    };
399
400    format!("{}{}.mjs", up, to.as_str().replace('.', "/"))
401}
402
403/// The specifier the module named `from` imports the runtime by.
404///
405/// **Provisional**, like [`module_specifier`]: the runtime is assumed to be at the root
406/// of the output, above every package's directory, which is where
407/// [`GEN-13`](../../../docs/tickets/gen-13.md) names as the obvious candidate.
408fn runtime_specifier(from: &Name) -> String {
409    format!("{}zelkova.mjs", "../".repeat(depth(from) + 1))
410}
411
412/// The specifier a facade named `module` imports its own companion by.
413///
414/// **Provisional**, like [`module_specifier`]: assumes the companion sits beside this
415/// module's own emitted file, sharing the last segment of its name — `Js.Basics`
416/// imports `./Basics.mjs` — which is where it sits beside the `.zel` source today
417/// ([*A facade names a boundary, not a
418/// backend*](../../../docs/spec/interop.md#a-facade-names-a-boundary-not-a-backend)).
419/// Whether the facade's own emitted file and the companion can share that same output
420/// path, and copying the companion there at all, is
421/// [`GEN-13`](../../../docs/tickets/gen-13.md)'s to settle.
422fn companion_specifier(module: &Name) -> String {
423    let last = module
424        .as_str()
425        .rsplit('.')
426        .next()
427        .unwrap_or(module.as_str());
428    format!("./{}.mjs", last)
429}

433/// A JavaScript string literal holding `c` and nothing else.
434fn char_literal(c: char) -> String {
435    let escaped = match c {
436        '"' => "\\\"".to_string(),
437        '\\' => "\\\\".to_string(),
438        '\n' => "\\n".to_string(),
439        '\r' => "\\r".to_string(),
440        '\t' => "\\t".to_string(),
441        // Control characters, and the two line terminators JavaScript source treats
442        // specially, as escapes rather than raw.
443        c if c.is_control() || c == '\u{2028}' || c == '\u{2029}' => {
444            format!("\\u{{{:x}}}", c as u32)
445        }
446        c => c.to_string(),
447    };
448
449    format!("\"{}\"", escaped)
450}

452/// A JavaScript number literal for `f`.
453///
454/// `{:?}` is Rust's shortest representation that reads back as the same `f64`, and
455/// every finite one it writes — `1.0`, `0.1`, `1e300` — is also a JavaScript number
456/// literal of that value. No literal a source can write is infinite or `NaN`; they are
457/// covered so that nothing here can write something that is not JavaScript.
458fn float_literal(f: f64) -> String {
459    if f.is_nan() {
460        "NaN".to_string()
461    } else if f == f64::INFINITY {
462        "Infinity".to_string()
463    } else if f == f64::NEG_INFINITY {
464        "-Infinity".to_string()
465    } else {
466        format!("{:?}", f)
467    }
468}

470// ── Emitting a module ─────────────────────────────────────────────────────────

472/// The JavaScript text of `module`, or every reason it cannot be emitted.
473///
474/// `has_companion` is irrelevant to any module but a `module foreign` facade, for which
475/// it says whether a JavaScript companion sits beside it for the target being built.
476/// [`emit`] has no path of its own to check that with — the caller does, since only it
477/// knows where `module`'s source came from — so a facade with no companion is
478/// [`Error::MissingCompanion`] rather than something this function discovers.
479///
480/// See this module's documentation for the shape of the text.
481pub fn emit(module: &CheckedModule, has_companion: bool) -> Result<String, Vec<Error>> {
482    let ir = &module.ir;
483
484    if ir.foreign && !has_companion {
485        return Err(vec![Error::MissingCompanion {
486            module: ir.name.name().clone(),
487            target: "javascript",
488        }]);
489    }
490
491    let mut emitter = Emitter {
492        arities: ir
493            .declarations
494            .iter()
495            .map(|declaration| (declaration.name.clone(), declaration.arity))
496            .collect(),
497        runtime: BTreeSet::new(),
498        imports: BTreeMap::new(),
499        module: ir.name.name().clone(),
500        imported_constructors: BTreeMap::new(),
501        errors: ir
502            .unchecked
503            .iter()
504            .map(|unchecked| Error::Unchecked {
505                name: unchecked.name.clone(),
506                span: unchecked.span,
507            })
508            .collect(),
509        declaration: None,
510    };
511
512    let mut functions = Vec::new();
513    let mut constants: HashMap<&Name, String> = HashMap::new();
514    let mut companion_imports: Vec<String> = Vec::new();
515
516    for declaration in &ir.declarations {
517        emitter.declaration = Some(declaration.name.clone());
518
519        if ir.foreign {
520            emitter.facade_declaration(
521                &module.canonical,
522                declaration,
523                &mut functions,
524                &mut constants,
525                &mut companion_imports,
526            );
527            continue;
528        }
529
530        // Every declaration of a module that is not a facade has a body; one without
531        // would be a facade signature, handled above.
532        let Some(body) = &declaration.body else {
533            continue;
534        };
535
536        let expression = emitter.expression(&body.expression);
537        let name = mangle(declaration.name.as_str());
538
539        if body.parameters.is_empty() {
540            constants.insert(
541                &declaration.name,
542                format!("const {} = {};", name, expression),
543            );
544        } else {
545            let parameters: Vec<String> = body
546                .parameters
547                .iter()
548                .enumerate()
549                .map(|(position, parameter)| match parameter.name.as_str() {
550                    "_" => wildcard(position),
551                    other => mangle(other),
552                })
553                .collect();
554
555            functions.push(format!(
556                "function {}({}) {{\n  return {};\n}}",
557                name,
558                parameters.join(", "),
559                expression
560            ));
561        }
562    }
563
564    if !emitter.errors.is_empty() {
565        return Err(emitter.errors);
566    }
567
568    // The parameterless bindings, in the order they have to be initialised. Every one
569    // of them is in that order; a binding that somehow was not would still be emitted,
570    // after the rest and in name order, rather than lost.
571    let mut ordered = Vec::new();
572    for name in &ir.initialisation_order {
573        if let Some(constant) = constants.remove(name) {
574            ordered.push(constant);
575        }
576    }
577    let mut leftover: Vec<(&Name, String)> = constants.into_iter().collect();
578    leftover.sort_by(|left, right| left.0.as_str().cmp(right.0.as_str()));
579    ordered.extend(leftover.into_iter().map(|(_, constant)| constant));
580
581    let mut hoisted = hoisted_constructors(ir);
582    hoisted.extend(
583        emitter
584            .imported_constructors
585            .iter()
586            .map(|(local, name)| format!("const {} = {{$: \"{}\"}};", local, name.as_str())),
587    );
588
589    let mut sections: Vec<String> = Vec::new();
590
591    let mut imports = Vec::new();
592    if !emitter.runtime.is_empty() {
593        let helpers: Vec<&str> = emitter.runtime.iter().copied().collect();
594        imports.push(format!(
595            "import {{ {} }} from \"{}\";",
596            helpers.join(", "),
597            runtime_specifier(ir.name.name())
598        ));
599    }
600    if !companion_imports.is_empty() {
601        imports.push(format!(
602            "import {{ {} }} from \"{}\";",
603            companion_imports.join(", "),
604            companion_specifier(ir.name.name())
605        ));
606    }
607    for (from, names) in &emitter.imports {
608        let specifiers: Vec<String> = names
609            .iter()
610            .map(|name| format!("{} as {}", name, imported(from, name)))
611            .collect();
612        imports.push(format!(
613            "import {{ {} }} from \"{}\";",
614            specifiers.join(", "),
615            module_specifier(ir.name.name(), &Name::new(from.as_str()))
616        ));
617    }
618
619    for section in [imports, hoisted, ordered_functions(functions), ordered] {
620        if !section.is_empty() {
621            sections.push(section.join("\n"));
622        }
623    }
624
625    let exports = exports(module);
626    if !exports.is_empty() {
627        sections.push(format!("export {{ {} }};", exports.join(", ")));
628    }
629
630    let mut text = sections.join("\n\n");
631    text.push('\n');
632    Ok(text)
633}

635/// Functions are separated from each other by a blank line, which joining the section
636/// with one more newline gives.
637fn ordered_functions(functions: Vec<String>) -> Vec<String> {
638    functions
639        .into_iter()
640        .enumerate()
641        .map(|(index, function)| {
642            if index == 0 {
643                function
644            } else {
645                format!("\n{}", function)
646            }
647        })
648        .collect()
649}

651/// One `const` per constructor of no arguments the module declares, unions in the IR's
652/// name order and each union's constructors in declaration order.
653///
654/// `Bool`'s two are not among them: they are `true` and `false`.
655fn hoisted_constructors(ir: &ir::Module) -> Vec<String> {
656    ir.unions
657        .iter()
658        .filter(|union| !scalars::BOOL.declares(&union.name))
659        .flat_map(|union| {
660            union
661                .variants
662                .iter()
663                .filter(|variant| variant.arity == 0)
664                .map(move |variant| {
665                    format!(
666                        "const {} = {{$: \"{}\"}};",
667                        hoisted(&union.name, &variant.name),
668                        variant.name.as_str()
669                    )
670                })
671        })
672        .collect()
673}

675/// The export specifiers for the values `module` exposes, in name order: a value its
676/// `exposing` header names, or the function an exposed operator stands for.
677///
678/// Each is exported under its Zelkova name, so a renamed one reads `$class as class` —
679/// an export's name may be a reserved word where a binding's may not.
680fn exports(module: &CheckedModule) -> Vec<String> {
681    let exposed = |name: &Name| match &module.canonical.exports {
682        Exports::Everything => true,
683        Exports::Specifics(specifics) => {
684            specifics.get(name) == Some(&ExportType::Value)
685                || specifics.iter().any(|(symbol, kind)| {
686                    *kind == ExportType::Infix
687                        && module
688                            .canonical
689                            .infixes
690                            .get(symbol)
691                            .is_some_and(|infix| &infix.function_name == name)
692                })
693        }
694    };
695
696    module
697        .ir
698        .declarations
699        .iter()
700        .filter(|declaration| exposed(&declaration.name))
701        .map(|declaration| {
702            let local = mangle(declaration.name.as_str());
703            if local == declaration.name.as_str() {
704                local
705            } else {
706                format!("{} as {}", local, declaration.name.as_str())
707            }
708        })
709        .collect()
710}

712// ── Emitting an expression ────────────────────────────────────────────────────
713
714struct Emitter {
715    /// How many parameters each of this module's declarations takes.
716    arities: HashMap<Name, usize>,
717    /// The runtime helpers the emitted text calls.
718    runtime: BTreeSet<&'static str>,
719    /// The values of other modules the emitted text mentions, by the module declaring
720    /// each.
721    imports: BTreeMap<String, BTreeSet<String>>,
722    /// The module being emitted, which tells a constructor it declares from one another
723    /// module does.
724    module: Name,
725    /// The constructors of no arguments another module declares that the emitted text
726    /// mentions, by the name each is hoisted to. This module hoists its own constant for
727    /// each, since the declaring module exports none.
728    imported_constructors: BTreeMap<String, Name>,
729    errors: Vec<Error>,
730    /// The declaration being emitted, which an [`Error::Unsupported`] names.
731    declaration: Option<Name>,
732}
733
734impl Emitter {
735    fn unsupported(&mut self, construct: Construct, span: NodeSpan) -> String {
736        self.errors.push(Error::Unsupported {
737            construct,
738            declaration: self.declaration.clone().unwrap_or_else(|| Name::new("")),
739            span,
740        });
741        // Never part of an emitted module: an error means `emit` answers `Err`.
742        String::new()
743    }
744
745    fn curry(&mut self, function: &str, arity: usize) -> String {
746        self.runtime.insert("$curry");
747        format!("$curry({}, {})", function, arity)
748    }
749
750    /// One `module foreign` facade declaration's forwarding code, appended to
751    /// `functions` or `constants` — a plain function at arity one or more, a `const`
752    /// at arity zero — plus the companion import it needs, appended to
753    /// `companion_imports`.
754    ///
755    /// Only for a signature marked `unsafe`: one that is not declares an effect
756    /// ([An effectful facade](../../../docs/spec/interop.md#an-effectful-facade)),
757    /// which this backend does not wrap yet, so [`Error::Effectful`] is pushed instead
758    /// and nothing is appended for it.
759    fn facade_declaration<'a>(
760        &mut self,
761        canonical: &super::canonical::Module,
762        declaration: &'a ir::Declaration,
763        functions: &mut Vec<String>,
764        constants: &mut HashMap<&'a Name, String>,
765        companion_imports: &mut Vec<String>,
766    ) {
767        let marked_unsafe = matches!(
768            canonical.values.get(&declaration.name),
769            Some(Value::TypedValue {
770                marked_unsafe: true,
771                ..
772            })
773        );
774
775        if !marked_unsafe {
776            self.errors.push(Error::Effectful {
777                name: declaration.name.clone(),
778                span: declaration.span,
779            });
780            return;
781        }
782
783        // The companion's export is imported under an alias — never the plain name,
784        // which this method is about to declare a local binding under, and a module
785        // cannot import and declare the same name twice.
786        let local = mangle(declaration.name.as_str());
787        let alias = imported(self.module.as_str(), declaration.name.as_str());
788        companion_imports.push(format!("{} as {}", declaration.name.as_str(), alias));
789
790        if declaration.arity == 0 {
791            constants.insert(&declaration.name, format!("const {} = {};", local, alias));
792        } else {
793            let parameters: Vec<String> = (0..declaration.arity).map(field).collect();
794            functions.push(format!(
795                "function {}({}) {{\n  return {}({});\n}}",
796                local,
797                parameters.join(", "),
798                alias,
799                parameters.join(", ")
800            ));
801        }
802    }
803
804    fn expression(&mut self, term: &TypedTerm) -> String {
805        match &term.kind {
806            TypedTermKind::Int(i) => format!("{}n", i),
807            TypedTermKind::Float(f) => float_literal(*f),
808            TypedTermKind::Char(c) => char_literal(*c),
809            TypedTermKind::Bool(b) => b.to_string(),
810            TypedTermKind::Identifier(reference) => self.value(&reference.name, &reference.kind),
811            TypedTermKind::Apply { .. } => self.application(term),
812            TypedTermKind::If {
813                cond,
814                true_branch,
815                false_branch,
816            } => {
817                let cond = self.operand(cond);
818                let true_branch = self.expression(true_branch);
819                let false_branch = self.expression(false_branch);
820                format!("{} ? {} : {}", cond, true_branch, false_branch)
821            }
822            TypedTermKind::Tuple(tuple) => {
823                let elements: Vec<String> = tuple
824                    .iter()
825                    .map(|element| self.expression(element))
826                    .collect();
827                format!("[{}]", elements.join(", "))
828            }
829            TypedTermKind::Case {
830                scrutinee,
831                branches,
832                form,
833            } => self.case_expression(scrutinee, branches, *form),
834            TypedTermKind::Let { .. } => self.unsupported(Construct::Let, term.span),
835            TypedTermKind::Fun { .. } => self.unsupported(Construct::Lambda, term.span),
836        }
837    }
838
839    /// An expression in a position where a conditional has to be parenthesised: the
840    /// condition of another conditional, and the function of a call.
841    fn operand(&mut self, term: &TypedTerm) -> String {
842        let text = self.expression(term);
843        match term.kind {
844            TypedTermKind::If { .. } => format!("({})", text),
845            _ => text,
846        }
847    }
848
849    /// A name used as a value rather than called.
850    fn value(&mut self, name: &str, kind: &ReferenceKind) -> String {
851        match kind {
852            ReferenceKind::Local => mangle(name),
853            ReferenceKind::TopLevel(qname) => {
854                let unqualified = qname.unqualified_name();
855                let local = mangle(unqualified.as_str());
856                match self.arities.get(&unqualified).copied() {
857                    Some(arity) if arity >= 2 => self.curry(&local, arity),
858                    _ => local,
859                }
860            }
861            ReferenceKind::Foreign(qname) => {
862                let module = qname.module_name().as_str().to_string();
863                let name = qname.unqualified_name().as_str().to_string();
864                let local = imported(&module, &name);
865                self.imports.entry(module).or_default().insert(name);
866                local
867            }
868            ReferenceKind::Constructor(ctor) => {
869                if scalars::BOOL.declares(&ctor.union) {
870                    match ctor.name.as_str() {
871                        "True" => return "true".to_string(),
872                        "False" => return "false".to_string(),
873                        _ => {}
874                    }
875                }
876
877                match ctor.arity {
878                    0 => {
879                        let local = hoisted(&ctor.union, &ctor.name);
880                        if ctor.union.module_name() != self.module {
881                            self.imported_constructors
882                                .insert(local.clone(), ctor.name.clone());
883                        }
884                        local
885                    }
886                    arity => {
887                        let parameters: Vec<String> = (0..arity).map(field).collect();
888                        let function = format!(
889                            "({}) => ({})",
890                            parameters.join(", "),
891                            tagged(&ctor.name, parameters.clone())
892                        );
893                        if arity >= 2 {
894                            self.curry(&function, arity)
895                        } else {
896                            function
897                        }
898                    }
899                }
900            }
901        }
902    }
903
904    /// An application spine: a direct call up to the node the IR marks saturated, if
905    /// there is one, then one call per remaining argument.
906    fn application(&mut self, term: &TypedTerm) -> String {
907        let mut arguments = Vec::new();
908        let mut head = term;
909        while let TypedTermKind::Apply {
910            fun,
911            arg,
912            saturation,
913        } = &head.kind
914        {
915            arguments.push((arg.as_ref(), *saturation));
916            head = fun;
917        }
918        arguments.reverse();
919
920        let saturated = arguments
921            .iter()
922            .position(|(_, saturation)| *saturation == Saturation::Saturated);
923
924        // Evaluated in the order written: the function, then each argument.
925        let (mut callee, rest) = match (&head.kind, saturated) {
926            (TypedTermKind::Identifier(reference), Some(last)) => match &reference.kind {
927                ReferenceKind::TopLevel(qname) => {
928                    let supplied = self.arguments(&arguments[..=last]);
929                    (
930                        format!(
931                            "{}({})",
932                            mangle(qname.unqualified_name().as_str()),
933                            supplied.join(", ")
934                        ),
935                        &arguments[last + 1..],
936                    )
937                }
938                ReferenceKind::Constructor(ctor) => {
939                    let supplied = self.arguments(&arguments[..=last]);
940                    let fields: Vec<String> = supplied;
941                    (tagged(&ctor.name, fields), &arguments[last + 1..])
942                }
943                _ => (self.operand(head), &arguments[..]),
944            },
945            _ => (self.operand(head), &arguments[..]),
946        };
947
948        for (argument, _) in rest {
949            let argument = self.expression(argument);
950            callee = format!("{}({})", callee, argument);
951        }
952
953        callee
954    }
955
956    fn arguments(&mut self, arguments: &[(&TypedTerm, Saturation)]) -> Vec<String> {
957        arguments
958            .iter()
959            .map(|(argument, _)| self.expression(argument))
960            .collect()
961    }

963    /// A `case … of`, or a parameter written as a pattern — the IR's single-branch
964    /// match on it ([`ir::CaseForm::Parameter`]), which lowers and emits the same way.
965    /// See this module's doc comment, "A `case`", for the shape.
966    ///
967    /// `scrutinee` is evaluated exactly once — bound to `$scrutinee` before the tree is
968    /// walked — never once per test, which is what a decision tree built by
969    /// [`decision_tree`] wants: [Order of
970    /// evaluation](../../../docs/spec/evaluation-semantics.md#order-of-evaluation).
971    ///
972    /// `form` says whether the source wrote a `case … of` or a parameter pattern
973    /// ([`ir::CaseForm`]) and reaches [`abort_description`] unchanged, so a
974    /// [`Decision::Fail`] this tree needs describes itself in the vocabulary the source
975    /// actually used.
976    ///
977    /// Mutation-checked by re-emitting `self.expression(scrutinee)` at every
978    /// [`Decision::Test`] instead of binding it once: a `case` whose scrutinee is a call
979    /// then contains that call's text more than once.
980    fn case_expression(
981        &mut self,
982        scrutinee: &TypedTerm,
983        branches: &[(ir::TermPattern, Box<TypedTerm>)],
984        form: CaseForm,
985    ) -> String {
986        let declaration = self.declaration.clone().unwrap_or_else(|| Name::new(""));
987        let tree = decision_tree(&scrutinee.tpe, branches, &declaration);
988        let scrutinee_expr = self.expression(scrutinee);
989        let body = self.decision(&tree, "$scrutinee", 1, form);
990
991        format!(
992            "(() => {{\n  const $scrutinee = {};\n{}\n}})()",
993            scrutinee_expr, body
994        )
995    }
996
997    /// One [`Decision`] node as the statements of an `if`/`else` chain, each line
998    /// indented `depth` levels of two spaces — the body of [`case_expression`]'s
999    /// immediately invoked function. `root` is the name the scrutinee is bound to,
1000    /// which [`occurrence_expr`] reads a test's or a binding's value off; `form` is
1001    /// passed through unchanged to [`abort_description`].
1002    ///
1003    /// A [`Decision::Test`] nests: its `matched` and `default` are each a full
1004    /// [`Decision`] emitted one level deeper, so a chain of tests on the scrutinee comes
1005    /// out as `if`s nested in one another's `else`, never merged or reordered — the
1006    /// order [Conditional
1007    /// evaluation](../../../docs/spec/evaluation-semantics.md#conditional-evaluation)
1008    /// tries branches in. A [`Decision::Leaf`] declares its bindings as `const`s, each
1009    /// read off `root` by [`occurrence_expr`], ahead of a `return` of its body — all of
1010    /// it inside its own block, so a binding never shares a scope with the
1011    /// `$scrutinee` line above it. Sharing that scope is observable: a binding may name
1012    /// anything the pattern it comes from could ([Variable
1013    /// patterns](../../../docs/spec/patterns.md#variable-patterns) lets one repeat a
1014    /// name already in scope), and a `const` anywhere in a block puts every reference to
1015    /// that name earlier in the *same* block in its temporal dead zone — so without the
1016    /// leaf's own block, a scrutinee expression that happens to read a name a leaf also
1017    /// binds would throw `ReferenceError` before ever reaching the leaf. A
1018    /// [`Decision::Fail`] returns the runtime's `$abort`, importing it the way `$curry`
1019    /// is imported; it carries no binding, so it needs no block of its own.
1020    fn decision(&mut self, tree: &Decision, root: &str, depth: usize, form: CaseForm) -> String {
1021        let pad = "  ".repeat(depth);
1022
1023        match tree {
1024            Decision::Test {
1025                scrutinee,
1026                outcome,
1027                matched,
1028                default,
1029            } => {
1030                let condition = test_condition(root, scrutinee, outcome);
1031                let matched = self.decision(matched, root, depth + 1, form);
1032                let default = self.decision(default, root, depth + 1, form);
1033                format!(
1034                    "{pad}if ({condition}) {{\n{matched}\n{pad}}} else {{\n{default}\n{pad}}}",
1035                    pad = pad,
1036                    condition = condition,
1037                    matched = matched,
1038                    default = default,
1039                )
1040            }
1041            Decision::Leaf { bindings, body } => {
1042                let inner_pad = "  ".repeat(depth + 1);
1043                let mut lines: Vec<String> = bindings
1044                    .iter()
1045                    .map(|binding| {
1046                        format!(
1047                            "{}const {} = {};",
1048                            inner_pad,
1049                            mangle(&binding.name),
1050                            occurrence_expr(root, &binding.occurrence)
1051                        )
1052                    })
1053                    .collect();
1054                lines.push(format!("{}return {};", inner_pad, self.expression(body)));
1055                format!("{pad}{{\n{}\n{pad}}}", lines.join("\n"), pad = pad)
1056            }
1057            Decision::Fail { declaration } => {
1058                self.runtime.insert("$abort");
1059                format!(
1060                    "{}return $abort({});",
1061                    pad,
1062                    abort_description(declaration, form)
1063                )
1064            }
1065        }
1066    }
1067}
1068
1069/// The condition a [`Decision::Test`] compiles to: an equality check against the value
1070/// [`occurrence_expr`] reads off `root`. A constructor is tested by its `$` field — a
1071/// `Bool`'s constructors never reach here, since `typer::translate_pattern` normalises
1072/// `True`/`False` to the same [`Outcome::Literal`] a `true`/`false` pattern is — and a
1073/// literal by the value itself, which is also how a `case` on a `Bool` tests it (see
1074/// this module's doc comment, "Representations").
1075fn test_condition(root: &str, occurrence: &Occurrence, outcome: &Outcome) -> String {
1076    let value = occurrence_expr(root, occurrence);
1077
1078    match outcome {
1079        Outcome::Literal(LiteralValue::Bool(b)) => format!("{} === {}", value, b),
1080        Outcome::Literal(LiteralValue::Int(i)) => format!("{} === {}n", value, i),
1081        Outcome::Literal(LiteralValue::Char(c)) => format!("{} === {}", value, char_literal(*c)),
1082        Outcome::Constructor(ctor) => format!("{}.$ === \"{}\"", value, ctor.name.as_str()),
1083    }
1084}
1085
1086/// The JavaScript expression reading the value at `occurrence` off `root`, the name the
1087/// scrutinee is bound to: a constructor argument is a field ([`field`], the same one
1088/// [`tagged`] builds an object under), a tuple element an index — the representations
1089/// [A union crosses as a tagged
1090/// value](../../../docs/spec/interop.md#a-union-crosses-as-a-tagged-value) gives them.
1091fn occurrence_expr(root: &str, occurrence: &Occurrence) -> String {
1092    match occurrence {
1093        Occurrence::Root => root.to_string(),
1094        Occurrence::At(base, step) => {
1095            let base = occurrence_expr(root, base);
1096            match step {
1097                Step::ConstructorArgument(index) => format!("{}.{}", base, field(*index)),
1098                Step::TupleElement(index) => format!("{}[{}]", base, index),
1099            }
1100        }
1101    }
1102}
1103
1104/// The description a [`Decision::Fail`]'s `$abort` call carries: which declaration's
1105/// `case` — or, for [`CaseForm::Parameter`], parameter pattern — matched no branch. That
1106/// leaf exists only because [coverage is not checked
1107/// yet](../../../docs/spec/evaluation-semantics.md#two-outcomes) (`LANG-19`) — reaching
1108/// it aborts rather than falling through to `undefined`. `form` keeps the message in the
1109/// vocabulary the source actually used: a parameter written as a pattern has no `case`
1110/// for the message to name.
1111fn abort_description(declaration: &Name, form: CaseForm) -> String {
1112    match form {
1113        CaseForm::Expression => {
1114            format!("\"`{}`'s case matched no branch\"", declaration.as_str())
1115        }
1116        CaseForm::Parameter => format!(
1117            "\"`{}`'s parameter pattern matched no branch\"",
1118            declaration.as_str()
1119        ),
1120    }
1121}

1123/// The tagged object a constructor builds, each argument in the field [`field`] names
1124/// for its position.
1125fn tagged(name: &Name, arguments: Vec<String>) -> String {
1126    let mut fields = vec![format!("$: \"{}\"", name.as_str())];
1127    fields.extend(
1128        arguments
1129            .into_iter()
1130            .enumerate()
1131            .map(|(index, argument)| format!("{}: {}", field(index), argument)),
1132    );
1133    format!("{{{}}}", fields.join(", "))
1134}
