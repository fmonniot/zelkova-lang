1//! Class obligations: what a use of a constrained name asks of its types, and how the
2//! answer is found once unification has run.
3//!
4//! A use of a name whose type has a context — a class member, whose context is its class,
5//! or a function whose annotation wrote one — instantiates that context at the types the
6//! use gave the name's variables. Each constraint becomes an [`Obligation`]: a class, a
7//! type and an [`Origin`] naming the use. An obligation is not an equation, and `unify`
8//! cannot answer it on sight: `Comparable t7` waits on what `t7` turns out to be. So
9//! obligations are collected beside the equations (`constraint::Constraints`), left alone
10//! while [`unify`](super::unifier::unify) and `read_fields` run, and [`discharge`]d
11//! against the final substitution, in the order they were collected.
12//!
13//! # How an obligation is answered
14//!
15//! With the substitution applied, its type is one of three things.
16//!
17//! - **A declared type, a tuple or `()`.** [The head
18//!   rule](../../../docs/spec/type-classes.md#what-an-instance-is-declared-for) makes the
19//!   instance a lookup by the class and the name at the front of the type, with at most
20//!   one answer. None is [`ErrorKind::NoInstance`]. An instance with a context asks more:
21//!   its constraints, instantiated at the type's arguments, are obligations in their
22//!   turn, so `Eq (Maybe Colour)` asks for `Eq Colour`. Each is on a strictly smaller
23//!   type, so the asking stops.
24//! - **A function type.** No instance can be declared for one, so the same error.
25//! - **A record type.** Accepted, with no further obligation. A record is no instance's
26//!   head, so there is no lookup to make; a class that carries a derivation walks a record
27//!   field by field ([`records.md`](../../../docs/spec/records.md#records-and-derivation)),
28//!   which [`LANG-85`](../../../docs/tickets/lang-85.md) implements. Until it does an
29//!   obligation at a record is neither answered nor refused.
30//! - **A variable.** It is answered if a *given* provides it, and otherwise it is left for
31//!   the declaration to account for: see below.
32//!
33//! # What is given
34//!
35//! The context an annotation wrote — or an instance wrote, for the bindings of its body —
36//! is given inside the declaration, and not proved. A given is on a rigid variable: the one
37//! the annotation's variable was translated to, which `unify` does not solve to a type (see
38//! [`TypeVariable`]). It answers an obligation on that same variable and on nothing else. A
39//! superclass is implied by its subclass, transitively, so `Comparable a` provides `Eq a`.
40//!
41//! **A given cannot follow its variable to a type.** `min : Comparable a => a -> a -> a`
42//! over a body that makes `a` an `Int` never reaches an obligation: `unify` refuses to solve
43//! `a`, and the declaration is [`ErrorKind::RigidVariable`] before any obligation is read.
44//! So an obligation still on a variable of the declaration's type is on a rigid one, and
45//! the only thing that answers it is a given on it.
46//!
47//! # What a variable that nothing provides is
48//!
49//! An obligation still on a variable, with no given on it, is one of three errors, told
50//! apart because the fix differs.
51//!
52//! - The variable is part of the declaration's type and the declaration has an annotation:
53//!   the annotation is missing the constraint ([`ErrorKind::MissingConstraint`]). An
54//!   instance's binding counts as annotated, by its member's signature at the head. A
55//!   variable of that signature the head does not bind is the same error written as
56//!   [`Written::MemberSignature`](super::Written::MemberSignature), because no context of
57//!   the instance can be on a variable the head does not bind.
58//! - The variable is part of the declaration's type and the declaration has none: it
59//!   needs one, because a constraint is never inferred
60//!   ([`ErrorKind::ConstraintNeedsAnnotation`]).
61//! - The variable is not part of the declaration's type: nothing determines the type the
62//!   class is needed at, and no annotation on this declaration can
63//!   ([`ErrorKind::UndeterminedConstraint`]).
64//!
65//! The obligations are read in the order they were collected, and the error reported is
66//! the one whose obligation came first. A variable is not reported the moment it is met:
67//! the error for a declaration with no annotation says everything the declaration has to
68//! state, which takes every obligation on a variable of its type, so those are collected
69//! first. A missing instance ends the reading at once unless a variable was met before it.

85/// A class required of a type, and the use that required it.
86///
87/// Kept in order, in a `Vec`, for the reason `Constraint` is: an unordered collection
88/// would make which of several unsatisfiable obligations is reported vary between runs,
89/// and a set would drop the provenance of the duplicates it collapsed.
90#[derive(Debug, Clone)]
91pub(super) struct Obligation {
92    pub(super) class: QualName,
93    pub(super) tpe: Type,
94    pub(super) origin: Origin,
95}
96
97impl Obligation {
98    pub(super) fn new(predicate: Predicate, reason: Reason, span: NodeSpan) -> Obligation {
99        Obligation {
100            class: predicate.class,
101            tpe: predicate.tpe,
102            origin: Origin::new(reason, span),
103        }
104    }
105}

107/// Every class and instance a module can see: its own, and the ones its imports bring.
108///
109/// A class is found by the name of its declaration, which is what a constraint and an
110/// instance both carry; an instance by its class and the name at the front of its head,
111/// which [identify an instance](crate::canonical::HeadName) exactly.
112pub(super) struct ClassTable<'a> {
113    classes: HashMap<QualName, &'a ClassSignature>,
114    instances: HashMap<(QualName, HeadName), &'a InstanceSignature>,
115}
116
117impl<'a> ClassTable<'a> {
118    /// The classes of `module` and of each interface it was checked against, and every
119    /// instance in scope in `module`: its own and the ones its imports brought.
120    ///
121    /// An interface carries only the classes its module exposes, so a class that no
122    /// import exposes is not here, and neither is the superclass of one that is, when its
123    /// declaring module is not imported. That leaves a superclass of a superclass out of
124    /// the givens in the one case where the class in the middle is exposed by nothing the
125    /// module imports.
126    pub(super) fn of(
127        module: &'a CanonicalModule,
128        interfaces: &'a HashMap<Name, Interface>,
129    ) -> ClassTable<'a> {
130        let mut classes = HashMap::new();
131        for interface in interfaces.values() {
132            for (name, signature) in &interface.classes {
133                classes.insert(interface.module_name.qualify_name(name), signature);
134            }
135        }
136        for (name, class) in &module.classes {
137            classes.insert(module.name.qualify_name(name), &class.signature);
138        }
139
140        // The module's own instances go in last, so that were one reachable by both
141        // routes, the declaration in front of the typer is the one that answers.
142        let mut instances = HashMap::new();
143        let published = module
144            .imported_instances
145            .iter()
146            .map(|published| &published.signature);
147        let own = module.instances.iter().map(|instance| &instance.signature);
148        for signature in published.chain(own) {
149            instances.insert((signature.class.clone(), signature.head.name()), signature);
150        }
151
152        ClassTable { classes, instances }
153    }
154
155    /// A table that knows no class and no instance, for a caller with nothing to discharge
156    /// against.
157    pub(super) fn empty() -> ClassTable<'a> {
158        ClassTable {
159            classes: HashMap::new(),
160            instances: HashMap::new(),
161        }
162    }
163
164    /// The signature of `class`, when a module in reach exposes it.
165    pub(super) fn class(&self, class: &QualName) -> Option<&'a ClassSignature> {
166        self.classes.get(class).copied()
167    }
168
169    /// `class` required of `tpe`, and every superclass that implies, added to `into`.
170    fn provide(&self, class: &QualName, tpe: &Type, into: &mut Vec<(QualName, Type)>) {
171        if into.iter().any(|(c, t)| c == class && t == tpe) {
172            return;
173        }
174        into.push((class.clone(), tpe.clone()));
175
176        if let Some(signature) = self.class(class) {
177            for superclass in &signature.superclasses {
178                self.provide(&superclass.class, tpe, into);
179            }
180        }
181    }
182}

184/// What a declaration's obligations are discharged against: its own type, and what it
185/// was given.
186pub(super) struct Declared<'a> {
187    /// The declaration's type as `annotate` built it, before the substitution. Whether a
188    /// variable is part of it is what tells [`ErrorKind::MissingConstraint`] and
189    /// [`ErrorKind::ConstraintNeedsAnnotation`] from
190    /// [`ErrorKind::UndeterminedConstraint`].
191    pub(super) tpe: &'a Type,
192    /// Whether the declaration wrote its type: an annotation, or the member signature an
193    /// instance's binding is held to.
194    pub(super) annotated: bool,
195    /// What the annotation (or the instance's context) required of its variables, each a
196    /// class and the variable it is on.
197    pub(super) given: &'a [(QualName, TypeVariable)],
198    /// The names the source wrote for the variables it constrained, which a message
199    /// writes them by.
200    pub(super) names: &'a [(TypeVariable, Name)],
201    /// The variables of the declaration's type that no context of the declaration can be
202    /// on: an instance binding's variables from its member's signature, which the head
203    /// does not bind. Empty for everything else.
204    pub(super) member_variables: &'a [TypeVariable],
205    /// What a missing constraint would have to be written in.
206    pub(super) written: Written,
207}

209/// An obligation left on a variable that nothing given provides.
210struct Residual {
211    class: QualName,
212    variable: TypeVariable,
213    origin: Origin,
214}

216/// Answer every obligation of a declaration against the final `substitution`, in the order
217/// they were collected, or report the first that has no answer.
218pub(super) fn discharge(
219    table: &ClassTable,
220    obligations: Vec<Obligation>,
221    substitution: &Substitution,
222    declared: &Declared,
223) -> Result<(), ErrorKind> {
224    if obligations.is_empty() {
225        return Ok(());
226    }
227
228    // A given is on a rigid variable, which no substitution rewrites.
229    let mut given = Vec::new();
230    for (class, variable) in declared.given {
231        table.provide(class, &Type::Variable(variable.clone()), &mut given);
232    }
233
234    let mut residuals: Vec<Residual> = Vec::new();
235
236    for obligation in obligations {
237        let predicate = Predicate {
238            class: obligation.class,
239            tpe: substitution.apply_type(&obligation.tpe),
240        };
241
242        // An instance that does not exist is reported where it is found, but only once
243        // nothing earlier is left waiting: the first obligation in order is the one named.
244        if let Err(error) = entail(
245            table,
246            &given,
247            predicate,
248            &obligation.origin,
249            None,
250            &mut residuals,
251        ) {
252            if residuals.is_empty() {
253                return Err(error);
254            }
255            break;
256        }
257    }
258
259    let Some(first) = residuals.first() else {
260        return Ok(());
261    };
262
263    let signature = substitution.apply_type(declared.tpe);
264    let in_type = free_variables_in_order(&signature);
265    let names = names_for(declared, substitution, &in_type);
266    let origin = Box::new(first.origin.clone());
267
268    if !in_type.contains(&first.variable) {
269        return Err(ErrorKind::UndeterminedConstraint {
270            class: first.class.clone(),
271            origin,
272        });
273    }
274
275    if declared.annotated {
276        // A variable the member's signature binds is the signature's to constrain: adding
277        // it to the instance's context would be a constraint on a variable the head does
278        // not bind.
279        let of_member = declared.member_variables.iter().any(|variable| {
280            substitution.apply_type(&Type::Variable(variable.clone()))
281                == Type::Variable(first.variable.clone())
282        });
283        let written = if of_member {
284            Written::MemberSignature
285        } else {
286            declared.written
287        };
288
289        return Err(ErrorKind::MissingConstraint {
290            class: first.class.clone(),
291            variable: name_of(&first.variable, &names),
292            written,
293            origin,
294        });
295    }
296
297    // What the declaration has to state is every constraint it was found to need, on the
298    // variables its type holds, each once.
299    let mut needed: Vec<(&QualName, &TypeVariable)> = Vec::new();
300    for residual in &residuals {
301        let pair = (&residual.class, &residual.variable);
302        if in_type.contains(&residual.variable) && !needed.contains(&pair) {
303            needed.push(pair);
304        }
305    }
306    let constraints: Vec<String> = needed
307        .iter()
308        .map(|(class, variable)| {
309            format!("{} {}", class.unqualified_name(), name_of(variable, &names))
310        })
311        .collect();
312    let context = match constraints.as_slice() {
313        [one] => one.clone(),
314        many => format!("({})", many.join(", ")),
315    };
316
317    Err(ErrorKind::ConstraintNeedsAnnotation {
318        class: first.class.clone(),
319        stated: format!("{} => {}", context, super::WithNames(&signature, &names)),
320        origin,
321    })
322}

324/// Answer `predicate`, which has the final substitution applied, or push what it leaves
325/// on a variable onto `residuals`.
326///
327/// `needed_by` is the obligation of the use itself when `predicate` is one of its
328/// instance's constraints, so that an error says what asked for it.
329fn entail(
330    table: &ClassTable,
331    given: &[(QualName, Type)],
332    predicate: Predicate,
333    origin: &Origin,
334    needed_by: Option<&Predicate>,
335    residuals: &mut Vec<Residual>,
336) -> Result<(), ErrorKind> {
337    let no_instance = |predicate: &Predicate| ErrorKind::NoInstance {
338        class: predicate.class.clone(),
339        tpe: Box::new(predicate.tpe.clone()),
340        needed_by: needed_by.map(|required| Box::new(required.clone())),
341        origin: Box::new(origin.clone()),
342    };
343
344    let variable = match &predicate.tpe {
345        Type::Variable(variable) => variable,
346        // No instance can be declared for a function type, by the head rule.
347        Type::Fun { .. } => return Err(no_instance(&predicate)),
348        // A record is no instance's head, so there is nothing to look up. A class with a
349        // derivation walks a record's fields (`docs/spec/records.md`, LANG-85), and nothing
350        // does yet: the obligation is accepted, asks nothing further and raises no error.
351        Type::Record(_) => return Ok(()),
352        _ => {
353            let Some((head, arguments)) = head_of(&predicate.tpe) else {
354                return Err(no_instance(&predicate));
355            };
356            let Some(instance) = table.instances.get(&(predicate.class.clone(), head)) else {
357                return Err(no_instance(&predicate));
358            };
359
360            let variables = instance.head.variables();
361            if variables.len() != arguments.len() {
362                return Err(no_instance(&predicate));
363            }
364
365            // What the instance asks of the type's arguments, in turn. Each is asked at
366            // the span of the use that started it, and says which obligation of that use
367            // it is a part of.
368            let derived = Origin::new(Reason::InstanceContext, origin.span);
369            let top = needed_by.unwrap_or(&predicate);
370            for constraint in &instance.context {
371                let Some(position) = variables
372                    .iter()
373                    .position(|variable| **variable == constraint.variable)
374                else {
375                    continue;
376                };
377
378                let Some(argument) = arguments.get(position) else {
379                    continue;
380                };
381                let required = Predicate {
382                    class: constraint.class.clone(),
383                    tpe: argument.clone(),
384                };
385                entail(table, given, required, &derived, Some(top), residuals)?;
386            }
387
388            return Ok(());
389        }
390    };
391
392    if given
393        .iter()
394        .any(|(class, tpe)| class == &predicate.class && tpe == &predicate.tpe)
395    {
396        return Ok(());
397    }
398
399    residuals.push(Residual {
400        class: predicate.class,
401        variable: variable.clone(),
402        origin: origin.clone(),
403    });
404
405    Ok(())
406}

408/// The name at the front of `tpe` an instance is looked up by, and the types that name is
409/// applied to — the ones an instance's head variables stand for. `None` for a type no
410/// instance can be declared for.
411pub(crate) fn head_of(tpe: &Type) -> Option<(HeadName, Vec<Type>)> {
412    match tpe {
413        Type::Literal(literal) => {
414            let scalar = match literal {
415                TypeLiteral::Int => scalars::INT,
416                TypeLiteral::Float => scalars::FLOAT,
417                TypeLiteral::Char => scalars::CHAR,
418                TypeLiteral::String => scalars::STRING,
419            };
420            Some((HeadName::Type(scalar.qual_name()), Vec::new()))
421        }
422        Type::Adt(name, arguments) => Some((HeadName::Type(name.clone()), arguments.clone())),
423        Type::Tuple(Tuple::Two(a, b)) => Some((
424            HeadName::TwoTuple,
425            vec![a.as_ref().clone(), b.as_ref().clone()],
426        )),
427        Type::Tuple(Tuple::Three(a, b, c)) => Some((
428            HeadName::ThreeTuple,
429            vec![a.as_ref().clone(), b.as_ref().clone(), c.as_ref().clone()],
430        )),
431        Type::Unit => Some((HeadName::Unit, Vec::new())),
432        Type::Variable(_) | Type::Fun { .. } | Type::Record(_) => None,
433    }
434}

436/// The name a message writes each variable of the declaration's type by: the one its
437/// annotation wrote where it wrote one, and otherwise a letter no annotation variable
438/// has.
439///
440/// The names an annotation wrote belong to the variables it was translated to, and a
441/// variable of the solved type is what one of those was solved to.
442fn names_for(
443    declared: &Declared,
444    substitution: &Substitution,
445    in_type: &[TypeVariable],
446) -> VariableNames {
447    let mut names = VariableNames::new();
448
449    for (variable, name) in declared.names {
450        if let Type::Variable(solved) = substitution.apply_type(&Type::Variable(variable.clone())) {
451            names.entry(solved).or_insert_with(|| name.to_string());
452        }
453    }
454
455    let mut next = 0;
456    for variable in in_type {
457        if names.contains_key(variable) {
458            continue;
459        }
460        let name = loop {
461            let candidate = letter(next);
462            next += 1;
463            if !names.values().any(|taken| taken == &candidate) {
464                break candidate;
465            }
466        };
467        names.insert(variable.clone(), name);
468    }
469
470    names
471}

473/// The `n`th variable name: `a` to `z`, then `a1`, `b1`, and on.
474pub(super) fn letter(n: usize) -> String {
475    let letter = char::from(b'a' + (n % 26) as u8);
476    match n / 26 {
477        0 => letter.to_string(),
478        round => format!("{}{}", letter, round),
479    }
480}

482/// `variable` as `names` writes it, or as an inference variable when it has no name.
483fn name_of(variable: &TypeVariable, names: &VariableNames) -> String {
484    names
485        .get(variable)
486        .cloned()
487        .unwrap_or_else(|| format!("t{}", variable.id))
488}

490/// The type an instance is for, as the typer reads it: the head's declared type applied
491/// to one variable per parameter, a tuple of variables, or `()`. Each of the head's
492/// variables is entered into `variables` under its written name.
493pub(crate) fn instance_head_type(
494    head: &InstanceHead,
495    variables: &mut HashMap<String, TypeVariable>,
496    counter: &mut u32,
497) -> Type {
498    let variable = |name: &Name| crate::canonical::Type::Variable(name.clone());
499
500    let canonical = match head {
501        InstanceHead::Type(name, parameters) => {
502            crate::canonical::Type::Type(name.clone(), parameters.iter().map(variable).collect())
503        }
504        InstanceHead::Tuple(tuple) => {
505            crate::canonical::Type::Tuple(tuple.map(|name| variable(name)))
506        }
507        InstanceHead::Unit => crate::canonical::Type::Unit,
508    };
509
510    // Every form of a canonical type translates, and a head is built from the three that
511    // can stand in one, so the fallback is a variable no one uses.
512    super::canonical_type_to_typer_type(&canonical, variables, counter).unwrap_or_else(|| {
513        *counter += 1;
514        Type::Variable(TypeVariable::flexible(*counter))
515    })
