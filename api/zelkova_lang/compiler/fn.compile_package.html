pub fn compile_package(package_dir: &Path) -> Result<(), CompilationError>
Expand description

Compile the package rooted at package_dir — a directory holding a zelkova.toml manifest beside a src/ source root, per docs/spec/packages.md — and every package it depends on.

Its tests/ root is not compiled; compile_package_with_tests is that build. A package is compiled from source the same way whether it is the one asked for or a dependency of it, and the whole build shares one file database and one error accumulator: an error in any package of it makes this return Err.
