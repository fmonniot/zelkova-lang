Struct CheckedModule 

Source 
pub struct CheckedModule {
    pub canonical: Module,
    pub ir: Module,
}
Expand description

One module that passed every check, in both the forms the compiler still needs it.

The two halves answer different questions and neither is derivable from the other. canonical is what an Interface is built from, so the modules that import this one are checked against it; ir is what a backend reads, and carries the solved types, the name kinds, the arities and the constructor positions that emission needs and name resolution never did.
