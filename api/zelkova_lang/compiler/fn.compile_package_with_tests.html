compile_package, compiling the package’s tests/ root as well as its src/.

This is what running a package’s own tests needs, and the only thing that ever reads a tests/ root: the tests of the build’s other packages are not compiled, because nothing outside a package reads its tests (Running a package’s tests). A package holding no tests/ at all compiles exactly as it does through compile_package.

It compiles the tests and does not run them: what makes a declaration a test is its type, and there is no runner.
