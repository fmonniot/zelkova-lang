pub fn declares_a_default<'a>(names: impl IntoIterator<Item = &'a Name>) -> bool
Expand description

Whether a package declares one of the eight, given the names of every module it contains.

A package this is true for is zelkova-core, the package the eight belong to, and none of its modules receives any of them (implicit_imports) — the package is told apart by what it declares, not by its PackageName, because compile_package only ever compiles one package at a time and has no second package’s name to compare against.
